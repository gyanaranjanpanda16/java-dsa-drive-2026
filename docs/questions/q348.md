# Q348 — Count dictionary occurrences under each prefix

**Topic:** Tries · **Level:** Beginner

## Question and contract

Count dictionary occurrences under each prefix. Implement the operation exposed by `String solve(String[] words,String[] prefixes)`. Non-null strings and arrays; case-sensitive UTF-16 code-unit matching; duplicates are allowed unless stated otherwise.

## Runnable example

```java
solve(new String[]{"app","apple","app","ape"},new String[]{"ap","app","z",""})
```

Expected output:

```text
[4, 3, 0, 4]
```

## How and why the answer works

Each inserted word increments exactly the nodes corresponding to its prefixes. Therefore pass at a prefix node equals the number of inserted occurrences beginning with that prefix. This avoids enumerating all descendants for popularity counts or prefix-based inventory summaries.

## Walkthrough

Insert app twice: both occurrences increment the app node. apple adds a third visit there; ape diverges before that node. Thus ap has4 occurrences while app has3.

## Complexity and tradeoffs

O((S+P) log(A+1)) time and O(S) space plus results. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

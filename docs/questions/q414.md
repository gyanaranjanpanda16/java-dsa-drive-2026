# Q414 — Target Sum Sign Assignments

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Target Sum Sign Assignments` using the operation demonstrated below. Integer inputs, long target; counts must fit long and reachable states must fit memory.

## Demonstration

```java
count(new int[]{1,1,1,1,1},3)
```

Expected output:

```text
5
```

## How and why

Assignments of a prefix are partitioned by their sum. Extending each with plus and minus enumerates every new assignment exactly once, and merging equal sums retains their multiplicity.

## Walkthrough

Five1s total3 when exactly one position gets a minus sign; any of five positions can be chosen.

## Complexity and tradeoffs

O(n*S) expected time and O(S) space where S is the maximum number of distinct reachable totals; S may be exponential.

Use the input domain above when judging whether the state space fits memory and whether arithmetic fits the chosen numeric type. Recursive output-generation problems have an unavoidable cost proportional to their output; avoid using them on unrestricted large inputs.

- `Map<Long,Long> counts=new HashMap<>(); counts.put(0L,1L);` — The empty prefix has one assignment with total zero.
- `for(int value:values) {` — Assign one sign to each input position, including zeros.
- `Map<Long,Long> next=new HashMap<>();` — New states must not reuse the same position more than once.
- `next.merge(entry.getKey()+value,entry.getValue(),Math::addExact);` — Appending plus preserves all assignments leading to this total.

- `counts=next;` — Move to assignments of the entire processed prefix.

# Q421 — Longest Common Subsequence Length

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Longest Common Subsequence Length` using the operation demonstrated below. Non-null strings; compare UTF-16 char units; a subsequence need not be contiguous.

## Demonstration

```java
length("abcde","ace")
```

Expected output:

```text
3
```

## How and why

When final units match an optimum can pair them; otherwise a common subsequence must skip at least one unmatched end. These cases yield the recurrence over prefix pairs.

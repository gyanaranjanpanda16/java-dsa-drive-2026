# Q409 — Maximal Square Area

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Maximal Square Area` using the operation demonstrated below. Rectangular zero/one matrix; return the area of the largest all-one square.

## Demonstration

```java
area(new int[][]{{1,1,0},{1,1,1},{0,1,1}})
```

Expected output:

```text
4
```

## How and why

A square ending at a one-cell can extend only as far as the smallest square above, left, and diagonally above-left. Their overlap covers every cell of the proposed larger square.

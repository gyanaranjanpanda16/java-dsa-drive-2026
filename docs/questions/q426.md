# Q426 — Count Palindromic Substrings

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Count Palindromic Substrings` using the operation demonstrated below. Count nonempty positional substrings using UTF-16-unit equality.

## Demonstration

```java
count("aaa")
```

Expected output:

```text
6
```

## How and why

An interval is a palindrome exactly when its ends agree and its interior is palindromic. Processing intervals after their interior makes this a direct inductive proof.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

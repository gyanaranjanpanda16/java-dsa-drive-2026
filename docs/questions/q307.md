# Q307 — Build an undirected adjacency matrix

**Topic:** Graphs · **Level:** Beginner

## Question and contract

Build an undirected adjacency matrix. Implement the operation exposed by `String solve(int n,int[][] edges)`. Valid vertex endpoints; duplicate edges collapse to presence, not multiplicity.

## Runnable example

```java
solve(3,new int[][]{{0,1},{1,2}})
```

Expected output:

```text
[[0, 1, 0], [1, 0, 1], [0, 1, 0]]
```

## How and why the answer works

Matrix position[u][v] is one exactly when an edge connects the vertices. Setting both symmetric positions represents undirected edges; repeated edges collapse because this is a presence matrix.

# Q307 — Build an undirected adjacency matrix

**Topic:** Graphs · **Level:** Beginner

## Question and contract

Build an undirected adjacency matrix. Implement the operation exposed by `String solve(int n,int[][] edges)`. Valid vertex endpoints; duplicate edges collapse to presence, not multiplicity.

## Runnable example

```java
solve(3,new int[][]{{0,1},{1,2}})
```

Expected output:

```text
[[0, 1, 0], [1, 0, 1], [0, 1, 0]]
```

## How and why the answer works

Matrix position[u][v] is one exactly when an edge connects the vertices. Setting both symmetric positions represents undirected edges; repeated edges collapse because this is a presence matrix.

## Walkthrough

For undirected edges 0–1 and 1–2, mark both matrix[0][1] and matrix[1][0], then both matrix[1][2] and matrix[2][1]. Other entries remain 0. Symmetry records that either direction can be traversed. This matrix spends O(V²) space to make an edge-presence lookup direct.

## Complexity and tradeoffs

O(V²+E) time including allocation; O(V²) space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

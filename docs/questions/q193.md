# Q193 — Count days until a strictly warmer temperature

**Topic:** Stacks, queues, and deques · **Level:** Medium

## Question and contract

Return waiting days for the next greater temperature; zero means no warmer future day.

## Example

Input:73,74,75,71,69,72,76,73.

Expected printed output:

```text
[1, 1, 4, 2, 1, 1, 0, 0]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

Unresolved days form a decreasing stack. The first incoming warmer temperature resolves every smaller stacked temperature, so its index distance is the minimum wait.

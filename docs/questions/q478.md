# Q478 — Recover one unpaired value with XOR

**Topic:** XOR cancellation · **Level:** Easy

## Problem and accepted inputs

A nonempty int array has exactly one value occurring once and every other distinct value occurring exactly twice. Return the singleton.

## Example

```java
solve(new int[]{4,1,2,1,2})
```

Expected Java value: `4`.

Expected printed output (verified):

```text
4
```

## How, why, and where to use it

XOR is associative and commutative, and x XOR x=0. Every pair cancels regardless of position, leaving the singleton. This is a compact parity-based recovery technique; it relies on the stated multiplicity contract.

## Worked trace

[4,1,2,1,2] cancels both1s and both2s, leaving4.

- `public static int solve(int[] a) {` — Recover the unmatched32-bit pattern using cancellation.
- `int result=0;` — Zero is the identity for XOR.
- `for(int value:a) result^=value;` — Equal pairs cancel independently of their order.
- `return result;` — The only uncancelled occurrence is the promised singleton.

## Complexity and tradeoffs

O(n) time and O(1) space; no frequency map is needed under the exact pair assumption.

## Cases to practise

- `solve(new int[]{4,1,2,1,2})` → `4`: Pairs are interleaved.
- `solve(new int[]{-3})` → `-3`: A single negative value.
- `solve(new int[]{Integer.MIN_VALUE,7,7})` → `Integer.MIN_VALUE`: The sign bit is preserved by XOR.

# Q285 — Flatten a tree into a preorder right-child chain

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Flatten a tree into a preorder right-child chain. Implement the operation exposed by `String solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
[4, 2, 1, 3, 6, 5, 7]
```

## How and why the answer works

Flatten left and right subtrees first. Place the flattened left chain after the root, connect its tail to the original right chain, and clear the left link. Returning tails avoids repeated tail scans.

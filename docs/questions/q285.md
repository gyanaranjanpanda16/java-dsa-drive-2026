# Q285 — Flatten a tree into a preorder right-child chain

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Flatten a tree into a preorder right-child chain. Implement the operation exposed by `String solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
[4, 2, 1, 3, 6, 5, 7]
```

## How and why the answer works

Flatten left and right subtrees first. Place the flattened left chain after the root, connect its tail to the original right chain, and clear the left link. Returning tails avoids repeated tail scans.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

The required chain follows preorder 4,2,1,3,6,5,7. Reconnect each visited node as the preceding node's right child and clear left links. Saving or processing the original children before overwriting their links prevents losing the remaining subtree. The output is a chain made from tree nodes, not just a list of copied values.

## Complexity and tradeoffs

O(n) time; O(h) recursion plus output. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `static Node flatten(Node n) {` — Return the tail of the flattened chain rooted at n.
- `Node leftTail=flatten(n.left),rightTail=flatten(n.right);` — Flatten both child chains before reconnecting them.
- `if(leftTail!=null) { leftTail.right=n.right; n.right=n.left; n.left=null; }` — Splice left preorder before right preorder without losing either chain.
- `return rightTail!=null?rightTail:(leftTail!=null?leftTail:n);` — The last existing subtree determines the combined tail.
- `while(root!=null) { out.add(root.value); root=root.right; }` — Right links now follow preorder successor order.
- `return out.toString();` — Each original node appears exactly once.

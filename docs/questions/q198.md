# Q198 — Implement LIFO behavior with queue rotation

**Topic:** Stacks, queues, and deques · **Level:** Medium

## Question and contract

Push input values using a FIFO queue, then remove all in stack order.

## Example

Input:[1,2,3].

Expected printed output:

```text
[3, 2, 1]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

After appending a new value, rotating all older values behind it makes the newest value the queue front. The front therefore behaves as the stack top.

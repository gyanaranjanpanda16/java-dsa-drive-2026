# Q214 — Return the distinct intersection in first-array order

**Topic:** Hash maps and sets · **Level:** Easy

## Question and contract

Return each integer present in both arrays once, ordered by its first appearance in the first array.

## Example

First [3,1,3,2], second [2,3,3].

Expected printed output:

```text
[3, 2]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

A set stores unmatched second-array membership. Removing a value upon its first successful match both proves membership and prevents duplicate output. Useful when intersecting user cohorts while retaining a preferred display order.

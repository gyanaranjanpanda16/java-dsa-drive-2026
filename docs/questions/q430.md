# Q430 — Wildcard Pattern Match

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Wildcard Pattern Match` using the operation demonstrated below. Full-string wildcard matching: ? means one UTF-16 unit, * means any number; other units are literals.

## Demonstration

```java
matches("adceb","*a*b")
```

Expected output:

```text
true
```

## How and why

A star match splits into empty consumption or at least one unit, leaving the same star to consume more. Other tokens must consume one matching unit; these cases are exhaustive.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

## Walkthrough

In adceb, the first star consumes nothing, a matches a, the second star consumes dce, and b matches b.

## Complexity and tradeoffs

O(textLength*patternLength) time and space.

Use the input domain above when judging whether the state space fits memory and whether arithmetic fits the chosen numeric type. Recursive output-generation problems have an unavoidable cost proportional to their output; avoid using them on unrestricted large inputs.

# Q430 — Wildcard Pattern Match

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Wildcard Pattern Match` using the operation demonstrated below. Full-string wildcard matching: ? means one UTF-16 unit, * means any number; other units are literals.

## Demonstration

```java
matches("adceb","*a*b")
```

Expected output:

```text
true
```

## How and why

A star match splits into empty consumption or at least one unit, leaving the same star to consume more. Other tokens must consume one matching unit; these cases are exhaustive.

## Walkthrough

In adceb, the first star consumes nothing, a matches a, the second star consumes dce, and b matches b.

O(textLength*patternLength) time and space.

- `for(int j=1;j<=pattern.length();j++) dp[0][j]=pattern.charAt(j-1)=='*'&&dp[0][j-1];` — Only an all-star prefix can match empty text.
- `for(int i=1;i<=text.length();i++) for(int j=1;j<=pattern.length();j++) {` — Solve shorter text/pattern prefix pairs first.
- `char token=pattern.charAt(j-1);` — Interpret only the final token of this pattern prefix.
- `if(token=='*') dp[i][j]=dp[i][j-1]||dp[i-1][j];` — Star matches nothing or absorbs one more text unit.
- `else dp[i][j]=(token=='?'||token==text.charAt(i-1))&&dp[i-1][j-1];` — A literal or question mark consumes exactly one unit.
- `return dp[text.length()][pattern.length()];` — Require a full match, not a matching substring.

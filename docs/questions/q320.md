# Q320 — Enumerate every source-to-target path in a DAG

**Topic:** Graphs · **Level:** Medium

## Question and contract

Enumerate every source-to-target path in a DAG. Implement the operation exposed by `String solve(int n,int[][] edges,int source,int target)`. Directed acyclic simple graph, valid existing source/target; small inputs because the number of paths may be exponential.

## Runnable example

```java
solve(4,new int[][]{{0,1},{0,2},{1,3},{2,3}},0,3)
```

Expected output:

```text
[[0, 1, 3], [0, 2, 3]]
```

## How and why the answer works

Each recursive branch appends exactly one next edge. Distinct source-to-target edge choices form distinct recursion branches, so every route is generated once. Copying completed paths and undoing the latest choice prevents sibling branches from sharing mutable output.

## Complexity and tradeoffs

Output-sensitive and potentially exponential; O(V) recursion/current path plus stored paths. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

# Q215 — Intersect arrays including matched duplicate occurrences

**Topic:** Hash maps and sets · **Level:** Easy

## Question and contract

Return min(leftCount,rightCount) copies of each shared value, in first-array encounter order.

## Example

First [2,1,2,2], second [2,2,3].

Expected printed output:

```text
[2, 2]
```

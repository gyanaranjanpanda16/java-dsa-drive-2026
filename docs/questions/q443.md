# Q443 — Stock Profit With At Most K Trades

**Topic:** Dynamic programming · **Difficulty:** Hard

## Question and contract

Implement `Stock Profit With At Most K Trades` using the operation demonstrated below. Nonnegative int prices; at most one held share; no fees or cooldown.

## Demonstration

```java
profit(new int[]{3,2,6,5,0,3},2)
```

Expected output:

```text
7
```

## How and why

For each transaction budget track the best holding and nonholding profit. A purchase consumes the opportunity for the next completed trade, while a sale realizes that budget state.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

## Walkthrough

Buy2/sell6 earns4 and buy0/sell3 earns3, giving7 with two trades.

## Complexity and tradeoffs

O(n*min(k,n)) time, O(k) space when k<n/2; otherwise O(n) time and O(1) space.

Use the input domain above when judging whether the state space fits memory and whether arithmetic fits the chosen numeric type. Recursive output-generation problems have an unavoidable cost proportional to their output; avoid using them on unrestricted large inputs.

# Q460 — Partition Labels

**Topic:** Greedy and search on answer · **Difficulty:** Medium

## Question and contract

Implement `Partition Labels` using the operation demonstrated below. Partition a UTF-16 string into as many contiguous blocks as possible, with each unit appearing in only one block.

## Demonstration

```java
lengths("ababcbacadefegdehijhklij")
```

Expected output:

```text
[9, 7, 8]
```

## How and why

A partition containing a unit must include its last occurrence. Expanding to every forced endpoint yields the earliest possible valid cut, and taking that cut cannot reduce the number of later partitions.

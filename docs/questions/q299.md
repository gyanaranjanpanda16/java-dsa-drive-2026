# Q299 — Sort values displaced by at most k positions

**Topic:** Bounded heaps · **Level:** Medium

## Question and contract

Sort values displaced by at most k positions. Implement the operation exposed by `String solve(int[] a,int k)`. Input must already satisfy the displacement guarantee; arbitrary input with small k need not be sorted by this method.

## Runnable example

```java
solve(new int[]{2,1,4,3},1)
```

Expected output:

```text
[1, 2, 3, 4]
```

## How and why the answer works

If every value is within k positions of a sorted placement, the next required value must occur among the next k+1 unconsumed candidates. Removing their minimum and admitting the next arrival maintains that fact.

## Walkthrough

For [2,1,4,3] with displacement bound k 1, the smallest next value must occur among the next k+1=2 candidates. The initial heap emits 1, then adding 4 lets it emit 2. Adding 3 makes the next output 3, followed by 4. A heap of only k candidates could omit the correct next value.

## Complexity and tradeoffs

O(n log(k+2)) time; O(min(n,k+1)) heap plus output. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

- `List<Integer> result=new ArrayList<>();` — Emit the sorted sequence without changing the input.

- `heap.offer(value);` — The next answer cannot lie farther right than this candidate boundary.
- `if(heap.size()>k) result.add(heap.poll());` — Once k+1 candidates exist, their minimum is the next sorted value.

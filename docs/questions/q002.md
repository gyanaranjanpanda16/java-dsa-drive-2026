# Q002 — Print array indices beside values

**Topic:** Arrays — first steps · **Level:** Beginner

## Question and contract

Return index:value pairs for every array element. An indexed loop is needed because this output requires both the position and the stored value.

Implement `String solve(int[] a)`. The examples below define concrete accepted inputs and expected answers. Unless stated otherwise, reference inputs must be non-null; unsupported input violates the method's contract. Read the validation and comments in the source for additional restrictions.

## Example and answer

Input arguments: `new int[]{4,8}`

Expected Java value: `"0:4, 1:8"`

Expected printed output (verified):

```text
0:4, 1:8
```

## How and why the answer works

Return index:value pairs for every array element. An indexed loop is needed because this output requires both the position and the stored value.

Follow the state in this order for the sample input; each explanation corresponds to a line in the solution:

- `StringJoiner result = new StringJoiner(", ");` — Separate index:value entries without trailing punctuation.
- `for (int i = 0; i < a.length; i++) {` — Stop before length because the last valid index is length minus one.
- `result.add(i + ":" + a[i]);` — Use the index to access and label exactly one array slot.
- `return result.toString();` — Preserve the association between each position and value.

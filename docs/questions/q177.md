# Q177 — Remove repeated values from a sorted list

**Topic:** Linked lists · **Level:** Easy

## Question and contract

Input is nondecreasing and acyclic; retain one node per distinct value.

## Example

The demonstration constructs a fresh linked list with `list(...)`.

Expected printed output:

```text
[1, 2, 3]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

Equal values form adjacent runs. Keeping the first node and repeatedly bypassing equal successors collapses each run without affecting other values.

# Q138 — Find the longest common prefix

**Topic:** Strings · **Level:** Easy

## Question and contract

Return the common starting sequence of all non-null strings; an empty array yields an empty string.

## Example

Input: `flower`, `flow`, `flight`.

Expected printed output:

```text
fl
```

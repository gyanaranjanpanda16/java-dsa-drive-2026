# Q336 — Count provinces from a symmetric connection matrix

**Topic:** Graphs · **Level:** Medium

## Question and contract

Count provinces from a symmetric connection matrix. Implement the operation exposed by `int solve(int[][] connected)`. Square symmetric binary matrix; diagonal values do not affect component membership.

## How and why the answer works

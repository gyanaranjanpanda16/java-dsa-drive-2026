# Q155 — Add binary strings without numeric parsing

**Topic:** Strings · **Level:** Medium

## Question and contract

Add nonempty binary strings and return canonical binary output without leading zeros except zero itself. Inputs contain only0/1.

## Example

Input:1010 and1011.

Expected printed output:

```text
10101
```

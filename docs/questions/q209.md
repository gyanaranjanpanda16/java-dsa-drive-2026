# Q209 — Simplify an absolute Unix-style path

**Topic:** Stacks, queues, and deques · **Level:** Medium

## Question and contract

Input is an absolute path. Ignore repeated slashes and dot components; dot-dot removes a preceding component but cannot climb above root. This is lexical simplification,not filesystem/symlink resolution.

## Example

Input:/a/./b/../../c/.

Expected printed output:

```text
/c
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

A deque stores the surviving directory components. Ordinary names extend the path,while dot-dot reverses the most recent surviving directory entry.

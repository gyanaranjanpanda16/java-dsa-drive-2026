# Q204 — Interleave the two halves of an even queue

**Topic:** Stacks, queues, and deques · **Level:** Easy

## Question and contract

Input length must be even. Return first-half[0],second-half[0],first-half[1],second-half[1],and so on.

## Example

Input:[1,2,3,4,5,6].

Expected printed output:

```text
[1, 4, 2, 5, 3, 6]
```

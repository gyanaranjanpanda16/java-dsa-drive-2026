# Q145 — Find a substring using KMP failure links

**Topic:** Strings · **Level:** Medium

## Question and contract

Return first exact pattern index or -1; empty pattern returns0.

## Example

Input: ababcabcabababd, ababd.

Expected printed output:

```text
10
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

A failure link preserves the longest prefix already known to equal the suffix of matched text. It discards only impossible starts, so no text position needs to be re-read.

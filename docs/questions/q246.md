# Q246 — Sort by inserting each value into a sorted prefix

**Topic:** Elementary sorting · **Level:** Easy

## Problem and accepted inputs

Return a sorted copy using stable insertion sort.

## Example

```java
solve(new int[]{3,1,2})
```

Expected Java value: `new int[]{1,2,3}`.

Expected printed output (verified):

```text
[1, 2, 3]
```

## How, why, and where to use it

Before each iteration, the prefix is sorted. Shift only values larger than the new value, then fill the resulting gap. Equal values are not moved past each other, making the algorithm stable and useful for small or nearly sorted inputs.

## Worked trace

For[3,1,2], insert1 before3, then shift3 once to insert2 between1 and3.

## Line-by-line reasoning

- `public static int[] solve(int[] input) {` — Return new storage instead of modifying the supplied array.
- `int[] a=input.clone();` — A prefix of length one is already sorted.
- `for(int i=1;i<a.length;i++) {` — Extend the sorted prefix to include the next value.
- `int value=a[i],j=i-1;` — Save the value before shifting overwrites its original slot.
- `while(j>=0 && a[j]>value) { a[j+1]=a[j]; j--; }` — Move only larger values right, preserving equal-value order.
- `a[j+1]=value;` — The first nonlarger predecessor defines the insertion gap.
- `return a;` — Induction on prefix length establishes complete sorted order.

## Complexity and tradeoffs

O(n²) worst-case, O(n) on sorted input; O(n) output copy and O(1) working state.

## Cases to practise

- `solve(new int[]{3,1,2})` → `new int[]{1,2,3}`: Insert into two growing prefixes.
- `solve(new int[]{1,2,3})` → `new int[]{1,2,3}`: Already sorted needs no shifts.
- `solve(new int[]{2,-1,2})` → `new int[]{-1,2,2}`: Keep duplicates while moving a smaller value.

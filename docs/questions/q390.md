# Q390 — Count N Queens Placements

**Topic:** Recursion and backtracking · **Difficulty:** Hard

## Question and contract

Implement `Count N Queens Placements` using the operation demonstrated below. Count boards with n nonattacking queens; empty board counts as one placement.

## Demonstration

```java
count(4)
```

Expected printed output (verified):

```text
2
```

## How and why

Placing one queen per row removes row conflicts. Three occupancy arrays detect exactly the remaining column and diagonal attacks, so each accepted complete board is legal.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

## Walkthrough

For n=4, the two column sequences are [1,3,0,2] and [2,0,3,1].

## Complexity and tradeoffs

O(n*n!) upper-bound search time, O(n) working space.

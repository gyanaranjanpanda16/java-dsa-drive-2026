# Q347 — Check whether dictionary words share a requested prefix

**Topic:** Tries · **Level:** Beginner

## Question and contract

Check whether dictionary words share a requested prefix. Implement the operation exposed by `String solve(String[] words,String[] prefixes)`. Non-null strings and arrays; case-sensitive UTF-16 code-unit matching; duplicates are allowed unless stated otherwise.

## Runnable example

```java
solve(new String[]{"apple","ape"},new String[]{"ap","app","bat"})
```

Expected output:

```text
[true, true, false]
```

## How and why the answer works

All words under a trie node share its root-to-node prefix, so reaching a node with positive pass count is exactly the existence condition. Prefix search is useful for interactive lookup and early rejection during word-game exploration. The TreeMap edges support deterministic traversal and arbitrary UTF-16 units.

## Walkthrough

The words apple and ape both pass through ap. Only apple passes through app. No root edge for b exists, so bat is rejected immediately.

## Complexity and tradeoffs

O((S+P) log(A+1)) time for dictionary and queried prefix characters; O(S) space plus results. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Checks and edge cases

- Shared and absent prefixes.
- An empty dictionary has no matching word.
- An empty stored word shares the empty prefix.

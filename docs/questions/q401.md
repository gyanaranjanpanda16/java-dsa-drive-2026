# Q401 — Climbing Stairs

**Topic:** Dynamic programming · **Difficulty:** Easy

## Question and contract

Implement `Climbing Stairs` using the operation demonstrated below. Count ways to climb n steps using moves of one or two; 0<=n<=91.

## Demonstration

```java
ways(5)
```

Expected printed output (verified):

```text
8
```

## How and why

Paths ending with one step correspond to paths to n-1; paths ending with two correspond to n-2. These disjoint cases cover every valid path.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

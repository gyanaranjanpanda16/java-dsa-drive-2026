# Q335 — Return the last edge that closes an undirected cycle

**Topic:** Graphs · **Level:** Medium

## Question and contract

Return the last edge that closes an undirected cycle. Implement the operation exposed by `String solve(int n,int[][] edges)`. Undirected edge pairs with valid vertices; multiple cycle-closing edges are allowed; return the last one in input order.

## Runnable example

```java
solve(3,new int[][]{{0,1},{1,2},{2,0}})
```

Expected output:

```text
[2, 0]
```

## How and why the answer works

Before inserting an edge, its endpoints are connected exactly when some earlier path joins them. Adding the new edge then creates a cycle; if the endpoints are separate, joining them preserves a forest between components.

## Walkthrough

Process 0–1 and 1–2, joining all three vertices into one component. Edge 2–0 has both endpoints already connected, so adding it closes a cycle and it is returned as [2,0]. Union-find detects redundant connectivity without searching the existing graph anew for each edge.

## Complexity and tradeoffs

O(V+E α(V)) amortized time and O(V) space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

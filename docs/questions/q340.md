# Q340 — Decide whether all undirected edges can be traversed once

**Topic:** Graphs · **Level:** Medium

## Question and contract

Decide whether all undirected edges can be traversed once. Implement the operation exposed by `boolean solve(int n,int[][] edges)`. Undirected multigraph; loops and repeated edges allowed; isolated vertices ignored; empty edge set has an empty Euler trail.

## Runnable example

```java
solve(3,new int[][]{{0,1},{1,2}})
```

Expected output:

```text
true
```

## How and why the answer works

Every interior visit uses one entering and one leaving edge, so only zero or two vertices may have odd degree. With connected non-isolated vertices, these parity conditions are also sufficient by successively splicing edge cycles into a trail.

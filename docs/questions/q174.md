# Q174 — Detect a cycle using two moving pointers

**Topic:** Linked lists · **Level:** Easy

## Question and contract

Return whether following next references eventually revisits a node; null is acyclic.

## Example

The demonstration constructs a fresh linked list with `list(...)`.

Expected printed output:

```text
true
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

Inside a cycle, a fast pointer gains one position per step relative to slow, so they eventually coincide. In an acyclic chain fast reaches null.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value;Node next;` — The next reference, not physical adjacency, determines sequence order.
- `Node(int value) { this.value=value; }` — A new node starts with no successor.
- `static Node list(int... values) {` — Build a fresh acyclic list for each independent example.
- `Node dummy=new Node(0),tail=dummy;` — A sentinel makes the first append identical to later appends.
- `for(int value:values) { tail.next=new Node(value);tail=tail.next; }` — Attach each new value at the current tail.
- `return dummy.next;` — Exclude the sentinel from the logical data.
- `if(slow==fast) return true;` — Meeting after movement proves a reference cycle.
- `return false;` — A null successor proves the chain terminates.

# Q036 — Remove all occurrences while preserving order

**Topic:** Array compaction · **Level:** Beginner

## Question and contract

Return a new array with every occurrence of a selected value removed. A logical write count makes the number of retained elements explicit.

Implement `int[] solve(int[] a, int removed)`. The examples below define concrete accepted inputs and expected answers. Unless stated otherwise, reference inputs must be non-null; unsupported input violates the method's contract. Read the validation and comments in the source for additional restrictions.

- `int size = 0;` — Track logical length separately from allocated capacity.

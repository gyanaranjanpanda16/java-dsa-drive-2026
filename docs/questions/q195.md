# Q195 — Find every fixed-window maximum with a deque

**Topic:** Stacks, queues, and deques · **Level:** Hard

## Question and contract

Require1<=k<=array length. Return maxima for every length-k contiguous window.

## Example

Input:[1,3,-1,-3,5,3,6,7],k3.

Expected printed output:

```text
[3, 3, 5, 5, 6, 7]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

The deque retains unexpired indices in decreasing value order. A newer at-least-as-large value dominates an older candidate and lasts longer, so removing it cannot change any future maximum.

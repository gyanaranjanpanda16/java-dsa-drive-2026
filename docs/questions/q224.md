# Q224 — Detect whether repeated digit-square sums reach one

**Topic:** Cycle detection with a set · **Level:** Easy

## Problem and accepted inputs

Return whether positive n eventually reaches1 by repeatedly replacing it with the sum of the squares of its decimal digits.

## Example

```java
solve(19)
```

Expected Java value: `true`.

Expected printed output (verified):

```text
true
```

## How, why, and where to use it

The transformation is deterministic and eventually enters a bounded finite set. Reaching1 succeeds; repeating a previous state proves a cycle that can never newly reach1. This is a simple model of cycle detection in deterministic state transitions.

## Worked trace

19→82→68→100→1 succeeds.2 eventually revisits4 and fails.

## Line-by-line reasoning

- `public static boolean solve(int n) {` — Accept only the positive-number version of the problem.
- `if(n<=0) throw new IllegalArgumentException("positive input required");` — Zero and negative values are outside this domain.
- `Set<Integer> seen=new HashSet<>();` — Remember states before following their deterministic successor.
- `while(n!=1 && seen.add(n)) {` — Stop either at success or at a repeated state.
- `int next=0;` — Accumulate the squared digits of the current number.
- `while(n>0) { int digit=n%10; next+=digit*digit; n/=10; }` — Extract and remove one decimal digit each iteration.
- `n=next;` — Advance to the newly computed state.
- `return n==1;` — A repeated non-one state traps the sequence in a cycle.

## Complexity and tradeoffs

O(s*d) time and O(s) space for s visited states and at most d decimal digits per state.

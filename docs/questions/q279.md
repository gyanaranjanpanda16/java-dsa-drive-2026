# Q279 — Delete a BST key while preserving ordering

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Delete a BST key while preserving ordering. Implement the operation exposed by `String solve(Node root,int key)`. Input is a valid unique-key BST. The tree is mutated; deleting an absent key is a no-op.

## Runnable example

```java
solve(sample(),4)
```

Expected output:

```text
[1, 2, 3, 5, 6, 7]
```

## How and why the answer works

A node with one child is replaced by that child. A node with two children uses the smallest right-subtree key as successor, then removes its original occurrence; this preserves both ordering boundaries.

# Q279 — Delete a BST key while preserving ordering

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Delete a BST key while preserving ordering. Implement the operation exposed by `String solve(Node root,int key)`. Input is a valid unique-key BST. The tree is mutated; deleting an absent key is a no-op.

## Runnable example

```java
solve(sample(),4)
```

Expected output:

```text
[1, 2, 3, 5, 6, 7]
```

## How and why the answer works

A node with one child is replaced by that child. A node with two children uses the smallest right-subtree key as successor, then removes its original occurrence; this preserves both ordering boundaries.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Deleting 4 is the two-child case. Its inorder successor is the smallest value in the right subtree,5. Replace the root value with 5, then remove the original 5 node beneath 6. Inorder becomes 1,2,3,5,6,7. Copying the successor without deleting its old occurrence would leave an unwanted duplicate.

## Complexity and tradeoffs

O(h) deletion; O(n) rendering and O(h) recursion. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

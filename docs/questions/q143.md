# Q143 — Palindrome after at most one deletion

**Topic:** Two pointers · **Level:** Easy

## Problem and accepted inputs

Return whether deleting zero or one UTF-16 char makes the entire string a palindrome. Case and spaces are significant; use a code-point representation for full Unicode characters.

## Example

```java
solve("abca")
```

Expected Java value: `true`.

Expected printed output (verified):

```text
true
```

## How, why, and where to use it

A baseline deletes each position and checks the result, taking quadratic time. Matching outer characters can be kept. At the first mismatch, any valid repair must delete either the left or the right mismatching character: deleting elsewhere leaves that mismatch. Check those two remaining ranges without allocating substrings. This models validation with a single missing or extra symbol, rather than arbitrary typo correction.

## Worked trace

For abca, a matches a, leaving b versus c. Skip b and the remaining c is a palindrome; therefore return true. For abc, skipping a leaves bc and skipping c leaves ab; both fail. A string already symmetric uses no deletion.

## Line-by-line reasoning

- `public static boolean solve(String text) {` — Keep indices into the original immutable string.
- `int left=0,right=text.length()-1;` — Start with the complete range.
- `while(left<right) {` — A zero- or one-character range is already a palindrome.
- `if(text.charAt(left)!=text.charAt(right)) return palindrome(text,left+1,right)||palindrome(text,left,right-1);` — Spend the only deletion at one mismatching endpoint.
- `left++; right--;` — Equal outer characters can remain in the answer.
- `return true;` — No deletion was needed.
- `private static boolean palindrome(String text,int left,int right) {` — This check has no deletion budget left.
- `while(left<right) if(text.charAt(left++)!=text.charAt(right--)) return false;` — Every remaining mirrored pair must agree.
- `return true;` — All pairs matched, including an empty range.

## Complexity and tradeoffs

O(n) time and O(1) extra space: one outer scan and at most two additional scans.

## Cases to practise

- `solve("abca")` → `true`: Delete the middle b or c.
- `solve("abc")` → `false`: One deletion is insufficient.
- `solve("")` → `true`: Empty string is symmetric.
- `solve("deeee")` → `true`: Deletion at the beginning.

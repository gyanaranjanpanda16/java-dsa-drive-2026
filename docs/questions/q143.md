# Q143 — Find the longest common prefix of strings

**Topic:** Strings · **Level:** Easy

## Question and contract

Return the shared leading chars of non-null strings; empty array returns empty text.

## Example

Input: flower, flow, flight.

Expected printed output:

```text
fl
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

A candidate prefix is repeatedly shortened until it prefixes every processed string. Once empty it cannot grow again.

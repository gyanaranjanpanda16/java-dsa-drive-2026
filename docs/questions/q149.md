# Q149 — Evaluate a valid Roman numeral

**Topic:** Strings · **Level:** Easy

## Question and contract

Convert a valid canonical uppercase Roman numeral using I,V,X,L,C,D,M; empty text returns0. Canonical validity is assumed.

## Example

Input: MCMXCIV.

Expected printed output:

```text
1994
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

A smaller symbol before a larger one is subtracted; otherwise it is added. This partitions valid Roman notation into its additive and subtractive contributions.

# Q324 — Compute each cell distance to the nearest zero

**Topic:** Multi-source BFS · **Level:** Medium

## Question and contract

Compute each cell distance to the nearest zero. Implement the operation exposed by `String solve(int[][] grid)`. Rectangular binary grid; four-way movement; minus one means no zero is reachable because none exists.

## Runnable example

```java
solve(new int[][]{{0,1,1},{1,1,0}})
```

Expected output:

```text
[[0, 1, 1], [1, 1, 0]]
```

## How and why the answer works

Starting BFS from every zero is equivalent to adding a virtual source connected to all zeros. Layers therefore represent the minimum distance to any zero, avoiding one search per cell.

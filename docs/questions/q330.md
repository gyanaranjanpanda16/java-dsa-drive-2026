# Q330 — Find shortest paths allowing negative edges

**Topic:** Graphs · **Level:** Medium

## Question and contract

Find shortest paths allowing negative edges. Implement the operation exposed by `String solve(int n,int[][] edges,int source)`. Edges are directed [from,to,int weight]; valid source; practical-size graphs with all intermediate arithmetic within long.

## Runnable example

```java
solve(3,new int[][]{{0,1,4},{0,2,5},{1,2,-2}},0)
```

Expected output:

```text
[0, 4, 2]
```

## How and why the answer works

After p full edge passes, every shortest route using at most p edges has been considered. Without a reachable negative cycle, a shortest route can be simple and needs at most V-1 edges. Another possible relaxation therefore signals an unbounded improvement cycle.

## Walkthrough

Initially distance 0=0 and others are unreachable. Edge 0→1 gives 4;0→2 gives 5;1→2 with weight-2 improves 2 to 2. Further relaxation cannot improve these distances, so the result is [0,4,2]. A negative edge is allowed here; a reachable negative cycle would require explicit detection because no finite shortest distance would exist.

## Complexity and tradeoffs

O(VE) time and O(V) distance storage. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

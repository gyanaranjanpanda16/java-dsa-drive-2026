# Q425 — Distinct Target Subsequences

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Distinct Target Subsequences` using the operation demonstrated below. Non-null strings; positional subsequences, UTF-16-unit equality.

## Demonstration

```java
count("rabbbit","rabbit")
```

Expected output:

```text
3
```

## How and why

Selections forming a target prefix partition into those that skip the new source position and those using it to match the final target unit. Descending updates preserve the earlier-source counts.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

## Walkthrough

Choose which one of the three b positions to omit in rabbbit, producing rabbit in three ways.

## Complexity and tradeoffs

O(sourceLength*targetLength) time and O(targetLength) space; overflow throws.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `long[] dp=new long[target.length()+1]; dp[0]=1;` — Every source prefix has exactly one empty positional subsequence.
- `for(int i=0;i<source.length();i++) {` — Introduce each source position exactly once.
- `for(int j=target.length();j>=1;j--) {` — Descending target length prevents reusing the current source position.
- `if(source.charAt(i)==target.charAt(j-1)) dp[j]=Math.addExact(dp[j],dp[j-1]);` — Either skip this position or use it as the target prefix's final unit.
- `return dp[target.length()];` — Count distinct selections of source indices, not distinct resulting text values.

# Q402 — Minimum Cost Climbing Stairs

**Topic:** Dynamic programming · **Difficulty:** Easy

## Question and contract

Implement `Minimum Cost Climbing Stairs` using the operation demonstrated below. Nonnegative step costs; start at step0 or step1 and pay on departure.

## Demonstration

```java
minimum(new int[]{10,15,20})
```

Expected printed output (verified):

```text
15
```

## How and why

To reach a position, the previous jump must come from one of the preceding two steps. Taking the cheaper total among these exhaustive choices gives the optimal substructure.

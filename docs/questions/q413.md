# Q413 — Ordered Sum Count

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Ordered Sum Count` using the operation demonstrated below. Distinct positive choices may be reused; count ordered sequences with a nonnegative target.

## Demonstration

```java
count(new int[]{1,2,3},4)
```

Expected output:

```text
7
```

## How and why

Every ordered sequence has a unique final value; removing it leaves a sequence counted by the smaller total. Summing these disjoint final-value cases counts orderings correctly.

# Q451 — Maximum Compatible Meetings

**Topic:** Greedy and search on answer · **Difficulty:** Medium

## Question and contract

Implement `Maximum Compatible Meetings` using the operation demonstrated below. Half-open positive-length intervals; touching meetings are compatible.

## Demonstration

```java
maximum(new int[][]{{1,4},{2,3},{3,5},{5,7}})
```

Expected output:

```text
3
```

## How and why

Replace the first meeting in any optimal schedule with the earliest-finishing compatible one. This cannot block any later meeting, so repeating the exchange proves the greedy count optimal.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int[][] sorted=Arrays.stream(meetings).map(int[]::clone).toArray(int[][]::new);` — Sort a copy so the caller retains the original order.
- `Arrays.sort(sorted,Comparator.comparingInt(m->m[1]));` — Earliest finishing compatible meeting leaves the most future room.
- `long finish=Long.MIN_VALUE; int count=0;` — No meeting has yet consumed any time.
- `for(int[] meeting:sorted) if(meeting[0]>=finish) { count++; finish=meeting[1]; }` — Accept only meetings that do not overlap the current schedule.
- `return count;` — Every accepted meeting preserves the earliest available finishing frontier.

# Q451 — Maximum Compatible Meetings

**Topic:** Greedy and search on answer · **Difficulty:** Medium

## Question and contract

Implement `Maximum Compatible Meetings` using the operation demonstrated below. Half-open positive-length intervals; touching meetings are compatible.

## Demonstration

```java
maximum(new int[][]{{1,4},{2,3},{3,5},{5,7}})
```

Expected output:

```text
3
```

## How and why

Replace the first meeting in any optimal schedule with the earliest-finishing compatible one. This cannot block any later meeting, so repeating the exchange proves the greedy count optimal.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

## Walkthrough

Choose2..3 then3..5 then5..7, totaling three meetings.

## Complexity and tradeoffs

O(n log n) time and O(n) copied storage.

Use the input domain above when judging whether the state space fits memory and whether arithmetic fits the chosen numeric type. Recursive output-generation problems have an unavoidable cost proportional to their output; avoid using them on unrestricted large inputs.

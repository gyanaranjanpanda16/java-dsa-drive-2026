# Q187 — Validate nesting of three bracket types

**Topic:** Stacks, queues, and deques · **Level:** Easy

## Question and contract

Input contains only (),[],{}. Return whether pairs are correctly nested; other characters throw.

## Example

Input:{[()]}.

Expected printed output:

```text
true
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

The stack contains unmatched openings. A closing bracket must match the newest unmatched opener; otherwise the pairs would cross or be missing.

Openers{,[,( are pushed;closers),],} pop the matching types in reverse order.

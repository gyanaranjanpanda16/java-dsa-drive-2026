# Q203 — Reverse the first k queue values only

**Topic:** Stacks, queues, and deques · **Level:** Easy

## Question and contract

Require0<=k<=length. Reverse the first k values and preserve the order of the remaining suffix.

## Example

Input:[1,2,3,4,5],k3.

Expected printed output:

```text
[3, 2, 1, 4, 5]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

A stack reverses exactly the removed prefix. Rotating the untouched suffix behind that reversed prefix restores its original relative placement.

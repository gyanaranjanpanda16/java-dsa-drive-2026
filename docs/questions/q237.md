# Q237 — Find the first sorted value at least a target

**Topic:** Binary-search boundaries · **Level:** Easy

## Problem and accepted inputs

Return the first index with a[index]>=target in a nondecreasing array, or length if none.

## Example

```java
solve(new int[]{1,2,2,4},2)
```

Expected Java value: `1`.

Expected printed output (verified):

```text
1
```

## How, why, and where to use it

Maintain a half-open candidate interval for the boundary between values below target and values at least target. An equal value stays in the right candidate half because an earlier equal value may exist. Useful for insertion positions and inclusive range starts.

## Worked trace

In[1,2,2,4], lowerBound(2)=1 and lowerBound(5)=4.

## Line-by-line reasoning

- `public static int solve(int[] a,int target) {` — Return a boundary position, which may be one past the last element.
- `int low=0,high=a.length;` — The half-open interval avoids a special absent-result case.
- `while(low<high) {` — Converge to the first position satisfying the monotone predicate.
- `int middle=low+(high-low)/2;` — middle remains a valid array index while low is below high.
- `if(a[middle]<target) low=middle+1; else high=middle;` — Equality may be the boundary, so do not discard it.
- `return low;` — All earlier entries are below target; this entry, if any, is at least target.

## Complexity and tradeoffs

O(log(n+1)) time and O(1) space.

## Cases to practise

- `solve(new int[]{1,2,2,4},2)` → `1`: Return the first duplicate.
- `solve(new int[]{1,2},5)` → `2`: Length denotes the end insertion position.
- `solve(new int[]{},0)` → `0`: The only empty-array boundary.

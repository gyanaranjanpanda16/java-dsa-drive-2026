# Q033 — Rotate an array left by one

**Topic:** Array transformations · **Level:** Beginner

## Question and contract

Rotate a copy left by one position. Saving the first element before shifting prevents it from being overwritten.

Implement `int[] solve(int[] input)`. The examples below define concrete accepted inputs and expected answers. Unless stated otherwise, reference inputs must be non-null; unsupported input violates the method's contract. Read the validation and comments in the source for additional restrictions.

## Example and answer

Input arguments: `new int[]{1,2,3}`

Expected Java value: `new int[]{2,3,1}`

Expected printed output (verified):

```text
[2, 3, 1]
```

## How and why the answer works

Rotate a copy left by one position. Saving the first element before shifting prevents it from being overwritten.

Follow the state in this order for the sample input; each explanation corresponds to a line in the solution:

- `int[] a = input.clone();` — Preserve the caller's data while modifying the output copy.
- `if (a.length == 0) return a;` — There is no first element to save on empty input.
- `int first = a[0];` — Save the element that wraps to the final position.
- `for (int i = 1; i < a.length; i++) a[i - 1] = a[i];` — Shift later values into the preceding position.
- `a[a.length - 1] = first;` — Complete the wraparound after all shifts.
- `return a;` — Rotation preserves the multiset and relative cyclic order.

# Q315 — Reconstruct one shortest unweighted route

**Topic:** Graphs · **Level:** Medium

## Question and contract

Reconstruct one shortest unweighted route. Implement the operation exposed by `String solve(int n,int[][] edges,int source,int target)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(4,new int[][]{{0,1},{0,2},{1,3},{2,3}},0,3)
```

Expected output:

```text
[0, 1, 3]
```

## How and why the answer works

BFS first discovery establishes a shortest distance. Saving the edge that caused discovery gives a predecessor whose distance is exactly one smaller; following these links reaches the source without cycles.

## Walkthrough

BFS discovers 1 and 2 from 0, storing their parent 0. It first discovers 3 from 1, storing parent[3]=1. Reconstruct backward 3→1→0 and reverse to get [0,1,3]. Parent links recover a route; a distance array alone would say only that the route has two edges.

## Complexity and tradeoffs

O(V+E) time and storage; route length is at most V. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

# Q266 — Mirror a tree and return its inorder traversal

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Mirror a tree and return its inorder traversal. Implement the operation exposed by `String solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
[7, 6, 5, 4, 3, 2, 1]
```

## How and why the answer works

Swapping children at every node reverses every left/right decision. Recursive mirroring handles descendants, so the whole shape is reflected, not just the root.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Swap the root's children so 6 moves left and 2 moves right. Apply the same swap inside each subtree:6 now has 7 then 5, and 2 now has 3 then 1. Inorder traversal becomes 7,6,5,4,3,2,1. Mirroring changes links; merely reversing one printed traversal would not modify the tree.

## Complexity and tradeoffs

O(n) time; O(h) stack plus output. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

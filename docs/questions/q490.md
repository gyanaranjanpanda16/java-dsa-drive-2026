# Q490 — Compute an exact combination count without factorial overflow

**Topic:** BigInteger arithmetic · **Level:** Medium

## Problem and accepted inputs

Return n choose k exactly for0<=k<=n<=10000.

## Example

```java
solve(52,5)
```

Expected Java value: `new BigInteger("2598960")`.

Expected printed output (verified):

```text

```

## How, why, and where to use it

Use the recurrence C(n-k+i,i)=C(n-k+i-1,i-1)*(n-k+i)/i. Each division is exact, and symmetry reduces work to min(k,n-k) steps. BigInteger preserves results beyond long, useful for exact combinatorial counts.

## Complexity and tradeoffs

O(min(k,n-k)) BigInteger multiplication/division steps and result-sized storage; bit-operation costs grow with the answer.

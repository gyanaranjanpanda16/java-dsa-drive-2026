# Q420 — Count Subsets With Target Sum

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Count Subsets With Target Sum` using the operation demonstrated below. Nonnegative values; count positional subsets, including the empty subset for target zero.

## Demonstration

```java
count(new int[]{1,2,3,3},6)
```

Expected output:

```text
3
```

## How and why

For each position, subsets split into those excluding it and those including it. Adding the previous smaller-total count implements this disjoint partition.

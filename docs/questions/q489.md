# Q489 — Find a modular inverse using extended Euclid

**Topic:** Number theory · **Level:** Medium

## Problem and accepted inputs

For int value and modulus>=2, return OptionalLong x in[0,modulus) with value*x congruent1 modulo modulus, or empty if no inverse exists.

## Example

```java
solve(3,11)
```

Expected Java value: `OptionalLong.of(4)`.

Expected printed output (verified):

```text
OptionalLong[4]
```

## How, why, and where to use it

Extended Euclid maintains coefficients expressing each remainder as a combination of the original value and modulus. An inverse exists exactly when their gcd is1; its coefficient gives the inverse after normalization. Useful for modular division when coprimality is guaranteed.

## Worked trace

3*4=12 is1 modulo11, so inverse(3,11)=4.2 has no inverse modulo4 because their gcd is2.

## Line-by-line reasoning

- `public static OptionalLong solve(int value,int modulus) {` — Absence is a legitimate result for noncoprime inputs.
- `if(modulus<2) throw new IllegalArgumentException("modulus at least two required");` — Define inverses in a nontrivial residue ring.
- `long remainder=modulus,next=Math.floorMod((long)value,modulus),coefficient=0,nextCoefficient=1;` — Track the value coefficient in each Euclidean remainder.
- `while(next!=0) {` — Euclid reduces positive remainders until the gcd remains.
- `long quotient=remainder/next,saved=remainder-quotient*next; remainder=next; next=saved;` — Apply one remainder reduction.
- `saved=coefficient-quotient*nextCoefficient; coefficient=nextCoefficient; nextCoefficient=saved;` — Apply the same linear combination to the associated coefficient.
- `if(remainder!=1) return OptionalLong.empty();` — Only gcd1 can express a modular multiplicative identity.
- `return OptionalLong.of(Math.floorMod(coefficient,(long)modulus));` — Normalize the coefficient into the requested residue range.

## Complexity and tradeoffs

O(log modulus) Euclidean steps and O(1) space.

## Cases to practise

- `solve(3,11)` → `OptionalLong.of(4)`: A coprime pair has an inverse.
- `solve(2,4)` → `OptionalLong.empty()`: A shared factor prevents inversion.
- `solve(-3,11)` → `OptionalLong.of(7)`: Normalize a negative input and coefficient.

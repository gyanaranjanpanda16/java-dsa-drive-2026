# Q256 — Count every node

**Topic:** Trees and BST · **Level:** Beginner

## Question and contract

Count every node. Implement the operation exposed by `int solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
7
```

## How and why the answer works

The root contributes one and its disjoint left and right subtrees contribute their counts.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Each missing child contributes 0. Each of the four leaves contributes 1; node 2 contributes 1+1+1=3 and node 6 contributes 3. The root contributes 1+3+3=7. The extra 1 in each non-null call counts that node exactly once; omitting it would count no nodes at all.

## Complexity and tradeoffs

O(n) time; O(h) call-stack space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `if(root==null) return 0;` — Supply the identity for an empty subtree.
- `return 1+solve(root.left)+solve(root.right);` — Combine the root with independent child answers.

# Q274 — Find the kth smallest BST key

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Find the kth smallest BST key. Implement the operation exposed by `int solve(Node root,int k)`. Input is a valid BST with unique values; k is one-based and must not exceed node count.

## Runnable example

```java
solve(sample(),3)
```

Expected output:

```text
3
```

## How and why the answer works

Inorder traversal of a BST is sorted. Stopping at the kth visit therefore returns the kth smallest key without sorting a separate collection.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Inorder visits 1 first,2 second,3 third. With k=3, stop at 3 instead of sorting an additional list. The meaning of kth is one-based here. BST ordering makes inorder sorted; the same counting on a general binary tree would produce a traversal position rather than an ordered statistic.

## Complexity and tradeoffs

O(h+k) time until a valid rank; O(h) stack. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `Deque<Node> stack=new ArrayDeque<>();` — Explicit frames avoid recursive inorder traversal.
- `while(root!=null||!stack.isEmpty()) {` — Continue while a left descent or deferred ancestor remains.
- `while(root!=null) { stack.push(root); root=root.left; }` — Descend to the smallest unvisited key.
- `root=stack.pop(); if(--k==0) return root.value;` — Each inorder visit advances the sorted rank once.
- `root=root.right;` — The next greater key lies in the right subtree or a deferred ancestor.
- `throw new IllegalArgumentException("k exceeds tree size");` — No kth key exists after exhausting the tree.

# Q274 — Find the kth smallest BST key

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Find the kth smallest BST key. Implement the operation exposed by `int solve(Node root,int k)`. Input is a valid BST with unique values; k is one-based and must not exceed node count.

## Runnable example

```java
solve(sample(),3)
```

Expected output:

```text
3
```

## How and why the answer works

Inorder traversal of a BST is sorted. Stopping at the kth visit therefore returns the kth smallest key without sorting a separate collection.

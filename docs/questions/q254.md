# Q254 — List values in breadth-first level order

**Topic:** Trees and BST · **Level:** Beginner

## Question and contract

List values in breadth-first level order. Implement the operation exposed by `String solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
[4, 2, 6, 1, 3, 5, 7]
```

## How and why the answer works

FIFO processes a level before its children because all existing queued nodes were discovered earlier. Each child is appended exactly once.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

The queue begins [4]. Removing 4 appends its children, giving [2,6]. Removing 2 appends 1,3 behind 6; removing 6 appends 5,7 behind those. The first-in-first-out queue therefore emits 4,2,6,1,3,5,7. A stack would prioritize one branch instead of preserving these levels.

## Complexity and tradeoffs

O(n) time; O(w) queue and O(n) output, where w is maximum width. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `List<Integer> out=new ArrayList<>();` — Preserve the order in which nodes leave the queue.
- `Deque<Node> queue=new ArrayDeque<>(); queue.add(root);` — FIFO begins with the root at depth zero.
- `while(!queue.isEmpty()) {` — Continue until every discovered node has been processed.
- `Node n=queue.removeFirst(); out.add(n.value);` — The oldest pending node has minimum pending depth.
- `if(n.left!=null) queue.addLast(n.left);` — Children join after all nodes already waiting at this level.
- `if(n.right!=null) queue.addLast(n.right);` — Left-before-right insertion defines a stable level order.

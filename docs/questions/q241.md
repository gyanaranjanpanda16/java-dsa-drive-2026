# Q241 — Find a strict local peak without scanning the whole array

**Topic:** Binary search on slope · **Level:** Medium

## Problem and accepted inputs

Adjacent values must differ. Return an index whose value exceeds its existing neighbors, treating missing endpoints as negative infinity; return-1 for empty input.

## Example

```java
solve(new int[]{1,2,3,1})
```

Expected Java value: `2`.

Expected printed output (verified):

```text
2
```

## How, why, and where to use it

If the slope rises from middle to middle+1, some peak exists on the right: a rising walk must end at a descent or the array endpoint. A falling slope guarantees one on the left including middle. This locates a local optimum, not necessarily the global maximum.

## Line-by-line reasoning

- `public static int solve(int[] a) {` — Find any strict local peak under the unequal-neighbor contract.
- `if(a.length==0) return -1;` — An empty array has no peak position.
- `int low=0,high=a.length-1;` — The retained interval always contains at least one peak.
- `while(low<high) {` — middle+1 is valid because middle is strictly below high.
- `int middle=low+(high-low)/2;` — Probe the local slope near the interval center.
- `if(a[middle]<a[middle+1]) low=middle+1; else high=middle;` — Follow the side that is guaranteed to contain a peak.
- `return low;` — Both bounds agree on a locally maximal position.

## Complexity and tradeoffs

O(log(n+1)) time and O(1) space.

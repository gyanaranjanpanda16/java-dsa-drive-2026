# Q128 — Check an exact palindrome

**Topic:** Strings · **Level:** Beginner

## Question and contract

Return whether a non-null string equals its reverse under exact UTF-16 char comparison.

## Example

Input: `level`.

Expected printed output:

```text
true
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

A palindrome requires every symmetric pair to match. One mismatch is sufficient to disprove it; all pairs matching proves it.

# Q442 — Stock Profit With Transaction Fee

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Stock Profit With Transaction Fee` using the operation demonstrated below. Nonnegative prices and fee; unlimited transactions, at most one held share.

## Demonstration

```java
profit(new int[]{1,3,2,8,4,9},2)
```

Expected output:

```text
8
```

## How and why

At each day the only relevant distinction is whether a share is held. Choosing the better hold/sell/buy transitions covers all legal trading histories, charging a fee only on sale.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `if(fee<0) throw new IllegalArgumentException("Nonnegative fee required");` — A fee is charged once for each completed trade.
- `long cash=0,hold=Long.MIN_VALUE/4;` — Start with no share and zero realized profit.
- `for(int value:price) {` — Consider either keeping the existing state or trading today.
- `long nextCash=Math.max(cash,hold+value-fee);` — Selling pays the fee exactly once.
- `long nextHold=Math.max(hold,cash-value);` — Buy using yesterday's cash so transitions do not accidentally chain.
- `cash=nextCash; hold=nextHold;` — Move both states to the next day.
- `return cash;` — Only realized cash is a completed trading answer.

# Q272 — Search a value in a binary search tree

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Search a value in a binary search tree. Implement the operation exposed by `boolean solve(Node root,int key)`. Input is a valid BST; duplicates are not stored.

## Runnable example

```java
solve(sample(),5)
```

Expected output:

```text
true
```

## How and why the answer works

The BST invariant places every smaller value to the left and every larger value to the right. Following that one admissible branch cannot discard the key.

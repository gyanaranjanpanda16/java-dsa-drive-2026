# Q272 — Search a value in a binary search tree

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Search a value in a binary search tree. Implement the operation exposed by `boolean solve(Node root,int key)`. Input is a valid BST; duplicates are not stored.

## Runnable example

```java
solve(sample(),5)
```

Expected output:

```text
true
```

## How and why the answer works

The BST invariant places every smaller value to the left and every larger value to the right. Following that one admissible branch cannot discard the key.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Compare target 5 with root 4: it is greater, so only the right subtree can contain it. At 6,5 is smaller, so go left. Node 5 matches and the search succeeds. This pruning relies on the BST ordering invariant; it is invalid for a general binary tree.

## Complexity and tradeoffs

O(h) time and O(1) extra space; h can equal n in an unbalanced tree. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

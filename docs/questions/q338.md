# Q338 — Find edges whose removal disconnects an undirected graph

**Topic:** Graphs · **Level:** Medium

## Question and contract

Find edges whose removal disconnects an undirected graph. Implement the operation exposed by `String solve(int n,int[][] edges)`. Simple undirected graph with valid vertices and no parallel edges; output sorted by endpoints; recursive depth must fit stack.

## Runnable example

```java
solve(4,new int[][]{{0,1},{1,2},{2,0},{1,3}})
```

Expected output:

```text
[[1, 3]]
```

## How and why the answer works

low[v] is the earliest discovery time reachable from the DFS subtree of v through tree edges followed by at most one back edge. A child subtree with low[child]>entered[parent] cannot reach the parent or an ancestor without its tree edge, so that edge is a bridge.

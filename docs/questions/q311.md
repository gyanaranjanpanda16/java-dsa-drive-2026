# Q311 — Traverse reachable vertices in depth-first order

**Topic:** Graphs · **Level:** Medium

## Question and contract

Traverse reachable vertices in depth-first order. Implement the operation exposed by `String solve(int n,int[][] edges,int source)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(4,new int[][]{{0,1},{0,2},{1,3}},0)
```

Expected output:

```text
[0, 1, 3, 2]
```

## How and why the answer works

Marking before recursive descent prevents cycles from reopening an active or completed vertex. Each call explores all outgoing edges of one vertex, so induction over the recursive exploration covers exactly the reachable set.

## Walkthrough

DFS from 0 chooses neighbor 1 first, then follows 1→3 before returning to 0 and visiting 2. The order is 0,1,3,2. The call stack remembers unfinished ancestors. Neighbor order affects traversal order, so a deterministic adjacency order is part of reproducing this example.

## Complexity and tradeoffs

O(V+E) time and graph storage; O(V) recursion/visited workspace. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

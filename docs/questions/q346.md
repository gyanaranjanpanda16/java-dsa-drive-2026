# Q346 — Find complete dictionary words with a trie

**Topic:** Tries · **Level:** Beginner

## Question and contract

Find complete dictionary words with a trie. Implement the operation exposed by `String solve(String[] words,String[] queries)`. Non-null strings and arrays; case-sensitive UTF-16 code-unit matching; duplicates are allowed unless stated otherwise.

## Runnable example

```java
solve(new String[]{"car","cart"},new String[]{"car","ca","cat"})
```

Expected output:

```text
[true, false, false]
```

## How and why the answer works

A trie stores shared prefixes as shared paths. Following the query reaches its unique prefix node if that prefix exists; the terminal flag then distinguishes a stored word from a partial prefix. This supports dictionary validation. Java has no standard Trie collection, so nodes compose a TreeMap of outgoing character edges.

## Walkthrough

In the example, car and cart share c→a→r. car ends at a terminal node; ca ends before any terminal marker; cat fails on its last edge.

## Complexity and tradeoffs

O((S+Q) log(A+1)) time, where S is total dictionary characters, Q total query characters and A alphabet size; O(S) trie space plus result. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Checks and edge cases

- Distinguish complete words, prefixes, and missing paths.
- The root can represent an empty word.
- An empty dictionary.

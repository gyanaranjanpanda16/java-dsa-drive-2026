# Q001 — Print every array element in order

**Topic:** Arrays — first steps · **Level:** Beginner

## Question and contract

Return the elements of an integer array as one space-separated line. Iteration is necessary because every element must appear; a StringJoiner preserves order and handles separators without special first/last cases.

Implement `String solve(int[] values)`. The examples below define concrete accepted inputs and expected answers. Unless stated otherwise, reference inputs must be non-null; unsupported input violates the method's contract. Read the validation and comments in the source for additional restrictions.

## Example and answer

Input arguments: `new int[]{10,20,30}`

Expected Java value: `"10 20 30"`

Expected printed output (verified):

```text
10 20 30
```

## How and why the answer works

Return the elements of an integer array as one space-separated line. Iteration is necessary because every element must appear; a StringJoiner preserves order and handles separators without special first/last cases.

Follow the state in this order for the sample input; each explanation corresponds to a line in the solution:

- `StringJoiner output = new StringJoiner(" ");` — Insert a separator only between elements, avoiding a trailing space.
- `for (int value : values) {` — Visit each stored value in its existing order.
- `output.add(Integer.toString(value));` — Convert the number to text before appending it.
- `return output.toString();` — An empty array naturally produces an empty line.

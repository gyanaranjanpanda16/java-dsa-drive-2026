# Q310 — Traverse reachable vertices in breadth-first order

**Topic:** Graphs · **Level:** Medium

## Question and contract

Traverse reachable vertices in breadth-first order. Implement the operation exposed by `String solve(int n,int[][] edges,int source)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(5,new int[][]{{0,1},{0,2},{1,3},{2,3}},0)
```

Expected output:

```text
[0, 1, 2, 3]
```

## How and why the answer works

Enqueueing children at the back makes vertices at distance d leave before vertices at distance d+1. Marking at discovery gives each reachable vertex exactly one queue entry.

## Walkthrough

Start BFS at 0 and mark it when queued. Processing 0 queues 1 and 2. Processing 1 queues 3; processing 2 also sees 3 but does not queue it again. Processing 3 adds nothing. Output is 0,1,2,3; vertex 4 is unreachable from 0 and should not be added merely because it exists in the graph.

## Complexity and tradeoffs

O(V+E) time including graph construction; O(V+E) storage and O(V) traversal workspace. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

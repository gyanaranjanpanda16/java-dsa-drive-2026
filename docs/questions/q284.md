# Q284 — Serialize a tree with null markers

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Serialize a tree with null markers. Implement the operation exposed by `String solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

## How and why the answer works

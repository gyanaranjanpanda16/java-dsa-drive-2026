# Q284 — Serialize a tree with null markers

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Serialize a tree with null markers. Implement the operation exposed by `String solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
4,2,1,#,#,3,#,#,6,5,#,#,7,#,#,
```

## How and why the answer works

Values alone do not identify a tree shape. Preorder plus explicit null-child markers uniquely describes where each child subtree begins and ends.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Preorder writes 4, then 2, then 1. The two missing children of 1 each write #, before traversal continues to 3. Continue similarly through 6,5,7 to obtain 4,2,1,#,#,3,#,#,6,5,#,#,7,#,#,. The null markers preserve tree shape; values alone could describe multiple different trees.

## Complexity and tradeoffs

O(n) node visits and O(n) output for fixed-width int values; O(h) stack. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `if(n==null) { out.append("#,"); return; }` — Null markers preserve the position of absent children.
- `out.append(n.value).append(',');` — Write the root before either child subtree.
- `encode(n.left,out); encode(n.right,out);` — Fixed child order makes the representation deterministic.
- `StringBuilder out=new StringBuilder(); encode(root,out);` — One preorder pass writes values and structural markers.
- `return out.toString();` — Commas separate multi-digit and negative values unambiguously.

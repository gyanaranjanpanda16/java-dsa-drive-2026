# Q197 — Implement FIFO removal with two stacks

**Topic:** Stacks, queues, and deques · **Level:** Medium

## Question and contract

Commands are add:x or remove; valid sequences remove only when nonempty. Return removed values.

## Example

Commands:add1,add2,remove,add3,remove,remove.

Expected printed output:

```text
[1, 2, 3]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

The incoming stack stores newest-first arrivals. Transferring all values to an empty outgoing stack reverses them into oldest-first order; remaining outgoing values always precede new arrivals.

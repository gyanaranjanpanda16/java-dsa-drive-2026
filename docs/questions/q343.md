# Q343 — Find the fewest obstacles to remove across a grid

**Topic:** Graphs · **Level:** Medium

## Question and contract

Find the fewest obstacles to remove across a grid. Implement the operation exposed by `int solve(int[][] grid)`. Nonempty rectangular binary grid with grid[0][0]=0; four-direction moves; each entered1 costs one removal; input is unchanged.

## Runnable example

```java
solve(new int[][]{{0,1,1},{1,1,0},{1,1,0}})
```

Expected output:

```text
2
```

## How and why the answer works

When weights are only zero or one, a deque maintains the same distance ordering needed by Dijkstra without a heap. A zero-cost relaxation belongs at the front; a cost-one relaxation belongs at the back. This is useful when route planning counts paid transitions rather than physical steps.

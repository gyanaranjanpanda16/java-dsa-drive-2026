# Q278 — Insert a missing BST key and show sorted contents

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Insert a missing BST key and show sorted contents. Implement the operation exposed by `String solve(Node root,int key)`. Input is a valid BST. This method mutates it, and duplicate insertion is ignored.

## Runnable example

```java
solve(sample(),8)
```

Expected output:

```text
[1, 2, 3, 4, 5, 6, 7, 8]
```

## How and why the answer works

Comparisons choose the only child subtree in which a new key can belong. The recursive return reconnects the changed subtree while preserving all untouched ordering relations.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Insert 8 by comparing against 4, then 6, then 7. Each comparison moves right because 8 is larger. The missing right child of 7 is the insertion point. Inorder becomes 1,2,3,4,5,6,7,8. Returning the updated subtree root allows callers to reconnect a newly created node, including insertion into an empty tree.

## Complexity and tradeoffs

O(h) insertion; O(n) display time/output and O(h) stack. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Checks and edge cases

- Insert a larger missing key.
- Insert into an empty tree.
- Duplicate key does not grow the tree.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `static Node insert(Node n,int key) {` — Return the root of the subtree after insertion.
- `if(n==null) return new Node(key);` — The first missing position is the insertion point.
- `if(key<n.value) n.left=insert(n.left,key);` — Smaller keys retain their left-side invariant.

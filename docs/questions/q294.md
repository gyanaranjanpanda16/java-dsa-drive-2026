# Q294 — Select the most frequent words with lexical ties

**Topic:** Maps and priority queues · **Level:** Medium

## Question and contract

Select the most frequent words with lexical ties. Implement the operation exposed by `String solve(String[] words,int k)`. Non-null words; exact Java String equality and natural UTF-16 lexical order; k>=0.

## Runnable example

```java
solve(new String[]{"java","dsa","java","array","dsa"},2)
```

Expected output:

```text
[dsa, java]
```

## How and why the answer works

Map frequencies establish each word priority. Comparing frequency first and text second defines a total deterministic ranking; queue removal always yields the best unreturned word.

## Walkthrough

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `Map<String,Integer> counts=new HashMap<>();` — Equal words share one frequency entry.
- `for(String word:words) counts.merge(Objects.requireNonNull(word),1,Integer::sum);` — Reject absent words and count exact case-sensitive matches.
- `PriorityQueue<String> heap=new PriorityQueue<>((a,b)->counts.get(a).equals(counts.get(b))?a.compareTo(b):Integer.compare(counts.get(b),counts.get(a)));` — Frequency dominates, then lexical order determines ties.
- `heap.addAll(counts.keySet());` — Each distinct word is a separate ranked candidate.
- `while(answer.size()<k&&!heap.isEmpty()) answer.add(heap.poll());` — Emit at most the number of available words.
- `return answer.toString();` — String list formatting reveals the ranking.

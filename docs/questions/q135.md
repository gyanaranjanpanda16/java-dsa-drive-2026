# Q135 — Find the first repeated encounter

**Topic:** Strings · **Level:** Easy

## Question and contract

Return the index of the first char encountered a second time; return -1 if all are distinct.

## Example

Input: `abcbad`.

Expected printed output:

```text
3
```

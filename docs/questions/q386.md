# Q386 — Generate Distinct Permutations

**Topic:** Recursion and backtracking · **Difficulty:** Medium

## Question and contract

Implement `Generate Distinct Permutations` using the operation demonstrated below. Distinct integers, small n; return all orderings without mutating input.

## Demonstration

```java
permutations(new int[]{1,2})
```

Expected printed output (verified):

```text
[[1, 2], [2, 1]]
```

## How and why

Fixing the next position partitions permutations by which remaining value occupies it. Swapping back restores the same unresolved suffix for the next branch.

## Walkthrough

Choose 1 then 2 to obtain [1,2]; restore and choose 2 then 1 for [2,1].

## Complexity and tradeoffs

O(n*n!) time/output and O(n) stack besides the copied input.

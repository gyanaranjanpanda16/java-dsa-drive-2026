# Q302 — Check the binary min-heap property

**Topic:** Heap invariants · **Level:** Easy

## Question and contract

Check the binary min-heap property. Implement the operation exposed by `boolean solve(int[] heap)`. An ordinary array has no missing internal positions; duplicate values are allowed.

## Runnable example

```java
solve(new int[]{1,3,2,7,4})
```

Expected output:

```text
true
```

## How and why the answer works

An array already represents a complete binary-tree shape. Therefore checking the heap property only requires checking every parent-child edge; transitivity then makes the root no larger than every descendant.

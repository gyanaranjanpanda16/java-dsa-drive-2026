# Q302 — Check the binary min-heap property

**Topic:** Heap invariants · **Level:** Easy

## Question and contract

Check the binary min-heap property. Implement the operation exposed by `boolean solve(int[] heap)`. An ordinary array has no missing internal positions; duplicate values are allowed.

## Runnable example

```java
solve(new int[]{1,3,2,7,4})
```

Expected output:

```text
true
```

## How and why the answer works

An array already represents a complete binary-tree shape. Therefore checking the heap property only requires checking every parent-child edge; transitivity then makes the root no larger than every descendant.

## Walkthrough

For [1,3,2,7,4], root 1 is no greater than children 3 and 2. Parent 3 is no greater than children 7 and 4. The remaining elements are leaves, so the min-heap property holds. A heap array need not be globally sorted:3 appears before 2 even though this is a valid heap.

## Complexity and tradeoffs

O(n) time and O(1) auxiliary space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Checks and edge cases

- Valid heap with unsorted siblings.
- Child smaller than parent.
- Empty array vacuously satisfies the invariant.

# Q301 — Build a binary min-heap in an array

**Topic:** Heap construction · **Level:** Medium

## Question and contract

Build a binary min-heap in an array. Implement the operation exposed by `String solve(int[] input)`. Input is any non-null int array; the resulting array is a heap, not necessarily fully sorted.

## Runnable example

```java
solve(new int[]{5,3,8,1,2})
```

Expected output:

```text
[1, 2, 8, 3, 5]
```

## How and why the answer works

When an internal node is processed, both child subtrees are already heaps. Sifting its root down restores its local order without breaking either child heap. Processing parents in reverse index order eventually repairs the whole tree.

## Walkthrough

Starting [5,3,8,1,2], first sift internal node 3 below child 1, producing [5,1,8,3,2]. Then sift root 5 below 1 and then 2, producing [1,2,8,3,5]. Leaves need no repair. Working from the last parent upward ensures both child subtrees are already heaps when their parent is processed.

## Complexity and tradeoffs

O(n) time, because most nodes have short downward paths; O(n) returned copy and O(1) working space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int[] a=input.clone();` — Heap construction should not modify the caller's input.
- `for(int root=a.length/2-1;root>=0;root--) {` — Leaves are already heaps; repair internal nodes bottom-up.
- `int parent=root;` — Follow the one branch whose parent order may be violated.
- `while(parent<a.length/2) {` — A node before length/2 has at least a left child.
- `int child=2*parent+1;` — Begin with the left child as the smaller-child candidate.
- `if(child+1<a.length&&a[child+1]<a[child]) child++;` — Swapping with the smaller child preserves both child comparisons.
- `parent=child;` — Only the displaced value's new branch can still violate the invariant.
- `return Arrays.toString(a);` — The array encodes a complete tree with every parent no larger than its children.

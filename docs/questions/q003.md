# Q003 — Print an array backwards without changing it

**Topic:** Arrays — first steps · **Level:** Beginner

## Question and contract

Produce the array elements in reverse order without modifying the input. Reversing the traversal order is sufficient; allocating a reversed numeric array is unnecessary.

Implement `String solve(int[] a)`. The examples below define concrete accepted inputs and expected answers. Unless stated otherwise, reference inputs must be non-null; unsupported input violates the method's contract. Read the validation and comments in the source for additional restrictions.

## Example and answer

Input arguments: `new int[]{1,2,3}`

Expected Java value: `"3 2 1"`

Expected printed output (verified):

```text

```

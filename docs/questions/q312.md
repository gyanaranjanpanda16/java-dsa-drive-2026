# Q312 — Count connected components in an undirected graph

**Topic:** Graphs · **Level:** Medium

## Question and contract

Count connected components in an undirected graph. Implement the operation exposed by `int solve(int n,int[][] edges)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(5,new int[][]{{0,1},{1,2},{3,4}})
```

Expected output:

```text
2
```

## How and why the answer works

A traversal from one start reaches exactly its connected component. Once exhausted, every unseen vertex lies in a different component, so counting new traversal starts counts components without overlap.

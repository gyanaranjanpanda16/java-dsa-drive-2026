# Q159 — Match pattern symbols bijectively to words

**Topic:** Strings · **Level:** Easy

## Question and contract

Given a char pattern and an array of word tokens, require one-to-one symbol-to-word mapping with matching lengths.

## Example

Input:abba and[dog,cat,cat,dog].

Expected printed output:

```text
true
```

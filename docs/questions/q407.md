# Q407 — Minimum Grid Path Sum

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Minimum Grid Path Sum` using the operation demonstrated below. Nonempty rectangular int grid; sums must fit long; moves only right/down.

## Demonstration

```java
minimum(new int[][]{{1,3,1},{1,5,1},{4,2,1}})
```

Expected output:

```text
7
```

## How and why

A right/down path has a final move from above or left. Replacing its prefix with the cheaper optimal prefix cannot make it worse, so choosing the smaller predecessor cost is correct.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

# Q249 — Sort a bounded integer range with occurrence counts

**Topic:** Non-comparison sorting · **Level:** Medium

## Problem and accepted inputs

Return a sorted copy. Allow negative ints, but require max-min+1<=1000000 to bound allocated counting storage.

## Example

```java
solve(new int[]{-2,1,-2,0})
```

Expected Java value: `new int[]{-2,-2,0,1}`.

Expected printed output (verified):

```text
[-2, -2, 0, 1]
```

## How, why, and where to use it

Translate each value by the minimum into a nonnegative bucket index. Emitting every bucket in increasing index order reconstructs the sorted multiset. Useful when the value universe is small compared with the input size.

## Worked trace

For[-2,1,-2,0], counts at offsets0,2,3 are2,1,1, producing[-2,-2,0,1].

## Line-by-line reasoning

- `public static int[] solve(int[] input) {` — Sorting by value counts does not require pairwise comparisons.
- `if(input.length==0) return new int[0];` — Empty input has no minimum or maximum to measure.
- `int minimum=input[0],maximum=input[0];` — Establish the bounded universe from actual values.
- `for(int value:input) { minimum=Math.min(minimum,value); maximum=Math.max(maximum,value); }` — Find both range endpoints.
- `long range=(long)maximum-minimum+1; if(range>1000000) throw new IllegalArgumentException("range too large");` — Widen before subtracting and reject excessive allocation.
- `int[] counts=new int[(int)range];` — One bucket stores each possible offset from the minimum.
- `for(int value:input) counts[value-minimum]++;` — The accepted range makes offset arithmetic safe.
- `int[] result=new int[input.length]; int out=0;` — Reserve exactly one slot per original occurrence.
- `for(int offset=0;offset<counts.length;offset++) for(int copy=0;copy<counts[offset];copy++) result[out++]=minimum+offset;` — Increasing buckets yield increasing values.
- `return result;` — Occurrence counts preserve duplicates exactly.

## Complexity and tradeoffs

O(n+R) time and O(n+R) space, where R is the value range; unsuitable for sparse huge ranges.

## Cases to practise

- `solve(new int[]{-2,1,-2,0})` → `new int[]{-2,-2,0,1}`: Negative values use a minimum offset.
- `solve(new int[]{})` → `new int[]{}`: Empty input.
- `solve(new int[]{Integer.MAX_VALUE,Integer.MAX_VALUE})` → `new int[]{Integer.MAX_VALUE,Integer.MAX_VALUE}`: A large absolute value can still have a tiny range.

# Q429 — Interleaving Strings

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Interleaving Strings` using the operation demonstrated below. Use all characters of both non-null sources, preserving order within each; UTF-16 units.

## Demonstration

```java
possible("aabcc","dbbca","aadbbcbcac")
```

Expected output:

```text
true
```

## How and why

The final target unit must come from the next unit of one source available unit. Prefix states capture exactly how much of each source has been consumed while preserving order.

## Walkthrough

For ab and cd, choose a,c,b,d to form acbd; adbc fails because d cannot precede c.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `if(a.length()+b.length()!=target.length()) return false;` — Interleaving uses every unit exactly once.
- `boolean[][] dp=new boolean[a.length()+1][b.length()+1]; dp[0][0]=true;` — Empty prefixes form the empty target prefix.
- `for(int i=0;i<=a.length();i++) for(int j=0;j<=b.length();j++) {` — Each state consumes i units from a and j from b.
- `if(i>0&&a.charAt(i-1)==target.charAt(i+j-1)) dp[i][j]|=dp[i-1][j];` — Take the final target unit from the end of the a prefix.
- `if(j>0&&b.charAt(j-1)==target.charAt(i+j-1)) dp[i][j]|=dp[i][j-1];` — Or take it from the end of the b prefix.
- `return dp[a.length()][b.length()];` — Both complete sources must have been consumed in order.

# Q458 — Minimum Candy Allocation

**Topic:** Greedy and search on answer · **Difficulty:** Hard

## Question and contract

Implement `Minimum Candy Allocation` using the operation demonstrated below. Higher-rated adjacent children need strictly more candy; equal ratings impose no extra relation.

## Demonstration

```java
minimum(new int[]{1,0,2})
```

Expected output:

```text
5
```

## How and why

The left-to-right pass gives the minimum required by ascending runs from the left; the reverse pass gives the analogous right requirement. Each child must meet both, so their maximum is the minimum feasible assignment.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int[] candies=new int[ratings.length]; Arrays.fill(candies,1);` — Every child must receive at least one candy.
- `for(int i=1;i<ratings.length;i++) if(ratings[i]>ratings[i-1]) candies[i]=candies[i-1]+1;` — Satisfy constraints imposed by a lower-rated left neighbor.
- `for(int i=ratings.length-2;i>=0;i--) if(ratings[i]>ratings[i+1]) candies[i]=Math.max(candies[i],candies[i+1]+1);` — Enforce right-neighbor constraints without undoing the left constraints.
- `long total=0; for(int candy:candies) total+=candy;` — Sum the smallest simultaneous per-child lower bounds.
- `return total;` — Taking the maximum of the two directional requirements is necessary and sufficient.

# Q339 — Find vertices whose removal increases component count

**Topic:** Graphs · **Level:** Medium

## Question and contract

Find vertices whose removal increases component count. Implement the operation exposed by `String solve(int n,int[][] edges)`. Simple undirected graph; valid endpoints; no parallel edges; recursion must fit JVM stack.

## Runnable example

```java
solve(4,new int[][]{{0,1},{1,2},{1,3}})
```

Expected output:

```text
[1]
```

## How and why the answer works

For a non-root vertex, a child with low[child]>=entered[v] cannot reconnect above v after v is removed. A DFS root has no ancestor, so it is a cut vertex exactly when it has at least two DFS children.

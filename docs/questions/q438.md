# Q438 — Matrix Chain Multiplication Cost

**Topic:** Dynamic programming · **Difficulty:** Hard

## Question and contract

Implement `Matrix Chain Multiplication Cost` using the operation demonstrated below. Matrix i has dimensions[i] rows and dimensions[i+1] columns; dimensions are positive.

```java

```

Expected output:

```text

```

## How and why

The final multiplication splits the chain into two independently parenthesized intervals. Trying every final split and optimal subintervals covers all parenthesizations.

Use the input domain above when judging whether the state space fits memory and whether arithmetic fits the chosen numeric type. Recursive output-generation problems have an unavoidable cost proportional to their output; avoid using them on unrestricted large inputs.

# Q314 — Find shortest edge-count distances from a source

**Topic:** Graphs · **Level:** Medium

## Question and contract

Find shortest edge-count distances from a source. Implement the operation exposed by `String solve(int n,int[][] edges,int source)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(5,new int[][]{{0,1},{0,2},{1,3},{2,3}},0)
```

Expected output:

```text
[0, 1, 1, 2, -1]
```

## How and why the answer works

If a newly found neighbor had a shorter path, its predecessor on that path would belong to an earlier BFS layer and would already have discovered it. Thus first discovery gives minimum edge count.

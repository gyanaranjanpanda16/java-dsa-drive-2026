## Runnable example

Expected output:

## How and why the answer works

If a newly found neighbor had a shorter path, its predecessor on that path would belong to an earlier BFS layer and would already have discovered it. Thus first discovery gives minimum edge count.

## Walkthrough

BFS from 0 assigns distance 0 to 0, then distance 1 to 1 and 2. Both can reach 3, but its first discovery fixes distance 2. Vertex 4 remains -1 because it is unreachable. BFS distances count edges here and assume every edge has equal cost; weighted edges need a different shortest-path algorithm.

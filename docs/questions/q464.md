# Q464 — Fractional Knapsack

**Topic:** Greedy and search on answer · **Difficulty:** Medium

## Question and contract

Implement `Fractional Knapsack` using the operation demonstrated below. Each item is[weight,value]; fractions allowed, positive int weights, nonnegative values.

## Demonstration

```java
maximum(new int[][]{{10,60},{20,100},{30,120}},50)
```

Expected output:

```text
240.0
```

## How and why

With divisible items, exchanging lower-density selected weight for equal higher-density unselected weight cannot decrease value. Filling by descending density therefore reaches an optimum.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

O(n log n) time and O(n) copied storage.

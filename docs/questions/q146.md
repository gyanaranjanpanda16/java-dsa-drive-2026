# Q146 — Encode runs as character-count pairs

**Topic:** Strings · **Level:** Easy

## Question and contract

Encode runs of lowercase English letters as letter followed by positive decimal count. Empty text encodes to empty text.

## Example

Input: aaabbc.

Expected printed output:

```text
a3b2c1
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

Every maximal equal-character run is found once, and its length equals the difference between its end and start indices.

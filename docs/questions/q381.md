# Q381 — Select the kth lexicographic permutation

**Topic:** Factorial blocks · **Level:** Medium

## Problem and accepted inputs

Return the kth permutation of digits1 through n in lexicographic order. Require1<=n<=9 and1<=k<=n!. Ranking starts at1. Return a string of the digits.

## Example

```java
solve(3,4)
```

Expected Java value: `"231"`.

Expected printed output (verified):

```text
231
```

## How, why, and where to use it

Generating and sorting n! permutations is unnecessary for selecting one rank. With m available digits, each possible first digit begins a block of (m-1)! permutations. Divide the zero-based rank by that block size to choose the next digit, then keep the remainder as the rank inside its block. This is positional ranking with factorial place values, useful for indexing arrangements without enumerating them.

## Worked trace

For n3,k4, convert rank to3. Blocks have size2: rank3 lies in block1, so choose digit2. The remainder is1. With remaining [1,3], blocks have size1, so choose index1, digit3. Only1 remains. The answer is231, the fourth entry after123,132,213.

## Line-by-line reasoning

- `public static String solve(int n,int k) {` — Select directly from factorial-sized blocks.
- `if(n<1||n>9) throw new IllegalArgumentException("1..9 required");` — Keep factorial arithmetic and digit spelling unambiguous.
- `int[] factorial=new int[n+1]; factorial[0]=1;` — The empty suffix has one arrangement.
- `List<Integer> available=new ArrayList<>();` — Maintain remaining digits in lexical order.
- `for(int i=1;i<=n;i++) { factorial[i]=factorial[i-1]*i; available.add(i); }` — Build factorials and the initial candidate list.
- `if(k<1||k>factorial[n]) throw new IllegalArgumentException("rank outside permutations");` — A rank must identify an existing arrangement.
- `StringBuilder answer=new StringBuilder(); int rank=k-1;` — Zero-based ranks make division select the correct block.
- `for(int remaining=n;remaining>0;remaining--) {` — Fix one leading digit per iteration.
- `int block=factorial[remaining-1];` — Every candidate digit owns the same number of suffixes.
- `answer.append(available.remove(rank/block));` — Remove the selected digit so it cannot be reused.
- `rank%=block;` — Continue at the corresponding position within this candidate's suffix block.
- `return answer.toString();` — All n digits have been selected exactly once.

## Complexity and tradeoffs

O(n^2) time because removing a digit shifts the ArrayList, and O(n) storage. Factorials through9! fit int; the bound also keeps each symbol one character.

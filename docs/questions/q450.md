**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Longest Arithmetic Subsequence` using the operation demonstrated below. Integer sequence; return longest ordered subsequence with a constant mathematical difference.

## Demonstration

```java
length(new int[]{3,6,9,12})
```

Expected output:

```text

```

## How and why

An arithmetic subsequence is determined for extension by its final index and common difference. Any earlier endpoint with that difference can be extended; retaining the longest such history is sufficient.

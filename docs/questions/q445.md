# Q445 — Minimum Falling Path Sum

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Minimum Falling Path Sum` using the operation demonstrated below. Nonempty rectangular int grid; move down one row and at most one column sideways.

## Demonstration

```java
minimum(new int[][]{{2,1,3},{6,5,4},{7,8,9}})
```

Expected output:

```text
13
```

## How and why

Every falling path has one of three predecessors for each cell. An optimal prefix to a predecessor can replace any more expensive prefix without changing allowed future moves.

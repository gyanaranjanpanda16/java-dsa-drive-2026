# Q292 — Report the kth largest after every eligible prefix

**Topic:** Heaps · **Level:** Medium

## Question and contract

Report the kth largest after every eligible prefix. Implement the operation exposed by `String solve(int[] stream,int k)`. k positive; duplicates are occurrences; output omits prefixes with fewer than k elements.

## Runnable example

```java
solve(new int[]{4,1,7,2,9},2)
```

Expected output:

```text
[1, 4, 4, 7]
```

## How and why the answer works

Each prefix reuses the previous top-k heap rather than recomputing a rank from scratch. Removing the minimum after overflow preserves exactly the k largest processed occurrences.

## Walkthrough

With k 2 and stream 4,1,7,2,9, no answer exists after only 4. After 1, the two largest are 1,4, giving 1. After 7 they are 4,7, giving 4;2 changes nothing. After 9 they are 7,9, giving 7. The outputs begin only once at least k arrivals have been seen.

## Complexity and tradeoffs

O(n log(k+1)) time; O(k) working storage plus output. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Checks and edge cases

- Boundary changes over time.
- Insufficient arrivals.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `if(k<1) throw new IllegalArgumentException("positive rank required");` — A zero rank has no meaning.
- `PriorityQueue<Integer> heap=new PriorityQueue<>();` — The root is the current kth boundary once k values exist.
- `List<Integer> answers=new ArrayList<>();` — Prefixes shorter than k intentionally produce no answer.
- `for(int value:stream) {` — Update the retained candidates with every arrival.
- `if(heap.size()>k) heap.poll();` — Retain only the k largest occurrences.
- `if(heap.size()==k) answers.add(heap.peek());` — A complete candidate set makes rank k defined.
- `return answers.toString();` — Output follows the order of eligible prefixes.

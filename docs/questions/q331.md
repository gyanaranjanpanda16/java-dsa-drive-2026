# Q331 — Find all-pairs shortest distances

**Topic:** Graphs · **Level:** Medium

## Question and contract

Find all-pairs shortest distances. Implement the operation exposed by `String solve(int n,int[][] edges)`. Directed [from,to,int weight] edges; valid vertices; practical-size inputs with path arithmetic within long; any negative cycle produces the reported marker.

## Runnable example

```java
solve(3,new int[][]{{0,1,3},{1,2,-1},{0,2,8}})
```

Expected output:

```text
[[0, 3, 2], [INF, 0, -1], [INF, INF, 0]]
```

## How and why the answer works

With intermediate vertices restricted to0..k, an optimal route either avoids k or splits into i-to-k and k-to-j routes using earlier intermediates. This recurrence covers all possibilities and yields all shortest distances when no negative cycle exists.

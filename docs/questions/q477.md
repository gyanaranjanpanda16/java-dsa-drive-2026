# Q477 — Recognize a positive power of two

**Topic:** Bit manipulation · **Level:** Easy

## Problem and accepted inputs

Return whether an int is a positive mathematical power of two.

## Example

```java
solve(16)
```

Expected Java value: `true`.

Expected printed output (verified):

```text
true
```

## How, why, and where to use it

A positive power of two has exactly one set bit, so clearing its lowest set bit yields zero. The positivity check excludes zero and the negative sign-bit pattern. Useful for validating power-of-two capacities and alignments.

## Complexity and tradeoffs

O(1) time and space for fixed-width ints.

## Cases to practise

- `solve(16)` → `true`: One positive set bit.
- `solve(0)` → `false`: Zero is not a power of two.
- `solve(Integer.MIN_VALUE)` → `false`: A single sign bit is still a negative number.
- `solve(18)` → `false`: Multiple set bits.

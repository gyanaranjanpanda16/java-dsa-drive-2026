# Q202 — Track the earliest nonrepeating character after each arrival

**Topic:** Stacks, queues, and deques · **Level:** Medium

## Question and contract

Input is lowercase English letters. Return one character per prefix: earliest currently unique letter, or # if none.

## Example

Input:aabc.

Expected printed output:

```text
a#bb
```

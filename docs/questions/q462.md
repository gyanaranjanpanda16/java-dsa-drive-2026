**Topic:** Greedy and search on answer · **Difficulty:** Medium

## Question and contract

Implement `Huffman Weighted Encoding Cost` using the operation demonstrated below. Weighted prefix-code path length; ignore zero-frequency symbols; a single symbol has zero-bit depth in this mathematical model.

## Demonstration

```java
cost(new int[]{5,9,12,13,16,45})
```

Expected output:

```text

```

## How and why

In an optimal prefix tree the two least frequent symbols can be deepest siblings. Merging them reduces the problem while adding exactly their combined weight, yielding an exchange-based optimal greedy recursion.

# Q271 — Find the lowest common ancestor of two existing values

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Find the lowest common ancestor of two existing values. Implement the operation exposed by `int solve(Node root,int a,int b)`. Values are unique and BOTH requested values must exist; existence is a precondition, not fully validated.

## Runnable example

```java
solve(sample(),1,3)
```

Expected output:

```text
2
```

## How and why the answer works

If targets appear in different child subtrees, the current node is their first meeting point. If both lie on one side, pass that side upward. Reaching a target makes it a candidate ancestor of the other.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Search for values 1 and 3. Both lie below node 2, one on each side, so 2 is where their search paths first meet. Return that common ancestor up through root 4. The answer is 2, not 4: an ancestor is lowest when no descendant is also an ancestor of both targets.

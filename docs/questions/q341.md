# Q341 — Decide whether a path visits every vertex exactly once

**Topic:** Graphs · **Level:** Hard

## Question and contract

Decide whether a path visits every vertex exactly once. Implement the operation exposed by `boolean solve(int n,int[][] edges)`. Undirected graph with 0<=n<=18 and valid endpoints; loops are harmless; this exponential algorithm is for small graphs.

## Runnable example

```java
solve(4,new int[][]{{0,1},{1,2},{2,3}})
```

Expected output:

```text
true
```

## How and why the answer works

A state records both the visited set and the endpoint because only those facts affect legal extensions. Inductively each transition appends one new neighbor, and every valid path can be split into its last vertex and a smaller recorded path. This models small itinerary constraints; Java bit masks compactly encode subsets, but the exponential growth restricts practical size.

## Walkthrough

In the chain 0–1–2–3, choose 0, then its unused neighbor 1, then 2, then 3. All four vertices are now on one path, so return true. Backtracking removes a vertex from the current path when a branch fails. This exhaustive existence test is exponential on general graphs, unlike ordinary reachability.

## Complexity and tradeoffs

O(2^V V²) time and O(2^V V) space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Checks and edge cases

- A chain visits all vertices.
- A three-leaf star cannot visit every leaf without repetition.
- Empty graph has an empty path.

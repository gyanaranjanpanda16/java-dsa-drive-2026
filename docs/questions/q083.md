# Q083 — Sort words by length while preserving equal-length order

**Topic:** Java Collections: stable sorting · **Level:** Beginner

## Question and contract

Sort non-null strings by UTF-16 length, retaining original order among equal lengths. List.sort is stable, so an unnecessary alphabetical tie-breaker would change the requested behavior.

Implement `List<String> solve(List<String> input)`. The examples below define concrete accepted inputs and expected answers. Unless stated otherwise, reference inputs must be non-null; unsupported input violates the method's contract. Read the validation and comments in the source for additional restrictions.

## Example and answer

Input arguments: `List.of("bb","a","cc","ddd")`

Expected Java value: `List.of("a","bb","cc","ddd")`

Expected printed output (verified):

```text
[a, bb, cc, ddd]
```

## How and why the answer works

Sort non-null strings by UTF-16 length, retaining original order among equal lengths. List.sort is stable, so an unnecessary alphabetical tie-breaker would change the requested behavior.

Follow the state in this order for the sample input; each explanation corresponds to a line in the solution:

- `List<String> ordered = new ArrayList<>(input);` — Preserve encounter order before the stable sort begins.
- `ordered.sort(Comparator.comparingInt(String::length));` — Compare only length so stability determines the order of ties.
- `return ordered;` — Equal-length words remain in their original relative order.

## Cost and alternatives

O(n log n) comparisons and O(n) copy/sorting space; String.length is O(1). Choose this approach when the stated operations and input constraints match the problem. Before reading the code, write a small manual example and identify the work that would otherwise be repeated.

# Q153 — Find a shortest substring covering required characters

**Topic:** Strings · **Level:** Hard

## Question and contract

Return the earliest shortest substring containing all pattern chars with multiplicity; empty pattern or no covering window returns empty text.

## Example

Input: ADOBECODEBANC and ABC.

Expected printed output:

```text
BANC
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

A missing-occurrence counter reaches zero exactly when the window covers all requirements. Shrinking while covered finds the minimal window at each right endpoint.

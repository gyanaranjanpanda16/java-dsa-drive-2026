# Q309 — Reverse every directed graph edge

**Topic:** Graphs · **Level:** Easy

## Question and contract

Reverse every directed graph edge. Implement the operation exposed by `String solve(int n,int[][] edges)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(3,new int[][]{{0,1},{0,2},{1,2}})
```

Expected output:

```text
[[], [0], [0, 1]]
```

## How and why the answer works

Every original path reverses into a path in the transpose because each constituent edge is reversed. This representation is useful for predecessor queries and strongly connected components.

# Q323 — Recolor the connected region containing a chosen pixel

**Topic:** Grid traversal · **Level:** Easy

## Question and contract

Recolor the connected region containing a chosen pixel. Implement the operation exposed by `String solve(int[][] image,int sr,int sc,int replacement)`. Nonempty rectangular image with valid starting coordinates; any int colors; four-way adjacency.

## Runnable example

```java
solve(new int[][]{{1,1},{1,0}},0,0,2)
```

Expected output:

```text
[[2, 2], [2, 0]]
```

## How and why the answer works

Reachability is restricted to pixels with the original seed color. Changing color on enqueue marks discovery; when replacement differs from original, no explicit visited array is needed.

## Walkthrough

Start at(0,0) in [[1,1],[1,0]] and replace its original color 1 with 2. The top-right and bottom-left 1s are connected orthogonally and also change. The bottom-right 0 is a different color and stops expansion, producing [[2,2],[2,0]]. If replacement equals the old color, return early or use separate visited state to avoid repeated traversal.

## Complexity and tradeoffs

O(RC) time and output/queue space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

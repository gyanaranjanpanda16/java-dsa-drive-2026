## How and why the answer works

Every pushed vertex is reachable because it is the source or an outgoing neighbor of a reachable vertex. Conversely, exploring every outgoing edge ensures no reachable target can be missed.

## Walkthrough

To test reachability from 0 to 2, visit 0, then its neighbor 1, then 1's neighbor 2. Finding the target proves true; there is no need to visit every graph vertex. The visited set prevents cycles from restarting the same search forever.

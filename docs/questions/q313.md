# Q313 — Determine whether a directed target is reachable

**Topic:** Graphs · **Level:** Medium

## Question and contract

Determine whether a directed target is reachable. Implement the operation exposed by `boolean solve(int n,int[][] edges,int source,int target)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(4,new int[][]{{0,1},{1,2}},0,2)
```

Expected output:

```text
true
```

## How and why the answer works

Every pushed vertex is reachable because it is the source or an outgoing neighbor of a reachable vertex. Conversely, exploring every outgoing edge ensures no reachable target can be missed.

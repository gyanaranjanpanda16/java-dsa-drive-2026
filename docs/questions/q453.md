## Question and contract

Implement `Assign Cookies` using the operation demonstrated below. Nonnegative greed requirements and cookie sizes; one cookie per child.

## How and why

Giving the smallest adequate cookie to the least-demanding unsatisfied child cannot reduce the number of future matches. Any assignment using a larger cookie can exchange it with this smaller one.

# Q288 — Return the k largest values in descending order

**Topic:** Heaps · **Level:** Medium

## Question and contract

Return the k largest values in descending order. Implement the operation exposed by `String solve(int[] a,int k)`. 0<=k<=length; input is not modified.

## Runnable example

```java
solve(new int[]{4,1,9,3,9},3)
```

Expected output:

```text
[9, 9, 4]
```

## How and why the answer works

A bounded min-heap retains the k largest occurrences. Repeated polling sorts those candidates ascending; reversing only the k outputs avoids sorting the entire input.

# Q484 — Enumerate every submask of a bitmask exactly once

**Topic:** Subset bit operations · **Level:** Medium

## Problem and accepted inputs

For a nonnegative int mask with at most20 set bits, return all submasks in descending numeric order, including zero.

## Example

```java
solve(5)
```

Expected Java value: `List.of(5,4,1,0)`.

Expected printed output (verified):

```text
[5, 4, 1, 0]
```

## How, why, and where to use it

Subtracting one and ANDing with mask jumps to the next smaller subset using only allowed bits. Stop explicitly at zero before the subtraction would cycle back. Useful for subset DP and exhaustive choices over a small active feature set.

## Worked trace

Mask5 is101; its submasks are101,100,001,000, or[5,4,1,0].

## Line-by-line reasoning

- `public static List<Integer> solve(int mask) {` — Treat only set positions of mask as selectable elements.
- `if(mask<0||Integer.bitCount(mask)>20) throw new IllegalArgumentException("small nonnegative mask required");` — Bound exponential output and exclude a signed ordering ambiguity.
- `List<Integer> result=new ArrayList<>(); int subset=mask;` — The full mask is the greatest possible subset.
- `while(true) {` — Include the zero subset exactly once before stopping.
- `result.add(subset); if(subset==0) break;` — Without this guard, the next step would restart at mask.
- `subset=(subset-1)&mask;` — Move to the next lower selection that uses only allowed bits.
- `return result;` — Each possible subset appears once in strictly decreasing order.

## Complexity and tradeoffs

O(2^b) time and output space for b set bits.

## Cases to practise

- `solve(5)` → `List.of(5,4,1,0)`: Nonadjacent allowed bit positions.
- `solve(0)` → `List.of(0)`: Zero has exactly one submask.
- `solve(1)` → `List.of(1,0)`: One available feature.

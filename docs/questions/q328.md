# Q328 — Infer an alphabet order from sorted words

**Topic:** Topological ordering · **Level:** Hard

## Question and contract

Infer an alphabet order from sorted words. Implement the operation exposed by `String solve(String[] words)`. Non-null words; UTF-16 char symbols; returns one deterministic valid alphabet or INVALID.

## Runnable example

```java
solve(new String[]{"wrt","wrf","er","ett","rftt"})
```

Expected output:

```text
wertf
```

## How and why the answer works

The first different characters in adjacent lexicographically sorted words determine a directed precedence edge. A topological order satisfies all such constraints; a prefix violation or cycle proves no alphabet can explain the ordering.

## Walkthrough

Compare adjacent words wrt/wrf to get t before f; wrf/er gives w before e; er/ett gives r before t; ett/rftt gives e before r. Together these force w→e→r→t→f, yielding wertf. Only the first differing character in each pair establishes an ordering rule.

## Complexity and tradeoffs

O(total characters + U log(U+1) + E) time, with ordered-set insertion adding O(E log(U+1)); O(U+E) graph space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `Map<Character,Set<Character>> edges=new TreeMap<>();` — Track only observed symbols and deduplicate ordering constraints.
- `Map<Character,Integer> indegree=new HashMap<>();` — Count distinct required predecessors per symbol.
- `for(String word:words) for(char c:word.toCharArray()) { edges.computeIfAbsent(c,x->new TreeSet<>()); indegree.putIfAbsent(c,0); }` — Even unconstrained symbols must appear in the answer.
- `for(int i=1;i<words.length;i++) {` — Adjacent sorted words provide all necessary first-difference constraints.
- `String a=words[i-1],b=words[i]; int j=0;` — Compare the common prefix before deriving any order.
- `while(j<Math.min(a.length(),b.length())&&a.charAt(j)==b.charAt(j)) j++;` — Equal prefix letters reveal no new ordering.
- `for(char next:edges.get(c)) if(indegree.merge(next,-1,Integer::sum)==0) ready.offer(next);` — Release a symbol after its final predecessor is output.
- `return result.length()==edges.size()?result.toString():"INVALID";` — An unresolved cycle contradicts the claimed sorted input.

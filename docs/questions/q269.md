# Q269 — Sum only the deepest leaves

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

## How and why the answer works

When a deeper leaf appears, shallower candidates become irrelevant and the sum resets. Equal-depth leaves are added, preserving exactly the deepest-leaf total.

## Walkthrough

The levels sum to 4,8,16. Replace the remembered level sum after each complete level; when the queue empties, the last sum 16 belongs to the deepest leaves 1,3,5,7. Adding every level would answer a different question, the total tree sum 28.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `static void visit(Node n,int depth,long[] state) {` — Compare leaf depth against the best depth so far.
- `if(depth>state[0]) { state[0]=depth; state[1]=0; }` — A deeper level replaces all earlier shallower sums.

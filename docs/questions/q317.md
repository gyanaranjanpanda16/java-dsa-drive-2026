# Q317 — Detect a directed cycle using DFS colors

**Topic:** Graphs · **Level:** Medium

## Question and contract

Detect a directed cycle using DFS colors. Implement the operation exposed by `boolean solve(int n,int[][] edges)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(3,new int[][]{{0,1},{1,2},{2,0}})
```

Expected output:

```text
true
```

## How and why the answer works

An edge to an active DFS vertex returns to an ancestor on the current directed path and closes a cycle. An edge to a finished vertex alone is not a cycle, which is why a single visited bit is insufficient.

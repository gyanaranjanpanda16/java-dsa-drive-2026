# Q317 — Detect a directed cycle using DFS colors

**Topic:** Graphs · **Level:** Medium

## Question and contract

## Runnable example

## How and why the answer works

An edge to an active DFS vertex returns to an ancestor on the current directed path and closes a cycle. An edge to a finished vertex alone is not a cycle, which is why a single visited bit is insufficient.

## Walkthrough

For 0→1→2→0, mark 0 active, then 1 active, then 2 active. Edge 2→0 points back to a vertex still on the active recursion path, so a cycle exists. A reference to a fully finished vertex would not prove a directed cycle; the active and finished states must be distinct.

## Complexity and tradeoffs

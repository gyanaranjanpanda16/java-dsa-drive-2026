# Q459 — Task Scheduler With Cooldown

**Topic:** Greedy and search on answer · **Difficulty:** Medium

## Question and contract

Implement `Task Scheduler With Cooldown` using the operation demonstrated below. Tasks may be reordered; each takes one slot; identical uppercase types need cooldown intervening slots.

## Demonstration

```java
minimumSlots("AAABBB",2)
```

Expected output:

```text
8
```

## How and why

Most frequent tasks require maximum-1 separating gaps; tied types occupy the final frame. This spacing lower bound is achievable by filling gaps with other tasks or idles, but cannot be smaller than the total task count.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

## Walkthrough

AAABBB with cooldown2 can run A,B,idle,A,B,idle,A,B in eight slots.

## Complexity and tradeoffs

O(n+26) time and O(26) space.

# Q261 — Check whether every subtree is height-balanced

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Check whether every subtree is height-balanced. Implement the operation exposed by `boolean solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

## How and why the answer works

The helper returns a valid height or -1. Rejecting a child sentinel before combining ensures a balanced ancestor cannot hide an unbalanced descendant.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Leaves return height 1. At nodes 2 and 6, both child heights are 1, so their difference is 0 and both return 2. At root 4 the heights are 2 and 2, so it is balanced. Every node must pass this check; checking only the root could miss an unbalanced subtree deeper down.

## Complexity and tradeoffs

O(n) time; O(h) recursion. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `static int height(Node n) {` — Compute height and balance together to avoid rescanning subtrees.
- `if(n==null) return 0;` — Empty subtrees have equal zero heights.
- `if(left<0||right<0||Math.abs(left-right)>1) return -1;` — Any local or inherited violation invalidates this subtree.
- `return 1+Math.max(left,right);` — Only balanced subtrees return a real height.
- `return height(root)>=0;` — A negative sentinel propagates any unbalanced descendant.

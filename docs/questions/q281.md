# Q281 — Check whether a binary tree is complete

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Check whether a binary tree is complete. Implement the operation exposed by `boolean solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
true
```

## How and why the answer works

Completeness means occupied level-order positions form a prefix. Recording the first gap and rejecting any later child is exactly this definition.

# Q281 — Check whether a binary tree is complete

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Check whether a binary tree is complete. Implement the operation exposed by `boolean solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:


## How and why the answer works

Completeness means occupied level-order positions form a prefix. Recording the first gap and rejecting any later child is exactly this definition.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

A breadth-first scan encounters all seven real nodes before encountering missing child slots. Once the first null slot appears, any later real node would create a gap and violate completeness. None appears in the sample, so the answer is true. Completeness concerns left-filled positions, not whether every level has equal values.

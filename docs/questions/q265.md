# Q265 — Compute the sum at every depth

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Compute the sum at every depth. Implement the operation exposed by `String solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
[4, 8, 16]
```

## How and why the answer works

Depth uniquely partitions the nodes. Accumulating each node into its depth bucket yields each level sum regardless of traversal order.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Initialize a new sum for each queue level. The root level sums to 4; the next sums 2+6=8; the leaf level sums 1+3+5+7=16. Resetting the sum between levels produces [4,8,16], instead of cumulative totals [4,12,28].

## Complexity and tradeoffs

O(n) time; O(h) recursion plus O(h) sums. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `static void add(Node n,int depth,List<Long> sums) {` — Carry depth explicitly through the recursion.
- `if(depth==sums.size()) sums.add(0L);` — Allocate an accumulator the first time a depth appears.
- `sums.set(depth,sums.get(depth)+n.value);` — Use long addition for aggregate values.
- `add(n.left,depth+1,sums); add(n.right,depth+1,sums);` — Both child subtrees belong one level lower.
- `add(root,0,sums);` — Each node contributes to exactly its own depth.
- `return sums.toString();` — Preserve the level order for a dashboard-like summary.

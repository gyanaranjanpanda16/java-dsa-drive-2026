# Q147 — Encode ASCII spaces as percent-20

**Topic:** Strings · **Level:** Easy

## Question and contract

Replace each ASCII space with %20 while preserving every other UTF-16 character.

## Example

Input: Mr John Smith.

Expected printed output:

```text
Mr%20John%20Smith
```

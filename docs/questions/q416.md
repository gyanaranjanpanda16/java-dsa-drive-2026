# Q416 — Minimum Subset Sum Difference

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Minimum Subset Sum Difference` using the operation demonstrated below. Nonnegative integers; total/2 table must fit memory.

## Demonstration

```java
minimum(new int[]{1,6,11,5})
```

Expected output:

```text
1
```

## How and why

Complementary subset sums s and total-s differ by total-2s when s is the smaller. Maximizing a reachable s not exceeding half minimizes that expression.

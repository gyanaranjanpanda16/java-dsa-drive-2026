# Q435 — Count Word Segmentations

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Count Word Segmentations` using the operation demonstrated below. Dictionary is a set of nonempty words; word reuse is allowed.

## Demonstration

```java
count("aaaa",Set.of("a","aa"))
```

Expected output:

```text
5
```

## How and why

Distinct final boundaries partition the segmentation set. Adding the counts of their preceding prefixes yields every segmentation exactly once.

## Walkthrough

aaaa can split as a+a+a+a, aa+a+a, a+aa+a, a+a+aa, or aa+aa: five ways.

## Complexity and tradeoffs

O(n³) worst-case time with Java substring creation/hashing and O(n) DP space; count overflow throws.

# Q255 — Alternate direction on successive tree levels

**Topic:** Trees and BST · **Level:** Beginner

## Question and contract

Alternate direction on successive tree levels. Implement the operation exposed by `String solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
[[4], [6, 2], [1, 3, 5, 7]]
```

## How and why the answer works

Ordinary BFS already groups nodes by depth. Reversing every other completed level changes output orientation while leaving the breadth-first invariant intact.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

The tree levels are [4], [2,6], and [1,3,5,7]. Keep the first level, reverse the second output to [6,2], and keep the third. Traversal still discovers children in a consistent order; alternating the displayed direction produces [[4],[6,2],[1,3,5,7]] without losing or duplicating nodes.

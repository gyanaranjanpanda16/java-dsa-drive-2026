# Q141 — Count characters in sorted order

**Topic:** Strings · **Level:** Easy

## Question and contract

Return a sorted map of UTF-16 chars to occurrence counts.

## Example

Input: `banana`.

Expected printed output:

```text
{a=3, b=1, n=2}
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

A map associates each distinct char with the number of scanned occurrences; merging one on each visit maintains this counting invariant.

## Walkthrough

The b entry becomes1, a is incremented three times, and n twice; TreeMap traversal orders a,b,n.

## Complexity and edge cases

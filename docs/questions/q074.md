# Q074 — Insert one interval into a disjoint sorted interval list

**Topic:** Interval scans · **Level:** Medium

## Question and contract

Given valid closed intervals already sorted by start and pairwise disjoint, insert one valid interval and merge any overlaps. Partition the input into before, overlapping, and after regions; the original interval preconditions are assumed.

Implement `int[][] solve(int[][] a, int[] added)`. The examples below define concrete accepted inputs and expected answers. Unless stated otherwise, reference inputs must be non-null; unsupported input violates the method's contract. Read the validation and comments in the source for additional restrictions.

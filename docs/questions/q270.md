# Q270 — Find the maximum sum of a nonempty tree path

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Find the maximum sum of a nonempty tree path. Implement the operation exposed by `long solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java

```


## How and why the answer works

A path turning at a node may use both positive child gains. A path returned to the parent may use only one branch, otherwise it would fork. Discard negative extensions because they decrease the sum.

# Q270 — Find the maximum sum of a nonempty tree path

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Find the maximum sum of a nonempty tree path. Implement the operation exposed by `long solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text

```

## How and why the answer works

A path turning at a node may use both positive child gains. A path returned to the parent may use only one branch, otherwise it would fork. Discard negative extensions because they decrease the sum.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

From node 2, the best upward extension uses child 3 and contributes 2+3=5. From node 6, the best upward extension uses 7 and contributes 6+7=13. Root 4 can join both extensions for 5+4+13=22, the path 3→2→4→6→7. Only one child branch may extend upward to a parent, otherwise the result would fork rather than remain a path.

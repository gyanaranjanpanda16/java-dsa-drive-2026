# Q370 — Maintain range greatest common divisors under assignments

**Topic:** Associative segment aggregates · **Level:** Medium

## Problem and accepted inputs

Operations[0,index,value] assign an int;[1,left,right] return the nonnegative gcd of that valid half-open range. The empty-range gcd is0.

## Example

```java
solve(new int[]{12,18,30},new int[][]{{1,0,3},{0,1,15},{1,0,3}})
```

Expected Java value: `List.of(6L,3L)`.

Expected printed output (verified):

```text
[6, 3]
```

## How, why, and where to use it

Gcd is associative and gcd(0,x)=|x|, so the same disjoint-segment decomposition works with gcd instead of sum or minimum. Widening before abs handles Integer.MIN_VALUE. Useful for querying shared divisibility constraints in changing data.

## Worked trace

For[12,18,30], full gcd is6; changing18 to15 makes the full gcd3.

## Line-by-line reasoning

- `private static long gcd(long a,long b) {` — Inputs to this helper are already nonnegative magnitudes.
- `while(b!=0) { long remainder=a%b; a=b; b=remainder; }` — Euclid preserves gcd while decreasing the second argument.
- `return a;` — gcd(0,0) naturally returns the empty-aggregate identity zero.
- `public static List<Long> solve(int[] initial,int[][] operations) {` — Generalize segment-tree aggregation beyond addition.
- `int n=initial.length; long[] tree=new long[2*n];` — Long can hold the magnitude of every int.
- `for(int i=0;i<n;i++) tree[n+i]=Math.abs((long)initial[i]);` — Convert signed values to safe nonnegative magnitudes.
- `for(int i=n-1;i>0;i--) tree[i]=gcd(tree[2*i],tree[2*i+1]);` — Parent gcd combines its disjoint children.
- `List<Long> result=new ArrayList<>();` — Preserve the sequence of aggregate queries.
- `for(int[] op:operations) {` — Valid bounds are assumed by contract.
- `if(op[0]==0) { int at=n+op[1]; tree[at]=Math.abs((long)op[2]); while((at/=2)>0) tree[at]=gcd(tree[2*at],tree[2*at+1]); }` — Assignment affects only a leaf and its ancestors.
- `else if(op[0]==1) {` — Query any half-open range, including the empty one.
- `int left=n+op[1],right=n+op[2]; long answer=0;` — Zero is neutral for gcd combination.
- `while(left<right) { if((left&1)==1) answer=gcd(answer,tree[left++]); if((right&1)==1) answer=gcd(answer,tree[--right]); left/=2; right/=2; }` — Fold disjoint covered nodes into the aggregate.
- `result.add(answer);` — Negative source signs do not affect gcd magnitude.
- `} else throw new IllegalArgumentException("unknown operation");` — Only assignments and gcd queries are supported.
- `return result;` — The same tree shape supports a different associative operation.

## Complexity and tradeoffs

O((n+q log(n+1))*log C) time for bounded Euclidean gcd work, O(n) space.

# Q282 — Find minimum root-to-leaf depth in nodes

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Find minimum root-to-leaf depth in nodes. Implement the operation exposed by `int solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
3
```

## How and why the answer works

The minimum must range over real leaf paths. Treating a missing child as a depth-zero candidate would incorrectly stop early at one-child nodes.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Breadth-first traversal sees root 4 at depth 1, nodes 2 and 6 at depth 2, and the first leaf 1 at depth 3. Stop at the first leaf because no later queue entry can be shallower. The answer is 3 nodes. A missing child is not a root-to-leaf path and must not force the minimum depth to zero.

## Complexity and tradeoffs

O(n) time; O(h) recursion. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `if(root==null) return 0;` — No path exists in an empty tree.
- `if(root.left==null) return 1+solve(root.right);` — A missing child is not a terminating leaf path.
- `if(root.right==null) return 1+solve(root.left);` — The existing branch must be followed.
- `return 1+Math.min(solve(root.left),solve(root.right));` — With both branches present, choose the nearer leaf.

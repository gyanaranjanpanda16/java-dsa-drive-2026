# Q487 — Factor a positive integer into prime factors

**Topic:** Trial division · **Level:** Easy

## Problem and accepted inputs

Return the prime factors of positive int n in ascending order with multiplicity. The factorization of1 is an empty list.

## Example

```java
solve(72)
```

Expected Java value: `List.of(2,2,2,3,3)`.

Expected printed output (verified):

```text
[2, 2, 2, 3, 3]
```

## How, why, and where to use it

Repeatedly remove a factor before advancing the candidate. Once candidate² exceeds the remaining value, any remaining factor must be prime, otherwise a smaller factor would already have been found. Useful for divisor analysis and multiplicative arithmetic.

## Worked trace

72 divides by2 three times to leave9, then by3 twice, giving[2,2,2,3,3].

## Line-by-line reasoning

- `public static List<Integer> solve(int n) {` — Factor a positive integer without treating1 as prime.
- `if(n<1) throw new IllegalArgumentException("positive input required");` — Zero and negatives need different factorization conventions.
- `List<Integer> factors=new ArrayList<>();` — Every division emits one prime occurrence.
- `for(int candidate=2;candidate<=n/candidate;candidate++) {` — Division expresses the square-root bound without multiplication overflow.
- `while(n%candidate==0) { factors.add(candidate); n/=candidate; }` — Strip all copies before trying the next candidate.
- `if(n>1) factors.add(n);` — A surviving value larger than1 has no smaller factor and is prime.
- `return factors;` — Candidate order guarantees ascending factors.

## Complexity and tradeoffs

O(sqrt(n)) worst-case trial divisions and O(log n) output factors.

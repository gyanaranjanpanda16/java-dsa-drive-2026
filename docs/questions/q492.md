# Q492 — Compute a huge-index Fibonacci residue with matrix powers

**Topic:** Matrix exponentiation · **Level:** Medium

## Problem and accepted inputs

Return F(n) modulo a positive int modulus for nonnegative long n, with F(0)=0 and F(1)=1.

## Example

```java
solve(10,1000)
```

Expected Java value: `55L`.

Expected printed output (verified):

```text
55
```

## How, why, and where to use it

The transition matrix[[1,1],[1,0]] maps consecutive Fibonacci states to the next state. Its nth power contains F(n) in the upper-right position. Binary exponentiation composes many transitions in logarithmically many matrix multiplications. Useful for fixed-size linear recurrences.

## Worked trace

For n=10, the transition matrix raised to10 has upper-right entry55; reducing after each multiplication preserves the residue.

## Complexity and tradeoffs

O(log(n+1)) fixed2x2 matrix operations and O(1) live matrix space.

# Q268 — Sum numbers represented by root-to-leaf digits

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Sum numbers represented by root-to-leaf digits. Implement the operation exposed by `long solve(Node root)`. Every value is a decimal digit 0–9. Arithmetic overflow throws ArithmeticException.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
1776
```

## How and why the answer works

Appending decimal digit d to prefix p produces 10p+d. Each leaf closes one number; summing disjoint child results counts every root-to-leaf number once.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Treat node values as digits. The path 4→2→1 evolves as 4, then 4*10+2=42, then 42*10+1=421. The four root-to-leaf numbers are 421,423,465,467, whose total is 1776. Multiplying the running prefix by 10 shifts its existing digits before appending the next one.

## Complexity and tradeoffs

O(n) time; O(h) recursion. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

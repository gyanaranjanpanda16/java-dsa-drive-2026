# Q493 — Sample k stream values uniformly with bounded storage

**Topic:** Randomized streaming · **Level:** Medium

## Problem and accepted inputs

For0<=k<=input.length, return a size-k reservoir sample using java.util.Random with the supplied seed. Order is reservoir-slot order; sampling is over positions, so equal values remain distinct occurrences.

## Example

```java
solve(new int[]{1,2,3,4,5},2,0)
```

Expected Java value: `new int[]{3,2}`.

Expected printed output (verified):

```text
[3, 2]
```

## How, why, and where to use it

After seeing i+1 elements, select a uniform integer in0..i. If it is below k, replace that reservoir slot. A new item enters with probability k/(i+1), and each older item survives with exactly the probability needed to maintain that same inclusion chance. Useful when a stream length is unknown ahead of time.

## Worked trace

With seed0, input[1,2,3,4,5] and k=2, the documented Java Random draws replace the first slot with3 and leave the final reservoir[3,2].

## Line-by-line reasoning

- `public static int[] solve(int[] input,int k,long seed) {` — Sample positions without keeping an additional copy of the entire stream.
- `if(k<0||k>input.length) throw new IllegalArgumentException("invalid sample size");` — A fixed-size sample cannot exceed observed input length.
- `int[] reservoir=Arrays.copyOf(input,k); Random random=new Random(seed);` — The first k observations initially occupy the reservoir.
- `for(int i=k;i<input.length;i++) {` — Incorporate one later observation using a uniform replacement decision.
- `int slot=random.nextInt(i+1);` — Each of the i+1 observed positions is equally likely to receive this draw.
- `if(slot<k) reservoir[slot]=input[i];` — Only k of those outcomes replace a retained sample position.
- `return reservoir;` — Uniform inclusion does not imply sorted output or cryptographic unpredictability.

## Complexity and tradeoffs

O(n) time and O(k) output/storage; the fixed seed is for reproducible teaching, not security.

## Cases to practise

- `solve(new int[]{1,2,3,4,5},2,0)` → `new int[]{3,2}`: A reproducible nontrivial replacement sequence.
- `solve(new int[]{1,2},0,9)` → `new int[]{}`: A zero-size reservoir stays empty.
- `solve(new int[]{4,4,7},3,5)` → `new int[]{4,4,7}`: Sampling every position retains duplicates.

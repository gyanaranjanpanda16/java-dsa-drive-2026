# Q476 — Count one bits by clearing the lowest set bit

**Topic:** Bit manipulation · **Level:** Easy

## Problem and accepted inputs

Return the number of one bits in the32-bit two-complement representation of any int, including negatives.

## Example

```java
solve(12)
```

Expected Java value: `2`.

Expected printed output (verified):

```text
2
```

## How, why, and where to use it

Subtracting one flips the lowest set bit and all lower zero bits; AND with the original clears exactly that one bit. Repeating until zero counts set bits directly. Useful for bitmask cardinality and packed feature counts.

## Worked trace

12 is binary1100:12&11 gives8, then8&7 gives0, so there are2 set bits.

## Line-by-line reasoning

- `public static int solve(int value) {` — Interpret all32 bits, not the decimal sign.
- `int count=0;` — No set bits have been removed initially.
- `while(value!=0) { value&=value-1; count++; }` — Clear exactly one set bit even when signed arithmetic wraps.
- `return count;` — Zero remaining bits means every original one bit was counted.

## Complexity and tradeoffs

O(number of set bits), at most32 iterations, and O(1) space.

## Cases to practise

- `solve(12)` → `2`: Two separated high bits.
- `solve(-1)` → `32`: Every bit is set in two-complement negative one.
- `solve(0)` → `0`: Zero has no set bits.

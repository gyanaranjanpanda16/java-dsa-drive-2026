# Q469 — Minimum Banana Eating Speed

**Topic:** Greedy and search on answer · **Difficulty:** Medium

## Question and contract

Implement `Minimum Banana Eating Speed` using the operation demonstrated below. One pile per hour, at most speed bananas from that pile; nonnegative pile sizes and hour budget.

## Demonstration

```java
minimum(new int[]{3,6,7,11},8)
```

Expected output:

```text
4
```

## How and why

The total rounded-up processing time is nonincreasing with speed. Binary search therefore finds the first speed meeting the hour budget between a known lower bound and a feasible upper bound.

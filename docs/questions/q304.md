# Q304 — Minimize refueling stops to reach a target

**Topic:** Greedy max-heap · **Level:** Hard

## Question and contract

Minimize refueling stops to reach a target. Implement the operation exposed by `int solve(int target,int startFuel,int[][] stations)`. Nonnegative target and start fuel; stations sorted by position with nonnegative positions/fuel; fuel consumption is one unit per distance, tank capacity unlimited.

## Runnable example

```java
solve(100,10,new int[][]{{10,60},{20,30},{30,30},{60,40}})
```

Expected output:

```text
2
```

## How and why the answer works

Delay committing to a refill until progress requires it. Among previously reachable stations, choosing the largest supply gives at least as much future reach as any other single stop; exchanging another choice for this one cannot hurt feasibility.

## Walkthrough

Start with fuel 10 toward target 100. Reach station 10 and, when more reach is needed, choose its 60 fuel, extending reachable distance to 70. Stations 20,30,60 are now available; choosing the largest remaining fuel 40 from station 60 extends reach to 110. Two stops suffice. The heap represents stations already passed, so choosing one retroactively is a planning decision, not physical backward travel.

## Complexity and tradeoffs

O(n log(n+1)) time and O(n) heap space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `long reachable=startFuel;` — Track the farthest position attainable with fuel already chosen.
- `PriorityQueue<Integer> available=new PriorityQueue<>(Comparator.reverseOrder());` — The largest passed fuel supply extends reach most per stop.
- `int next=0,stops=0;` — Stations are consumed once in positional order.
- `while(reachable<target) {` — Stop as soon as the target is reachable without another refill.
- `while(next<stations.length&&stations[next][0]<=reachable) available.offer(stations[next++][1]);` — Every passed station becomes an available earlier stopping choice.
- `if(available.isEmpty()) return -1;` — No reachable supply can extend the journey.
- `stops++;` — Taking one supply corresponds to one actual refueling stop.
- `return stops;` — The greedy reach dominates any plan with fewer chosen supplies at each step.

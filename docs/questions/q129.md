# Q129 — Count ASCII vowels and consonants

**Topic:** Strings · **Level:** Beginner

## Question and contract

Return [vowels, consonants] for ASCII English letters, ignoring other characters and case.

## Example

Input: `Java 17!`.

Expected printed output:

```text
[2, 2]
```

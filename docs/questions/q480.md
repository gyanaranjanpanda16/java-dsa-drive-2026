# Q480 — Recover a singleton when every other value occurs three times

**Topic:** Bit-state counters · **Level:** Medium

## Problem and accepted inputs

One int occurs once and all other distinct ints occur exactly three times. Return the singleton.

## Example

```java
solve(new int[]{2,2,3,2})
```

Expected Java value: `3`.

Expected printed output (verified):

```text
3
```

## How, why, and where to use it

Track each bit count modulo3 in two bitmasks. The state cycles absent→seen once→seen twice→absent. Bits from triples vanish, leaving the singleton mask, including its sign bit. This generalizes XOR cancellation beyond pairs.

## Worked trace

For[2,2,3,2], the bits belonging to three copies of2 reset, leaving the bits of3.

## Line-by-line reasoning

- `public static int solve(int[] a) {` — Process all32 independent bit counters in parallel.
- `int once=0,twice=0;` — No bit has yet appeared once or twice modulo three.
- `for(int value:a) {` — Update the modulo-three state for each incoming bit pattern.
- `once=(once^value)&~twice;` — Toggle once bits unless the old twice state requires this occurrence to reset them.
- `twice=(twice^value)&~once;` — Use the new once mask to exclude bits that have just entered their first-count state.
- `return once;` — Triples reset to zero; only the promised singleton remains in the once state.

## Complexity and tradeoffs

O(n) time and O(1) space for32 simultaneous modulo-three counters.

## Cases to practise

- `solve(new int[]{2,2,3,2})` → `3`: Triple bits cancel modulo three.
- `solve(new int[]{-7,5,5,5})` → `-7`: Negative singleton sign bits survive.
- `solve(new int[]{Integer.MIN_VALUE,0,0,0})` → `Integer.MIN_VALUE`: A lone sign bit is recovered exactly.

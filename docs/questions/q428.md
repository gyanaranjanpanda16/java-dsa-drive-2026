# Q428 — Minimum Palindrome Partition Cuts

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Minimum Palindrome Partition Cuts` using the operation demonstrated below. Cut a UTF-16 string into nonempty palindromic blocks; return the number of cuts.

## Demonstration

```java
cuts("aab")
```

Expected output:

```text
1
```

## How and why

Any valid partition has a final palindromic block. Choosing its start and combining it with the best partition of the preceding prefix explores all optimal possibilities.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

## Walkthrough

aab is partitioned aa|b with one cut, better than a|a|b.

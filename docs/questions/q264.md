# Q264 — Return the right view of a binary tree

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Return the right view of a binary tree. Implement the operation exposed by `String solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
[4, 6, 7]
```

## How and why the answer works

Visit the right child first. The first node reached at any depth is the extreme visible node on that side, so later nodes at that depth cannot replace it.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

The rightmost entries of levels [4], [2,6], and [1,3,5,7] are 4,6,7. Record only the last node processed at each level. Looking only at repeated right-child links would fail when a deeper visible node lies in a left subtree.

## Complexity and tradeoffs

O(n) time; O(h) recursion and output. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `static void visit(Node n,int depth,List<Integer> view) {` — Depth identifies which view position this node could fill.
- `if(n==null) return;` — Missing branches expose no new value.
- `if(depth==view.size()) view.add(n.value);` — Append only the first visit to an unseen depth.
- `visit(n.right,depth+1,view); visit(n.left,depth+1,view);` — Preferred side wins ties at the same depth.
- `List<Integer> view=new ArrayList<>();` — Store the first visible value at each depth.
- `return view.toString();` — Values are reported from shallowest to deepest.

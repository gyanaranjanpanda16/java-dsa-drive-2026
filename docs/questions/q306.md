# Q306 — Build directed adjacency lists from an edge list

**Topic:** Graphs · **Level:** Beginner

## Question and contract

Build directed adjacency lists from an edge list. Implement the operation exposed by `String solve(int n,int[][] edges)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(4,new int[][]{{0,1},{0,2},{2,3}})
```

Expected output:

```text
[[1, 2], [], [3], []]
```

## How and why the answer works

An edge list names connections globally; adjacency lists group them by their source. Every directed edge contributes exactly one neighbor entry, preserving direction and isolated vertices.

# Q422 — Longest Common Substring Length

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Longest Common Substring Length` using the operation demonstrated below. Non-null strings; exact UTF-16-unit substring comparison.

## Demonstration

```java
length("xabcdz","yabcw")
```

Expected output:

```text
3
```

## How and why

A shared contiguous block ending at a pair of positions extends only when those units match. Taking the maximum of all endpoint states finds every possible block.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int[][] suffix=new int[a.length()+1][b.length()+1]; int best=0;` — Each state counts matching contiguous suffixes ending at these positions.
- `for(int j=1;j<=b.length();j++) {` — Consider the corresponding second-string endpoint independently.
- `if(a.charAt(i-1)==b.charAt(j-1)) suffix[i][j]=1+suffix[i-1][j-1];` — Equal units extend the immediately preceding matching suffix.
- `best=Math.max(best,suffix[i][j]);` — A mismatch leaves zero, enforcing contiguity rather than skipping characters.
- `return best;` — The answer may end anywhere, not just at both final positions.

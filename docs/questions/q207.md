# Q207 — Repeatedly remove adjacent equal character pairs

**Topic:** Stacks, queues, and deques · **Level:** Easy

## Question and contract

Delete adjacent equal UTF-16 char pairs until none remain; return the unique stack-reduction result.

## Example

Input:abbaca.

Expected printed output:

```text
ca
```

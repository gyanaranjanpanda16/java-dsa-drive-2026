# Q333 — Find a minimum spanning-tree weight using sorted edges

**Topic:** Graphs · **Level:** Medium

## Question and contract

Find a minimum spanning-tree weight using sorted edges. Implement the operation exposed by `String solve(int n,int[][] edges)`. Undirected [u,v,int weight] edges with valid vertices; parallel edges and self-loops allowed; returns DISCONNECTED if no spanning tree exists.

## Runnable example

```java
solve(3,new int[][]{{0,1,4},{1,2,1},{0,2,2}})
```

Expected output:

```text
3
```

## How and why the answer works

Each accepted edge is a minimum remaining edge crossing between two forest components. The cut property permits adding it to some optimal spanning tree, while union-find rejects precisely the edges that would close a cycle.

# Q334 — Process union and connectivity queries online

**Topic:** Graphs · **Level:** Medium

## Question and contract

Process union and connectivity queries online. Implement the operation exposed by `String solve(int n,int[][] operations)`. Operation rows [0,u,v] add connectivity and [1,u,v] query it; valid vertex IDs; deletions are not supported.

## Runnable example

```java
solve(3,new int[][]{{1,0,2},{0,0,1},{0,1,2},{1,0,2}})
```

Expected output:

```text
[false, true]
```

## How and why the answer works

Union-find maintains a partition whose blocks are exactly the connected components after every insertion. Union merges the required blocks, and representative equality answers whether two vertices belong to the same block.

## Walkthrough

Initially 0,1,2 each belong to separate sets, so asking whether 0 and 2 are connected returns false. Union 0 with 1, then union 1 with 2. Now root lookups for 0 and 2 agree, so the final query returns true. A representative identifies membership; its numeric value is not itself the set's meaning.

## Complexity and tradeoffs

O(V+Q α(V)) amortized time; O(V) DSU plus query output. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

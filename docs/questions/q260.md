# Q260 — Find the maximum tree value

**Topic:** Trees and BST · **Level:** Beginner

## Question and contract

Find the maximum tree value. Implement the operation exposed by `int solve(Node root)`. A null root is empty. Height counts nodes; empty maximum is Integer.MIN_VALUE, which may also be a real value.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
7
```

## How and why the answer works

Every value is either the root or inside one child subtree; maximum combines all three candidates.

# Q260 — Find the maximum tree value

**Topic:** Trees and BST · **Level:** Beginner

## Question and contract

Find the maximum tree value. Implement the operation exposed by `int solve(Node root)`. A null root is empty. Height counts nodes; empty maximum is Integer.MIN_VALUE, which may also be a real value.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
7
```

## How and why the answer works

Every value is either the root or inside one child subtree; maximum combines all three candidates.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Compare each node with the maxima returned by its nonempty children. The left subtree maximum is 3, the right subtree maximum is 7, and comparing these with root 4 gives 7. Zero is not a safe default for an arbitrary all-negative tree; consult the source's empty-tree contract and sentinel handling.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `if(root==null) return Integer.MIN_VALUE;` — Supply the identity for an empty subtree.
- `return Math.max(root.value,Math.max(solve(root.left),solve(root.right)));` — Combine the root with independent child answers.

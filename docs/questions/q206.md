# Q206 — Resolve one-dimensional asteroid collisions

**Topic:** Stacks, queues, and deques · **Level:** Medium

## Question and contract

Nonzero signed ints represent size and direction. Positive moves right,negative left; equal speeds. Return surviving values in order.

## Example

Input:[10,2,-5].

Expected printed output:

```text
[10]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

Only an incoming left-mover can collide with prior right-movers. A stack holds the already stable prefix; repeated collisions remove exactly the obstacles encountered before the incoming object survives or is destroyed.

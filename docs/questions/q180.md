# Q180 — Check whether list values form a palindrome

**Topic:** Linked lists · **Level:** Easy

## Question and contract

Return value symmetry of an acyclic list without changing its links; empty is a palindrome.

## Example

The demonstration constructs a fresh linked list with `list(...)`.

Expected printed output:

# Q400 — Josephus Survivor

**Topic:** Recursion and backtracking · **Difficulty:** Medium

## Question and contract

Implement `Josephus Survivor` using the operation demonstrated below. Return a zero-based survivor index for positive n and step; keep n small enough for recursion.

## Demonstration

```java
survivor(5,2)
```

Expected printed output (verified):

```text
2
```

## How and why

After removing one person, the reduced circle has the same problem with n-1 participants and rotated labels. Adding step maps its survivor back to the original labels.

- `if(n<1||step<1) throw new IllegalArgumentException("Positive n and step");` — A nonempty circle and positive elimination interval are required.

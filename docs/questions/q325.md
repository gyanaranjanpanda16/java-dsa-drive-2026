**Topic:** Multi-source BFS · **Level:** Medium

## Question and contract

Find the time until all reachable fresh oranges rot. Implement the operation exposed by `int solve(int[][] grid)`. Rectangular grid using0=empty,1=fresh,2=rotten; four-way spread; input preserved.

## Runnable example

```java
solve(new int[][]{{2,1,1},{1,1,0},{0,1,1}})
```

Expected output:

```text
4
```

## How and why the answer works

BFS begins with every rotten cell, so first arrival at a fresh cell is its earliest infection minute. Counting unconverted cells distinguishes a long but possible spread from an impossible disconnected one.

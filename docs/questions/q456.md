# Q456 — Minimum Forward Jumps

**Topic:** Greedy and search on answer · **Difficulty:** Medium

## Question and contract

Implement `Minimum Forward Jumps` using the operation demonstrated below. Nonnegative maximum forward jump lengths; return-1 when unreachable or empty.

## Demonstration

```java
minimum(new int[]{2,3,1,1,4})
```

Expected output:

```text
2
```

## How and why

Scanning all positions of one reachable layer before extending the boundary simulates breadth-first search over jump counts without storing every edge. Each new layer adds one necessary jump.

## Walkthrough

The first jump reaches indices1..2; their combined reach includes index4, so two jumps suffice.

## Complexity and tradeoffs

O(n) time and O(1) space.

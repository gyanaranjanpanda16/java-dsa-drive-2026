# Q344 — Find the longest directed path length in a DAG

**Topic:** Graphs · **Level:** Medium

## Question and contract

Find the longest directed path length in a DAG. Implement the operation exposed by `String solve(int n,int[][] edges)`. Directed graph with valid endpoints; answer is the maximum number of edges in any path, or CYCLE if the graph is not a DAG; empty graph returns0.

## Runnable example

```java
solve(5,new int[][]{{0,1},{1,2},{0,3},{3,2},{2,4}})
```

Expected output:

```text
3
```

## How and why the answer works

For a DAG, every path ending at v either starts there or extends a path ending at one predecessor. Processing vertices topologically makes those predecessor optima final before v is released. This computes dependency depth or the longest chain of unit-duration tasks; a general cyclic longest-simple-path problem is much harder.

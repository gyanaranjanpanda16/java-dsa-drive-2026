# Q321 — Count four-connected islands in a binary grid

**Topic:** Grid graphs · **Level:** Medium

## Question and contract

Count four-connected islands in a binary grid. Implement the operation exposed by `int solve(int[][] grid)`. Rectangular non-null grid containing only0 and1; four-way adjacency; input preserved.

## Runnable example

```java
solve(new int[][]{{1,1,0},{0,0,1},{1,0,1}})
```

Expected output:

```text
3
```

## How and why the answer works

Grid adjacency turns the problem into connected-component counting. Flooding a new land seed marks its complete component, so later cells in that island cannot increment the count again.

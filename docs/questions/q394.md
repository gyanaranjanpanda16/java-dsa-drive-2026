# Q394 — Combination Sum Single Use

**Topic:** Recursion and backtracking · **Difficulty:** Medium

## Question and contract

Implement `Combination Sum Single Use` using the operation demonstrated below. Positive integer inputs may contain duplicates; each index can be selected once; target small enough to enumerate.

## Demonstration

```java
combinations(new int[]{1,1,2,5},3)
```

Expected printed output (verified):

```text

```

## How and why

Advancing to i+1 enforces single use. Skipping equal sibling choices removes duplicates while still permitting equal values from different depths when available.

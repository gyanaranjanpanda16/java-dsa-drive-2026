# Q067 — Rotate a square matrix clockwise

**Topic:** Matrix transformations · **Level:** Medium

## Question and contract

Return a clockwise 90-degree rotation of a square matrix without changing the input. Original coordinate (r,c) maps to (c,n-1-r).

Implement `int[][] solve(int[][] a)`. The examples below define concrete accepted inputs and expected answers. Unless stated otherwise, reference inputs must be non-null; unsupported input violates the method's contract. Read the validation and comments in the source for additional restrictions.

- `return rotated;` — The coordinate mapping is a bijection, so every value appears exactly once.

# Q240 — Find the minimum in a rotated array with duplicates

**Topic:** Ambiguous binary search · **Level:** Medium

## Problem and accepted inputs

Return OptionalInt minimum of a rotated nondecreasing array, or empty for no elements.

## Example

```java
solve(new int[]{2,2,2,0,1})
```

Expected Java value: `OptionalInt.of(0)`.

Expected printed output (verified):

```text
OptionalInt[0]
```

## How, why, and where to use it

Comparing midpoint to the right endpoint identifies which side contains a smaller value. Equality is ambiguous: removing the right endpoint is safe because the midpoint preserves an equal candidate. Duplicates can force linear work.

## Worked trace

For[2,2,2,0,1], midpoint2 exceeds right1, so the minimum is to its right.

## Line-by-line reasoning

- `public static OptionalInt solve(int[] a) {` — Represent empty input without reserving an integer sentinel.
- `if(a.length==0) return OptionalInt.empty();` — No minimum exists in an empty sequence.
- `int low=0,high=a.length-1;` — At least one minimum remains inside this inclusive interval.
- `while(low<high) {` — Stop when one candidate position remains.
- `int middle=low+(high-low)/2;` — Probe without arithmetic overflow.
- `if(a[middle]>a[high]) low=middle+1;` — The wrap and smaller values must occur after middle.
- `else if(a[middle]<a[high]) high=middle;` — The right side is ordered above a candidate at middle.
- `else high--;` — An equal midpoint preserves any minimum represented by the removed endpoint.
- `return OptionalInt.of(a[low]);` — The invariant leaves a minimum at the surviving index.

## Complexity and tradeoffs

O(log n) on informative comparisons, O(n) worst-case with duplicates; O(1) space.

## Cases to practise

- `solve(new int[]{2,2,2,0,1})` → `OptionalInt.of(0)`: Duplicates before a unique minimum.
- `solve(new int[]{1,1,1})` → `OptionalInt.of(1)`: Every value is a minimum.
- `solve(new int[]{})` → `OptionalInt.empty()`: Empty sequence.

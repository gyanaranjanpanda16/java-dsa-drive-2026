# Q316 — Detect a cycle in a simple undirected graph

**Topic:** Graphs · **Level:** Medium

## Question and contract

Detect a cycle in a simple undirected graph. Implement the operation exposed by `boolean solve(int n,int[][] edges)`. Simple undirected graph with valid vertices and no parallel edges; self-loops count as cycles; recursive depth must fit the JVM stack.

## Runnable example

```java
solve(3,new int[][]{{0,1},{1,2},{2,0}})
```

Expected output:

```text
true
```

## How and why the answer works

In undirected DFS, the edge back to the immediate parent is expected. Reaching any other already visited neighbor closes a cycle because tree paths already connect the two vertices.

## Walkthrough

Traverse the undirected triangle 0–1–2–0. From 1, seeing 0 again is just the edge back to the parent and is ignored. From 2, seeing already visited 0 is a different earlier vertex, proving a cycle. Without the parent exception, even a single undirected edge would be mistaken for a cycle.

## Complexity and tradeoffs

O(V+E) time and storage; O(V) worst-case recursion. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

# Q455 — Jump Game Reachability

**Topic:** Greedy and search on answer · **Difficulty:** Medium

## Question and contract

Implement `Jump Game Reachability` using the operation demonstrated below. Nonnegative maximum forward jump lengths; start at0 and ask whether the final index is reachable.

## Demonstration

```java
reachable(new int[]{2,3,1,1,4})
```

Expected output:

```text
true
```

## How and why

Reachable positions form a prefix because each jump can use any distance up to its maximum. Tracking only the farthest frontier is therefore sufficient; a gap before the next index is impossible to cross.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `if(jumps.length==0) return false;` — There is no starting position in empty input.
- `long farthest=0;` — The initial position is reachable without a jump.
- `for(int i=0;i<jumps.length&&i<=farthest;i++) {` — Only positions inside the reachable prefix can extend it.
- `if(jumps[i]<0) throw new IllegalArgumentException("Nonnegative jump lengths");` — Reachability is defined by forward jumps of bounded length.
- `farthest=Math.max(farthest,(long)i+jumps[i]);` — Any permitted shorter jump fills the interval up to this endpoint.
- `if(farthest>=jumps.length-1) return true;` — The destination belongs to the reachable prefix.
- `return false;` — The next unprocessed index lies beyond every reachable jump.

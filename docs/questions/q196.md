# Q196 — Maintain stack minima through pushes and pops

**Topic:** Stacks, queues, and deques · **Level:** Medium

## Question and contract

Commands are push:x,pop,min. Valid sequences never pop or query an empty stack. Return values produced by min commands.

## Example

Commands:push3,push1,min,pop,min.

Expected printed output:

```text
[1, 3]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

Each depth stores both its value and the minimum of the prefix below it. Popping restores the previous depth minimum automatically, including duplicate minima.

# Q318 — Produce a deterministic topological order or report a cycle

**Topic:** Graphs · **Level:** Medium

## Question and contract

Produce a deterministic topological order or report a cycle. Implement the operation exposed by `String solve(int n,int[][] edges)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(4,new int[][]{{0,2},{1,2},{2,3}})
```

Expected output:

```text
[0, 1, 2, 3]
```

## How and why the answer works

A zero-indegree vertex has no remaining prerequisite and is safe to output. Removing its outgoing constraints preserves the same problem on unscheduled vertices. If none is ready while vertices remain, following incoming edges eventually repeats a vertex, proving a cycle.

## Walkthrough

For edges 0→2,1→2,2→3, indegrees are 0,0,2,1. Begin with available vertices 0 and 1. Emitting 0 reduces 2 to 1; emitting 1 reduces it to 0, so 2 becomes available and then releases 3. The order 0,1,2,3 respects every dependency. Failing to emit all vertices would signal a cycle.

## Complexity and tradeoffs

O(E+V log(V+1)) time using the tie-breaking heap; O(V+E) space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

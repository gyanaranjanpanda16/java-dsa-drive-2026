# Q258 — Measure height in nodes

**Topic:** Trees and BST · **Level:** Beginner

## Question and contract

Measure height in nodes. Implement the operation exposed by `int solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
3
```

## How and why the answer works

The longest root-to-leaf path consists of the root followed by the taller child path.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Null children have height 0. Leaves have height 1, their parents 2 and 6 have height 2, and root 4 has height 3. We use the longer child path because height measures the deepest descent. This lesson counts nodes on that path; counting edges instead would give 2 for this same tree.

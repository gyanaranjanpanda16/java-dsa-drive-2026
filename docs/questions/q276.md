# Q276 — Find the smallest BST key at least a target

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Find the smallest BST key at least a target. Implement the operation exposed by `Integer solve(Node root,int key)`. Input is a valid BST; null means no ceiling exists.

## Runnable example

```java
solve(sample(),5)
```

Expected output:

```text
5
```

## How and why the answer works

This is the dual of floor search: an admissible node becomes a candidate while the search moves toward smaller admissible values.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

For target 5, root 4 is too small, so move right. Node 6 is a legal ceiling candidate; moving left may find a smaller legal one. Node 5 is exact, so the result is 5. A ceiling is the least value at least the target, which is different from the nearest value by absolute distance.

- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.

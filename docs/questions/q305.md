# Q305 — Find the smallest range covering every sorted feed

**Topic:** Heap frontier · **Level:** Hard

## Question and contract

Find the smallest range covering every sorted feed. Implement the operation exposed by `String solve(int[][] feeds)`. Rows are non-null and sorted nondecreasing; [] means no covering range; equal-width ties choose the earlier left endpoint.

## Runnable example

```java
solve(new int[][]{{4,10,15,24,26},{0,9,12,20},{5,18,22,30}})
```

Expected output:

```text
[20, 24]
```

## How and why the answer works

Each frontier holds one value from every feed. Advancing a representative other than the minimum cannot raise the lower endpoint and may only raise the maximum, so advancing the minimum is the only useful next choice. Enumerating these frontiers finds the optimum.

## Walkthrough

A candidate range must include at least one value from every sorted feed. The winning [20,24] contains 24 from the first,20 from the second, and 22 from the third. Advance the feed supplying the current minimum because retaining that minimum while increasing the maximum cannot shrink the range. Stop once a feed has no next candidate.

## Complexity and tradeoffs

O(N log(k+1)) time and O(k) working space for k feeds and N total values. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `if(feeds.length==0) return "[]";` — There is no required feed to cover.
- `PriorityQueue<int[]> heap=new PriorityQueue<>(Comparator.comparingInt(c->feeds[c[0]][c[1]]));` — The root identifies the smallest current representative.
- `int maximum=Integer.MIN_VALUE;` — Track the largest representative across all feeds.
- `for(int i=0;i<feeds.length;i++) {` — Initialize one representative per required feed.
- `if(feeds[i].length==0) return "[]";` — An empty feed makes complete coverage impossible.
- `heap.offer(new int[]{i,0}); maximum=Math.max(maximum,feeds[i][0]);` — The initial frontier covers every feed.
- `maximum=Math.max(maximum,feeds[c[0]][c[1]]); heap.offer(c);` — Replace only the consumed representative and preserve complete coverage.
- `return "["+left+", "+right+"]";` — Return inclusive endpoints of an optimal covering range.

# Q385 — Generate String Subsequences

**Topic:** Recursion and backtracking · **Difficulty:** Medium

## Question and contract

Implement `Generate String Subsequences` using the operation demonstrated below. Non-null short string; output preserves input order and includes empty string.

## Demonstration

```java
subsequences("ab")
```

Expected printed output (verified):

```text
[, b, a, ab]
```

## How and why

Every position has exactly two choices, exclude or include. The recursion partitions all positional subsets without losing or revisiting a choice sequence.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `List<String> out = new ArrayList<>();` — Each leaf contributes one positional subsequence.
- `choose(s, 0, new StringBuilder(), out);` — Initially no input position has been decided.
- `return out;` — Duplicate characters may create equal strings from different choices.
- `if (i == s.length()) { out.add(path.toString()); return; }` — Copy the completed choice before backtracking changes it.
- `path.append(s.charAt(i));` — Include the position without changing earlier choices.
- `choose(s, i+1, path, out);` — Explore every completion using this character.
- `path.deleteCharAt(path.length()-1);` — Restore the caller's path for its next branch.

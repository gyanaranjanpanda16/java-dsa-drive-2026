# Q436 — Decode Digit Strings

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Decode Digit Strings` using the operation demonstrated below. Map1..26 to letters; reject non-digits; empty message returns zero.

## Demonstration

```java
ways("226")
```

Expected output:

```text

```

## How and why

The final encoded letter uses either one valid nonzero digit or a valid pair10..26. These token lengths partition all decodings without overlap.

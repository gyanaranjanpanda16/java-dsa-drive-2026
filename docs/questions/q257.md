# Q257 — Count leaf nodes

**Topic:** Trees and BST · **Level:** Beginner

## Question and contract

Count leaf nodes. Implement the operation exposed by `int solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
4
```

## How and why the answer works

A leaf has no children; every other leaf belongs to exactly one child subtree.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Nodes 1,3,5,7 have neither a left nor a right child, so each contributes 1. Nodes 2,4,6 contribute only their children's leaf counts. The answer is 4. A node with just one missing child is not a leaf: both links must be null.

## Complexity and tradeoffs

O(n) time; O(h) call-stack space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

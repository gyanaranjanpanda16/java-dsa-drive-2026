# Q377 — Recursive Digit Sum

**Topic:** Recursion and backtracking · **Difficulty:** Easy

## Question and contract

Implement `Recursive Digit Sum` using the operation demonstrated below. Sum decimal digits of a nonnegative long.

## Demonstration

```java
digitSum(5072)
```

Expected printed output (verified):

```text
14
```

## How and why

Modulo ten extracts the last digit and integer division removes it. Every recursive call shortens the decimal representation.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

## Walkthrough

5072 becomes 2 + digitSum(507), then 2 + 7 + 0 + 5 = 14.

## Complexity and tradeoffs

O(d) time and O(d) stack for d decimal digits.

Use the input domain above when judging whether the state space fits memory and whether arithmetic fits the chosen numeric type. Recursive output-generation problems have an unavoidable cost proportional to their output; avoid using them on unrestricted large inputs.

# Q337 — Count strongly connected components with Kosaraju

**Topic:** Graphs · **Level:** Medium

## Question and contract

Count strongly connected components with Kosaraju. Implement the operation exposed by `int solve(int n,int[][] edges)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(5,new int[][]{{0,1},{1,0},{1,2},{2,3},{3,2},{3,4}})
```

Expected output:

```text
3
```

## How and why the answer works

Contracting SCCs gives a DAG. The highest finishing-time unprocessed component is a source in the remaining original component DAG and thus a sink in its transpose. A reverse traversal cannot escape it, so it discovers exactly one SCC.

## Walkthrough

Vertices 0 and 1 reach each other, forming one strongly connected component. Vertices 2 and 3 also reach each other, forming another. Vertex 4 has no return route and forms its own component. Thus the directed graph has 3 components even though edges link those groups in one direction.

# Q211 — Count words in sorted dictionary order

**Topic:** Hash maps and sets · **Level:** Easy

## Question and contract

Given case-sensitive word tokens, return each word and its count in natural String order; empty tokens are ordinary words.

## Example

Tokens: pear, apple, pear.

Expected printed output:

```text
{apple=1, pear=2}
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

A TreeMap maintains one entry per word. After processing a prefix, each value equals that word count in the prefix; increasing one entry preserves this invariant. Sorted iteration is useful for a reproducible word-index report.

## Walkthrough

pear becomes 1, apple becomes 1, then pear becomes 2. Sorted traversal emits apple before pear.

## Complexity and edge cases

O(n log u) map operations and O(u) entries for n tokens and u distinct words; string comparisons also inspect characters.

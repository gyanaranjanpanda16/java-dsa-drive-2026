# Q080 — Filter a list using set membership while preserving duplicates

**Topic:** Java Collections: retainAll · **Level:** Beginner

## Question and contract

Keep only allowed values while preserving input order and multiplicity. A set supplies membership checks, while ArrayList retains list semantics; unlike a set intersection, duplicates survive.

Implement `List<String> solve(List<String> input, Collection<String> allowed)`. The examples below define concrete accepted inputs and expected answers. Unless stated otherwise, reference inputs must be non-null; unsupported input violates the method's contract. Read the validation and comments in the source for additional restrictions.

## Example and answer

Input arguments: `List.of("a","b","a"),List.of("a")`

Expected Java value: `List.of("a","a")`

Expected printed output (verified):

```text
[a, a]
```

## How and why the answer works

Keep only allowed values while preserving input order and multiplicity. A set supplies membership checks, while ArrayList retains list semantics; unlike a set intersection, duplicates survive.

Follow the state in this order for the sample input; each explanation corresponds to a line in the solution:

- `Set<String> membership = new HashSet<>(allowed);` — Avoid repeated linear searches through the allowed collection.
- `List<String> result = new ArrayList<>(input);` — Preserve the original sequence and its duplicates.
- `result.retainAll(membership);` — Remove each occurrence whose value is absent from the allowed set.
- `return result;` — This is list filtering, so repeated allowed values remain repeated.

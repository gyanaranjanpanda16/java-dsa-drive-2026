# Q444 — Dungeon Minimum Initial Health

**Topic:** Dynamic programming · **Difficulty:** Hard

## Question and contract

Implement `Dungeon Minimum Initial Health` using the operation demonstrated below. Nonempty rectangular dungeon; move right/down; health must remain strictly positive.

## Demonstration

```java
minimum(new int[][]{{-2,-3,3},{-5,-10,1},{10,30,-5}})
```

Expected output:

```text
7
```

## How and why

The needed health before a cell is the chosen successor requirement minus the current cell gain, clamped to at least one. Backward evaluation preserves survival at every intermediate position.

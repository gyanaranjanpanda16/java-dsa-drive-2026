# Q491 — Count binary-tree shapes with exact Catalan numbers

**Topic:** Combinatorial dynamic programming · **Level:** Medium

## Problem and accepted inputs

Return the nth Catalan number for0<=n<=500, counting ordered binary-tree shapes with n nodes, including the empty shape for n=0.

## Example

```java
solve(3)
```

Expected Java value: `BigInteger.valueOf(5)`.

Expected printed output (verified):

```text
5
```

## How, why, and where to use it

Choose how many nodes belong to the left subtree; the rest belong to the right. Their independent shape counts multiply, and summing over all possible splits covers every root shape exactly once. The same sequence counts balanced-parenthesis shapes and several other recursive structures.

## Worked trace

For n=3, split sizes(0,2),(1,1),(2,0) contribute2+1+2=5 shapes.

## Line-by-line reasoning

- `public static BigInteger solve(int n) {` — Keep exponentially growing combinatorial counts exact.
- `if(n<0||n>500) throw new IllegalArgumentException("require zero to five hundred");` — Bound this quadratic teaching implementation.
- `BigInteger[] count=new BigInteger[n+1]; count[0]=BigInteger.ONE;` — One empty subtree is required for multiplicative combinations.
- `for(int nodes=1;nodes<=n;nodes++) {` — Smaller subtree counts are ready before larger shapes are constructed.
- `count[nodes]=BigInteger.ZERO;` — Sum disjoint possibilities for the left-subtree size.
- `for(int left=0;left<nodes;left++) count[nodes]=count[nodes].add(count[left].multiply(count[nodes-1-left]));` — Reserve one node for the root and combine both subtrees independently.
- `return count[n];` — The recurrence enumerates shapes, not key permutations or labeled trees.

## Complexity and tradeoffs

O(n²) BigInteger multiply/add operations and O(n) stored BigIntegers; actual bit costs grow with the counts.

## Cases to practise

- `solve(3)` → `BigInteger.valueOf(5)`: All three root splits contribute.
- `solve(0)` → `BigInteger.ONE`: The empty tree is one shape.
- `solve(20)` → `new BigInteger("6564120420")`: The count exceeds int.

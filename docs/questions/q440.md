# Q440 — Egg Drop Minimum Moves

**Topic:** Dynamic programming · **Difficulty:** Hard

## Question and contract

Implement `Egg Drop Minimum Moves` using the operation demonstrated below. Find a threshold floor in the worst case; eggs may be reused only if they survive.

## Demonstration

```java
moves(2,100)
```

Expected output:

```text
14
```

## How and why

A tested floor splits into a break branch using one fewer egg and a survive branch retaining all eggs. Their covered intervals plus the tested floor give the maximum range resolvable in one more move.

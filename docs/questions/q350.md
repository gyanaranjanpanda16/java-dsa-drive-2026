# Q350 — Find the longest prefix shared by all dictionary words

**Topic:** Tries · **Level:** Beginner

## Question and contract

Find the longest prefix shared by all dictionary words. Implement the operation exposed by `String solve(String[] words)`. Non-null strings and arrays; case-sensitive UTF-16 code-unit matching; duplicates are allowed unless stated otherwise.

## Runnable example

```java
solve(new String[]{"flower","flow","flight"})
```

Expected output:

```text
fl
```

## How and why the answer works

A common prefix can continue only while all words follow the same next edge and none has already ended. The first branching node or terminal node is therefore the exact stopping boundary. Shared-path discovery appears in namespace grouping and directory compression.

## Walkthrough

flower, flow, and flight share the only f edge, then the only l edge. The next node branches into o and i, so the answer is fl.

## Complexity and tradeoffs

O(S log(A+1)) construction time plus O(H) descent; O(S) space. A direct character scan uses less auxiliary memory if no other trie queries are needed. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Checks and edge cases

- Words branch after fl.
- Identical words share their full length.
- An empty word forces an empty common prefix.

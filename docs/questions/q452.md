# Q452 — Maximum Courses Before Deadlines

**Topic:** Greedy and search on answer · **Difficulty:** Hard

## Question and contract

Implement `Maximum Courses Before Deadlines` using the operation demonstrated below. A course needs uninterrupted positive duration; only one course at a time, start at time0, finish by its deadline.

## Demonstration

```java
maximum(new int[][]{{100,200},{200,1300},{1000,1250},{2000,3200}})
```

Expected output:

```text
3
```

## How and why

In deadline order, replacing the longest selected duration whenever time exceeds the deadline preserves the greatest feasible count while minimizing its total duration. Shorter total duration cannot harm later deadlines.

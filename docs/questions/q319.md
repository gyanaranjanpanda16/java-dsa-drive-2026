## Question and contract

## How and why the answer works

Alternating colors along paths is necessary for every edge to cross the partition. If propagation finds a conflict, the competing path parity yields an odd cycle; otherwise the completed coloring itself witnesses a valid bipartition.

## Walkthrough

Color vertex 0 in one group, its neighbors 1 and 3 in the other, then vertex 2 back in the first. Every edge of the square 0–1–2–3–0 crosses groups, so it is bipartite. The check is about neighboring colors; a graph with disconnected components needs a fresh start for each uncolored component.

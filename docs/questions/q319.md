**Topic:** Graphs · **Level:** Medium

## Question and contract

Check whether an undirected graph can be two-colored. Implement the operation exposed by `boolean solve(int n,int[][] edges)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(4,new int[][]{{0,1},{1,2},{2,3},{3,0}})
```

Expected output:

```text
true
```

## How and why the answer works

Alternating colors along paths is necessary for every edge to cross the partition. If propagation finds a conflict, the competing path parity yields an odd cycle; otherwise the completed coloring itself witnesses a valid bipartition.

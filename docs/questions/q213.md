# Q213 — Compare arrays while preserving duplicate multiplicities

**Topic:** Hash maps and sets · **Level:** Easy

## Question and contract

Return whether arrays contain the same integer multiset regardless of order.

## Example

Left [1,2,1], right [2,1,1].

Expected printed output:

```text
true
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

Count the first array and consume one count per second-array value. A missing count proves an unmatched occurrence. Equal lengths plus successful consumption imply no occurrences remain. This compares unordered batches where duplicates matter.

## Walkthrough

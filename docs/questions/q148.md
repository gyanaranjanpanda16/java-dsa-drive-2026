# Q148 — Parse and clamp a signed decimal prefix

**Topic:** Strings · **Level:** Medium

## Question and contract

Skip leading ASCII spaces, accept one sign, consume decimal digits, stop at first nondigit, and clamp outside int range. No digits means zero.

## Example

Expected printed output:

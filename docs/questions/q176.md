# Q176 — Merge two sorted linked lists by relinking

**Topic:** Linked lists · **Level:** Easy

## Question and contract

Inputs are disjoint acyclic nondecreasing lists; reuse their nodes and return the merged display.

## Example

The demonstration constructs a fresh linked list with `list(...)`.

Expected printed output:

```text
[1, 2, 3, 4, 5]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

Each head is its list smallest remaining value. Selecting the smaller head therefore appends the globally smallest unconsumed node.

# Q201 — Generate the first n positive binary representations

**Topic:** Stacks, queues, and deques · **Level:** Easy

## Question and contract

For n>=0 return binary representations of1 through n using a queue.

## Example

Input:n5.

Expected printed output:

```text
[1, 10, 11, 100, 101]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

Starting from1, appending0 and1 generates the two next-level binary strings. Breadth-first order is increasing length and then lexicographic order, which equals positive numeric order.

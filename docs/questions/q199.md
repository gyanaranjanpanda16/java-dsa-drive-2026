# Q199 — Simulate a bounded circular-array queue

**Topic:** Stacks, queues, and deques · **Level:** Medium

## Question and contract

Positive capacity; commands add:x or remove. Add returns true/false for accepted/full; remove returns the value or empty. Return all operation results.

## Example

Capacity2 with the demonstrated queue commands.

Expected printed output:

```text
[true, true, false, 1, true, 2, 3]
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

Logical position head+size modulo capacity identifies the next insertion slot. Head advances only on removal; a separate size distinguishes full from empty when indices coincide.

## Walkthrough

Capacity2;add1,2 fills the ring. Reject3,remove1,then reuse its physical slot for3 while2 remains the oldest.

## Complexity and edge cases

O(commands) time and O(capacity) storage plus output.

The contract defines the accepted domain. `selfTest()` includes at least three checks covering a regular input and meaningful boundaries or contrasting cases. A missing object reference is different from an empty collection; do not pass null unless the contract explicitly permits it. Numeric results must fit their declared type unless the method explicitly handles overflow.

# Q308 — Count degrees in an undirected multigraph

**Topic:** Graphs · **Level:** Beginner

## Question and contract

Count degrees in an undirected multigraph. Implement the operation exposed by `String solve(int n,int[][] edges)`. Vertices are numbered0 through n-1; n>=0; edge rows contain valid endpoints; arrays are non-null. Source vertices, if supplied, exist.

## Runnable example

```java
solve(3,new int[][]{{0,1},{0,2},{1,2}})
```

Expected output:

```text
[2, 2, 2]
```

## How and why the answer works

Degree counts incident edge ends, not distinct neighbors. Incrementing both endpoints handles repeated edges and the two ends of a self-loop consistently with the handshaking identity.

## Walkthrough

In the triangle 0–1,1–2,2–0, each edge contributes one to each endpoint's degree. All three vertices finish with degree 2, giving [2,2,2]. The sum 6 equals twice the three edges, which is a useful hand-check for an undirected graph under the lesson's edge conventions.

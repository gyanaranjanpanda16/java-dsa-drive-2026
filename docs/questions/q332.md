# Q332 — Find an undirected minimum spanning-tree weight with Prim

**Topic:** Graphs · **Level:** Medium

## Question and contract

Find an undirected minimum spanning-tree weight with Prim. Implement the operation exposed by `String solve(int n,int[][] edges)`. Undirected weighted edges [u,v,int weight], including negative weights; valid endpoints; DISCONNECTED when no spanning tree exists.

## Runnable example

```java
solve(3,new int[][]{{0,1,4},{1,2,1},{0,2,2}})
```

Expected output:

```text
3
```

## How and why the answer works

At every step, the cheapest edge crossing from selected vertices to unselected vertices is safe by the cut property: any spanning tree omitting it can exchange another crossing edge without increasing weight.

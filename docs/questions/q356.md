# Q356 — Maximize the unsigned XOR of two array values

**Topic:** Binary tries · **Level:** Medium

## Problem and accepted inputs

Return the largest unsigned32-bit XOR of two distinct array positions as a long; return0 when fewer than two positions exist.

## Example

```java
solve(new int[]{3,10,5,25,2,8})
```

Expected Java value: `28L`.

Expected printed output (verified):

```text
28
```

## How, why, and where to use it

At each bit from most to least significant, prefer the opposite stored bit because its contribution outweighs every lower bit combined. Query only previously inserted values to guarantee distinct indices. This is a bitwise optimization technique for encoded identifiers and numeric matching.

## Worked trace

For[3,10,5,25,2,8], choosing5 and25 yields28. For[-1,0], all32 XOR bits are set, yielding4294967295.

# Q419 — Rod Cutting Revenue

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Rod Cutting Revenue` using the operation demonstrated below. price[i] prices a piece of length i+1; cut the full rod of length price.length, even if prices are negative.

## Demonstration

```java
maximum(new int[]{1,5,8,9})
```

Expected output:

```text
10
```

## How and why

Every nonempty cutting plan has a first piece. Trying every length for that piece and combining it with an optimal remainder covers every possible plan.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `long[] dp=new long[price.length+1];` — dp[length] stores the best revenue for exactly that rod length.
- `Arrays.fill(dp,Long.MIN_VALUE); dp[0]=0;` — Only the empty rod has a known value before any cuts are considered.
- `for(int length=1;length<=price.length;length++) {` — Every shorter leftover rod is already solved.
- `for(int first=1;first<=length;first++) dp[length]=Math.max(dp[length],price[first-1]+dp[length-first]);` — Choose the first piece and optimally cut the remaining length.
- `return dp[price.length];` — Every unit of the original rod has been assigned to a priced piece.

# Q131 — Toggle ASCII letter case

**Topic:** Strings · **Level:** Beginner

## Question and contract

Toggle a-z to A-Z and A-Z to a-z; preserve all other UTF-16 chars.

## Example

Input: `Java17!`.

Expected printed output:

```text
jAVA17!
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

The ASCII uppercase and lowercase ranges have a fixed offset, so mapping only those ranges changes case without touching punctuation.

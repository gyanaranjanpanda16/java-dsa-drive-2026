# Q408 — Triangle Minimum Path

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Triangle Minimum Path` using the operation demonstrated below. Row r has r+1 values; choose a child at the same or next column; totals fit long.

## Demonstration

```java
minimum(new int[][]{{2},{3,4},{6,5,7},{4,1,8,3}})
```

Expected output:

```text
11
```

## How and why

From each triangle cell a route chooses exactly one of two children. Bottom-up optimal child costs therefore provide all possibilities for the optimal parent cost.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `if(triangle.length==0) return 0;` — The empty triangle has an empty path of cost zero.
- `long[] dp=new long[triangle.length+1];` — One zero boundary row makes the last actual row a uniform transition.
- `for(int row=triangle.length-1;row>=0;row--) {` — Children must be solved before their parent choices.
- `for(int col=0;col<=row;col++) dp[col]=triangle[row][col]+Math.min(dp[col],dp[col+1]);` — Choose the cheaper of the two adjacent child paths.
- `return dp[0];` — The top state summarizes the cheapest complete route.

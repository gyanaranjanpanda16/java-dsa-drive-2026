# Q296 — Simulate repeatedly smashing the two heaviest stones

**Topic:** Max heaps · **Level:** Easy

## Question and contract

Simulate repeatedly smashing the two heaviest stones. Implement the operation exposed by `int solve(int[] stones)`. Nonnegative int weights; input is not changed.

## Runnable example

```java
solve(new int[]{2,7,4,1,8,1})
```

Expected output:

```text
1
```

## How and why the answer works

A max-heap implements the required choice rule directly. After removing the two maxima, reinserting only their positive difference makes the heap exactly the next simulation state.

## Walkthrough

For stones [2,7,4,1,8,1], smash 8 with 7 and return 1. Smash 4 with 2 and return 2. Then smash 2 with 1 to return 1; pairs of remaining equal 1s cancel until one 1 remains. Always remove the two current largest stones; sorting only the initial list is insufficient because new stones are generated.

## Complexity and tradeoffs

O(n log(n+1)) time and O(n) space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `PriorityQueue<Integer> heap=new PriorityQueue<>(Comparator.reverseOrder());` — The next two removals must be the heaviest stones.
- `for(int stone:stones) {` — Load each physical stone as a separate occurrence.
- `if(stone<0) throw new IllegalArgumentException("negative stone");` — Negative weights do not model the problem.
- `heap.offer(stone);` — Preserve equal weights rather than collapsing them in a set.
- `while(heap.size()>1) {` — A smash requires two remaining stones.
- `if(largest!=second) heap.offer(largest-second);` — Equal stones disappear; otherwise their difference survives.
- `return heap.isEmpty()?0:heap.peek();` — No remaining stone has weight zero by convention.

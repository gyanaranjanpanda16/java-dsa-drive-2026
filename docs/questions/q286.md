# Q286 — Find the kth largest array element

**Topic:** Heaps · **Level:** Medium

## Question and contract

Find the kth largest array element. Implement the operation exposed by `int solve(int[] a,int k)`. Non-null int array; 1<=k<=length; duplicates count separately.

## Runnable example

```java
solve(new int[]{3,2,1,5,6,4},2)
```

Expected output:

```text
5
```

## How and why the answer works

After every insertion the heap contains the largest k values seen so far, or the entire shorter prefix. Discarding its minimum cannot eliminate a final top-k value without keeping k at least-as-large alternatives.

## Walkthrough

Keep only the largest two values of [3,2,1,5,6,4]. After seeing 3 and 2 the min heap contains 2,3. Discard 1; replace 2 with 5, then 3 with 6. Finally 4 cannot displace heap minimum 5. The retained pair is 5,6 and its minimum 5 is the second largest.

## Complexity and tradeoffs

O(n log(k+1)) time and O(k) space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

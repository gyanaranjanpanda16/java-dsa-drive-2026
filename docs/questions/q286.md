# Q286 — Find the kth largest array element

**Topic:** Heaps · **Level:** Medium

## Question and contract

Find the kth largest array element. Implement the operation exposed by `int solve(int[] a,int k)`. Non-null int array; 1<=k<=length; duplicates count separately.

## Runnable example

```java
solve(new int[]{3,2,1,5,6,4},2)
```

Expected output:

```text
5
```

## How and why the answer works

After every insertion the heap contains the largest k values seen so far, or the entire shorter prefix. Discarding its minimum cannot eliminate a final top-k value without keeping k at least-as-large alternatives.

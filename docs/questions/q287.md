# Q287 — Find the kth smallest array element

**Topic:** Heaps · **Level:** Medium

## Question and contract

Find the kth smallest array element. Implement the operation exposed by `int solve(int[] a,int k)`. Non-null array and valid one-based rank; duplicates count.

## Runnable example

```java
solve(new int[]{7,2,9,1},2)
```

Expected output:

```text
2
```

## How and why the answer works

The retained max-heap is the multiset of the k smallest processed occurrences. Its largest member is precisely the boundary value for rank k.

## Walkthrough

Keep only the smallest two values of [7,2,9,1] in a max heap. Start with 7 and 2;9 cannot improve them. Inserting 1 removes the largest retained value 7, leaving 1 and 2. The largest retained value 2 is the second smallest. Reversing the heap ordering is what keeps the correct boundary available.

## Complexity and tradeoffs

O(n log(k+1)) time; O(k) auxiliary space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `PriorityQueue<Integer> heap=new PriorityQueue<>(Comparator.reverseOrder());` — The largest retained small candidate is the eviction boundary.
- `heap.offer(value);` — Give the arrival a chance to join the k smallest.
- `if(heap.size()>k) heap.poll();` — Evict the largest of k+1 candidates.
- `return heap.element();` — The largest retained value is the kth smallest.

# Q133 — Count characters in sorted order

**Topic:** Strings · **Level:** Easy

## Question and contract

Return a TreeMap from UTF-16 char to occurrence count.

## Example

Input: `banana`.

Expected printed output:

```text
{a=3, b=1, n=2}
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

Incrementing the map entry on each visit makes it equal to occurrences in the scanned prefix; the tree orders keys for deterministic output.

## Walkthrough

b reaches one, a reaches three, n reaches two. Tree order prints a, b, then n.

## Complexity and edge cases

O(n log u) time and O(u) space, where u is the number of distinct chars.

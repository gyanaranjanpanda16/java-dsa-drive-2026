# Q132 — Remove whitespace characters

**Topic:** Strings · **Level:** Beginner

## Question and contract

Remove every char for which Character.isWhitespace returns true; retain order of all other chars.

## Example

Input contains spaces, a tab, and a newline around `a`, `b`, `c`.

Expected printed output:

```text
abc
```

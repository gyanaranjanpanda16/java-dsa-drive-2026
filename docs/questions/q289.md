# Q289 — Merge k sorted integer feeds

**Topic:** Heaps · **Level:** Hard

## Question and contract

Merge k sorted integer feeds. Implement the operation exposed by `String solve(int[][] feeds)`. Every row is non-null and sorted nondecreasing; N is total elements.

## Runnable example

```java
solve(new int[][]{{1,4},{2,3},{}})
```

Expected output:

```text
[1, 2, 3, 4]
```

## How and why the answer works

Because each feed is sorted, its head is its smallest unconsumed value. The minimum among all heads is therefore globally next; replacing only that head preserves the invariant.

## Walkthrough

Insert the first entry of each nonempty feed:1 from [1,4] and 2 from [2,3]. Remove 1 and insert its successor 4; remove 2 and insert 3; then remove 3 and 4. An empty feed contributes no candidate. Every heap entry is the smallest unconsumed value of its own sorted feed.

## Complexity and tradeoffs

O(k+N log(k+1)) time; O(k) heap plus O(N) output. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

- Multiple feeds and an empty feed.
- No feeds.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `PriorityQueue<int[]> heap=new PriorityQueue<>(Comparator.comparingInt(c->feeds[c[0]][c[1]]));` — Compare the value at each feed cursor.
- `for(int f=0;f<feeds.length;f++) if(feeds[f].length>0) heap.offer(new int[]{f,0});` — Only nonempty feeds have a current head.
- `List<Integer> result=new ArrayList<>();` — Append globally smallest remaining values in order.
- `while(!heap.isEmpty()) {` — Each iteration consumes exactly one feed element.
- `int[] cursor=heap.poll();` — The minimum head is the smallest value in all remaining feeds.
- `result.add(feeds[cursor[0]][cursor[1]]);` — Emit that value before advancing its feed.
- `if(cursor[1]<feeds[cursor[0]].length) heap.offer(cursor);` — Replace the consumed head if this feed has more values.
- `return result.toString();` — Every input occurrence was emitted once.

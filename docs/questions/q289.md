# Q289 — Merge k sorted integer feeds

**Topic:** Heaps · **Level:** Hard

## Question and contract

Merge k sorted integer feeds. Implement the operation exposed by `String solve(int[][] feeds)`. Every row is non-null and sorted nondecreasing; N is total elements.

## Runnable example

```java
solve(new int[][]{{1,4},{2,3},{}})
```

Expected output:

```text
[1, 2, 3, 4]
```

## How and why the answer works

Because each feed is sorted, its head is its smallest unconsumed value. The minimum among all heads is therefore globally next; replacing only that head preserves the invariant.

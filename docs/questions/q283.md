# Q283 — List nodes at a given depth from the root

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

List nodes at a given depth from the root. Implement the operation exposed by `String solve(Node root,int depth)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample(),2)
```

Expected output:

```text
[1, 3, 5, 7]
```

## How and why the answer works

Each descent consumes one unit of depth. A node is selected precisely when the remaining depth becomes zero, so no shallower or deeper node is included.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

The root is at depth 0. Its children 2 and 6 are at depth 1; their children 1,3,5,7 are at depth 2. For requested depth 2, emit those four values and do not descend further. Distinguishing zero-based depth from node-count height avoids an off-by-one answer.

## Complexity and tradeoffs

O(n) worst-case time; O(h) recursion plus selected output. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `static void collect(Node n,int remaining,List<Integer> out) {` — Remaining depth describes the exact selection target below n.
- `if(n==null) return;` — Missing branches cannot reach the requested level.
- `if(remaining==0) { out.add(n.value); return; }` — Stop descent once the required level is reached.
- `collect(n.left,remaining-1,out); collect(n.right,remaining-1,out);` — Both children are one step closer to the requested depth.
- `List<Integer> out=new ArrayList<>(); collect(root,depth,out);` — Carry the remaining depth instead of recomputing levels.
- `return out.toString();` — Values remain left-to-right within the selected level.

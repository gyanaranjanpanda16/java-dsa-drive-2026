# Q126 — Print every character with its index

**Topic:** Strings · **Level:** Beginner

## Question and contract

Return one index:character entry per UTF-16 char of a non-null string. Empty input returns an empty string.

## Example

Input: `Java`.

Expected printed output:

```text
0:J, 1:a, 2:v, 3:a
```

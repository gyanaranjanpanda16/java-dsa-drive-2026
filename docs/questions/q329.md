# Q329 — Find shortest paths with nonnegative weights

**Topic:** Graphs · **Level:** Medium

## Question and contract

Find shortest paths with nonnegative weights. Implement the operation exposed by `String solve(int n,int[][] edges,int source)`. Directed edges are [from,to,nonnegative int weight]; valid existing source; path sums use long.

## Runnable example

```java
solve(4,new int[][]{{0,1,8},{0,2,2},{2,1,1}},0)
```

Expected output:

```text
[0, 3, 2, INF]
```

## How and why the answer works

With nonnegative weights, the smallest pending distance cannot be improved through a more expensive unfinished prefix. Relaxation explores every outgoing continuation, and stale-entry rejection preserves this settled-distance reasoning.

## Walkthrough

From 0, tentative distances become 8 to 1 and 2 to 2. Settle 2 first; its edge to 1 of cost 1 improves distance 1 to 3. Vertex 3 remains unreachable. Output is [0,3,2,INF], where INF is the source's numeric sentinel. Taking the smallest unsettled distance works because edge weights are nonnegative.

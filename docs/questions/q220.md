# Q220 — Find a longest consecutive integer set run

**Topic:** Hash sets · **Level:** Medium

## Problem and accepted inputs

Return the maximum length of consecutive distinct integer values, ignoring duplicates and original order.

## Example

```java
solve(new int[]{100,4,200,1,3,2})
```

Expected Java value: `4`.

Expected printed output (verified):

```text
4
```

## How, why, and where to use it

Start scanning only at values whose predecessor is absent. Each distinct value belongs to exactly one such run, so all successor scans together are linear in the number of unique values. Useful for finding uninterrupted identifier or day-number coverage.

## Worked trace

In [100,4,200,1,3,2], only1 starts the run1,2,3,4;2,3,4 are skipped as starts.

## Line-by-line reasoning

- `public static int solve(int[] a) {` — Consecutiveness concerns numeric neighbors, not adjacent array positions.
- `Set<Integer> values=new HashSet<>(); for(int value:a) values.add(value);` — Remove duplicates before measuring run lengths.
- `int best=0;` — Empty input has no run.
- `for(int value:values) {` — Try only true starts rather than rescanning every suffix.
- `if(value!=Integer.MIN_VALUE && values.contains(value-1)) continue;` — Guard subtraction at the smallest int.
- `int end=value,length=1;` — Every start already contributes one distinct value.
- `while(end!=Integer.MAX_VALUE && values.contains(end+1)) { end++; length++; }` — Guard successor overflow at the largest int.
- `best=Math.max(best,length);` — Keep the longest complete run found.
- `return best;` — Each distinct member was scanned from its one run start.

## Complexity and tradeoffs

Expected O(n) time and O(u) space.

## Cases to practise

- `solve(new int[]{100,4,200,1,3,2})` → `4`: Order is irrelevant.
- `solve(new int[]{1,1,2})` → `2`: Duplicates do not extend a run.
- `solve(new int[]{Integer.MIN_VALUE,Integer.MAX_VALUE})` → `1`: Int overflow must not join extreme values.

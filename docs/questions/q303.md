# Q303 — Sort an integer array using an explicit heap

**Topic:** Sorting with heaps · **Level:** Medium

## Question and contract

Sort an integer array using an explicit heap. Implement the operation exposed by `String solve(int[] input)`. Input is non-null; equal values may change relative identity because heapsort is not stable.

## Runnable example

```java
solve(new int[]{4,1,3,2})
```

Expected output:

```text
[1, 2, 3, 4]
```

## How and why the answer works

A max-heap exposes the largest unsorted value at its root. Swapping it to the final available slot fixes that position forever; sifting the replacement down restores the invariant on the shorter prefix.

## Walkthrough

Heap sort on [4,1,3,2] first builds a max heap. Move largest 4 to the final slot and restore the heap among the first three items; then place 3, then 2. The result is [1,2,3,4]. Excluding the already sorted suffix from each repair prevents it from being disturbed.

## Complexity and tradeoffs

O(n log(n+1)) time; O(n) result copy and O(1) additional working space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `static void sink(int[] a,int parent,int size) {` — Restore max-heap ordering below one possibly misplaced root.
- `while(parent<size/2) {` — Only internal nodes can violate ordering with a child.
- `if(child+1<size&&a[child+1]>a[child]) child++;` — Promote the greater child so both child comparisons remain valid.
- `if(a[parent]>=a[child]) return;` — A correctly ordered root completes the repair.
- `int saved=a[parent]; a[parent]=a[child]; a[child]=saved;` — Exchange the misplaced value with its larger child.
- `parent=child;` — Continue along the only branch that may still violate heap order.
- `sink(a,0,end);` — Repair only the reduced unsorted prefix.
- `return Arrays.toString(a);` — Successive maxima occupy the suffix in ascending final order.

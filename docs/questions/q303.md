# Q303 — Sort an integer array using an explicit heap

**Topic:** Sorting with heaps · **Level:** Medium

## Question and contract

Sort an integer array using an explicit heap. Implement the operation exposed by `String solve(int[] input)`. Input is non-null; equal values may change relative identity because heapsort is not stable.

## Runnable example

```java
solve(new int[]{4,1,3,2})
```

Expected output:

```text
[1, 2, 3, 4]
```

## How and why the answer works

A max-heap exposes the largest unsorted value at its root. Swapping it to the final available slot fixes that position forever; sifting the replacement down restores the invariant on the shorter prefix.

# Q154 — Compare arbitrarily large version components

**Topic:** Strings · **Level:** Medium

## Question and contract

Compare dot-separated nonnegative decimal components; missing components are zero, leading zeros ignored. Return -1,0,1; valid nonempty components assumed.

## Example

Input:1.01.0 and1.1.

Expected printed output:

```text
0
```

## Approach and why each part exists

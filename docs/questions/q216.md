# Q216 — Detect equal values within an index distance

**Topic:** Hash maps · **Level:** Easy

## Problem and accepted inputs

Return whether distinct indices i,j satisfy a[i]==a[j] and |i-j|<=k; k must be nonnegative.

## Example

```java
solve(new int[]{1,2,1},2)
```

Expected Java value: `true`.

Expected printed output (verified):

```text
true
```

## How, why, and where to use it

Store the latest occurrence of each value. If even its nearest earlier occurrence is too far away, every older occurrence is also too far. This detects repeated event identifiers inside a bounded number of arrivals.

## Worked trace

For [1,2,1] and k=2, the second 1 finds earlier index0; distance2 is allowed.

## Line-by-line reasoning

- `public static boolean solve(int[] a,int k) {` — Inspect proximity in positions rather than in numeric value.
- `if(k<0) throw new IllegalArgumentException("negative distance");` — A distance bound cannot be negative.
- `Map<Integer,Integer> latest=new HashMap<>();` — Retain only the closest earlier occurrence of each value.
- `for(int i=0;i<a.length;i++) {` — Visit indices in increasing order so stored positions are earlier.
- `Integer previous=latest.put(a[i],i);` — Replace the old position and retrieve it in one map operation.
- `if(previous!=null && i-previous<=k) return true;` — One valid pair proves existence.
- `return false;` — No latest earlier occurrence met the bound.

## Complexity and tradeoffs

Expected O(n) time and O(u) space for u distinct values.

## Cases to practise

- `solve(new int[]{1,2,1},2)` → `true`: Pair exactly on the distance boundary.
- `solve(new int[]{1,2,1},1)` → `false`: Equal values too far apart.
- `solve(new int[]{7,7},0)` → `false`: Distinct indices cannot have distance zero.

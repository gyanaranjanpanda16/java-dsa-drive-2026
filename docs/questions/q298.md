# Q298 — Find the minimum slots for tasks with a cooldown

**Topic:** Greedy scheduling · **Level:** Medium

## Question and contract

Find the minimum slots for tasks with a cooldown. Implement the operation exposed by `long solve(String tasks,int cooldown)`. UTF-16 char task labels; unit durations; any task order; all labels share the same nonnegative cooldown.

## Runnable example

```java
solve("AAABBB",2)
```

Expected output:

```text
8
```

## How and why the answer works

The most frequent task needs maximum-1 gaps of cooldown slots. A frame of maximum-1 blocks of width cooldown+1 plus tied final labels gives a lower bound. Other tasks fill the gaps; when they overflow the frame, total task count is sufficient. This standard unit-duration, identical-cooldown model permits the bound to be attained.

## Walkthrough

For AAABBB and cooldown 2, arrange A B idle A B idle A B. Equal tasks have two slots between them and total length is 8. Six tasks alone are insufficient because the most frequent task forces gaps. The frequency formula compares the frame required by those repeated tasks with the total number of tasks.

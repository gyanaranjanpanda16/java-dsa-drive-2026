# Q267 — Check whether a root-to-leaf path has a target sum

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Check whether a root-to-leaf path has a target sum. Implement the operation exposed by `boolean solve(Node root,long target)`. Node values and path sums fit long; target subtraction must fit long. Only complete root-to-leaf paths count.

## Runnable example

```java
solve(sample(),7)
```

Expected output:

```text
true
```

## How and why the answer works

A valid path chooses exactly one child at each internal node. Subtracting the current value reduces the target to precisely what the remaining suffix must contribute.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Begin with target 7. Visiting 4 leaves 3 still required; choosing child 2 leaves 1; choosing leaf 1 leaves 0. Since this is a leaf, a complete root-to-leaf path has the required sum and the answer is true. A partial path reaching the target at an internal node would not satisfy the contract.

## Complexity and tradeoffs

O(n) time; O(h) stack. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Checks and edge cases

- Path 4→2→1 totals seven.
- Internal-node prefix is not a leaf path.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `if(root==null) return false;` — A missing tree has no root-to-leaf path.
- `if(root.left==null&&root.right==null) return target==root.value;` — Only a leaf may finish a valid path.

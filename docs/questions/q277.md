# Q277 — Sum BST keys in an inclusive interval

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Sum BST keys in an inclusive interval. Implement the operation exposed by `long solve(Node root,int low,int high)`. Input is a valid BST. Both interval endpoints are inclusive; low>high denotes an empty interval.

## Runnable example

```java
solve(sample(),3,6)
```

Expected output:

```text
18
```

## How and why the answer works

BST ordering rules out whole subtrees when the current value is outside the query interval. Included subtrees are still partitioned without overlap.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

For inclusive range [3,6], include 3,4,5,6, totaling 18. Node 2 is below the range, so its left branch can be skipped; node 7 is above it, so its right branch cannot contribute. Inclusive comparisons keep the endpoints 3 and 6 in the sum.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `if(root==null||low>high) return 0;` — Empty trees or empty intervals contribute nothing.
- `if(root.value<low) return solve(root.right,low,high);` — All left keys are even smaller and can be pruned.
- `if(root.value>high) return solve(root.left,low,high);` — All right keys are even larger and can be pruned.
- `return root.value+solve(root.left,low,high)+solve(root.right,low,high);` — Include the admissible node and search both remaining sides.

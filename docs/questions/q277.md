# Q277 — Sum BST keys in an inclusive interval

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Sum BST keys in an inclusive interval. Implement the operation exposed by `long solve(Node root,int low,int high)`. Input is a valid BST. Both interval endpoints are inclusive; low>high denotes an empty interval.

## How and why the answer works

BST ordering rules out whole subtrees when the current value is outside the query interval. Included subtrees are still partitioned without overlap.

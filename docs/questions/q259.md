# Q259 — Sum all tree values

**Topic:** Trees and BST · **Level:** Beginner

## Question and contract

Sum all tree values. Implement the operation exposed by `long solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
28
```

## How and why the answer works

Disjoint child subtrees plus the root partition the nodes, so their sums add without double counting.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

The left subtree totals 1+2+3=6 and the right subtree totals 5+6+7=18. Add the root value 4 to obtain 28. Every recursive result represents a whole subtree sum, not its node count. Using long for the aggregate allows many int values to be added safely within the stated numeric bounds.

## Complexity and tradeoffs

O(n) time; O(h) call-stack space. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

# Q384 — Tower Of Hanoi Moves

**Topic:** Recursion and backtracking · **Difficulty:** Medium

## Question and contract

Implement `Tower Of Hanoi Moves` using the operation demonstrated below. Return legal source-to-destination moves for 0..15 disks.

## Demonstration

```java
moves(2)
```

Expected printed output (verified):

```text
[A->B, A->C, B->C]
```

## How and why

The largest disk cannot move until all smaller disks are on the spare peg. Recursing on both smaller transfers keeps every move legal and gives 2^n-1 moves.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `List<String> out = new ArrayList<>();` — Collect moves in the only order they should be executed.
- `move(disks, 'A', 'C', 'B', out);` — Transfer the full tower from A to C using B.
- `return out;` — The list contains the complete legal move sequence.
- `if (n == 0) return;` — There is no move for an empty tower.
- `move(n-1, from, spare, to, out);` — Clear the largest disk by relocating the smaller tower.
- `out.add(from + "->" + to);` — Move the now-exposed largest disk once.
- `move(n-1, spare, to, from, out);` — Reassemble the smaller tower above it.

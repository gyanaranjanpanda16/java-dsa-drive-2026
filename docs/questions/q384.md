# Q384 — Tower Of Hanoi Moves

**Topic:** Recursion and backtracking · **Difficulty:** Medium

## Question and contract

Implement `Tower Of Hanoi Moves` using the operation demonstrated below. Return legal source-to-destination moves for 0..15 disks.

## Demonstration

```java
moves(2)
```

Expected printed output (verified):

```text
[A->B, A->C, B->C]
```

## How and why

The largest disk cannot move until all smaller disks are on the spare peg. Recursing on both smaller transfers keeps every move legal and gives 2^n-1 moves.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

## Walkthrough

For two disks: A→B, A→C, B→C.

## Complexity and tradeoffs

O(2^n) time/output and O(n) stack.

Use the input domain above when judging whether the state space fits memory and whether arithmetic fits the chosen numeric type. Recursive output-generation problems have an unavoidable cost proportional to their output; avoid using them on unrestricted large inputs.

`selfTest()` checks 3 independently expected cases, including small or boundary inputs. Before opening the solution, predict the sample and derive a simpler baseline. After solving, change one input condition and explain which part of the proof would need to change.

# Q411 — Minimum Coin Count

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Minimum Coin Count` using the operation demonstrated below. Unlimited positive denomination coins; nonnegative amount small enough to allocate a table.

## Demonstration

```java
minimum(new int[]{1,3,4},6)
```

Expected output:

```text
2
```

## How and why

Removing the final coin leaves a smaller amount. Trying every denomination includes the last coin of an optimal solution, while the stored smaller answer is already optimal.

## Complexity and tradeoffs

O(amount*coinCount) time and O(amount) space; pseudo-polynomial in the numeric amount.

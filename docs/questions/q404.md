# Q404 — Circular House Robber

**Topic:** Dynamic programming · **Difficulty:** Medium

## Question and contract

Implement `Circular House Robber` using the operation demonstrated below. Integer house values; selecting no house is allowed.

## Demonstration

```java
maximum(new int[]{2,3,2})
```

Expected printed output (verified):

```text
3
```

## How and why

The first and last houses are adjacent. Removing either endpoint turns the circle into a line, and every valid circular selection appears in at least one of those two cases.

The source includes comments at each meaningful line. Start by naming the state, identify the stopping or initialization case, and then follow how a smaller solved state or an accepted choice contributes to the answer. Do not memorize the loop order without the state definition.

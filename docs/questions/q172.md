# Q172 — Find the second middle node of a list

**Topic:** Linked lists · **Level:** Easy

## Question and contract

Return the middle value as OptionalInt; for even length choose the second middle; empty returns no value.

## Example

The demonstration constructs a fresh linked list with `list(...)`.


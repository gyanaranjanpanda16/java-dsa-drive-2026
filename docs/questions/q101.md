# Q101 — Build a reverse lookup index for shared values

**Topic:** Java Collections: inverse map · **Level:** Beginner

## Question and contract

Invert non-null string mappings into value-to-sorted-keys lists. A plain swapped map would overwrite duplicate values; a multi-value index supports department-to-employees or tag-to-items lookups without losing relationships.

Implement `Map<String,List<String>> solve(Map<String,String> input)`. The examples below define concrete accepted inputs and expected answers. Unless stated otherwise, reference inputs must be non-null; unsupported input violates the method's contract. Read the validation and comments in the source for additional restrictions.

## Example and answer

Input arguments: `Map.of("amy","dev","bob","ops","cat","dev")`

Expected Java value: `Map.of("dev",List.of("amy","cat"),"ops",List.of("bob"))`

Expected printed output (verified):

```text
{dev=[amy, cat], ops=[bob]}
```

- `inverse.computeIfAbsent(entry.getValue(),ignored -> new ArrayList<>()).add(entry.getKey());` — Preserve every key even when several share a value.

- `return inverse;` — Both value groups and their member keys have deterministic natural order.

# Q465 — Deadline Job Sequencing Profit

**Topic:** Greedy and search on answer · **Difficulty:** Medium

## Question and contract

Implement `Deadline Job Sequencing Profit` using the operation demonstrated below. Unit-duration jobs, slots begin at1, finish by integer deadline; selecting no job is allowed.

## Demonstration

```java
maximum(new int[][]{{2,100},{1,19},{2,27},{1,25},{3,15}})
```

Expected output:

```text
142
```

## How and why

Processing descending profit protects the most valuable feasible choices. Placing each as late as possible leaves maximal early capacity for later jobs with smaller deadlines; feasible job sets obey the scheduling exchange property.

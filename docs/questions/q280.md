# Q280 — Check mirror symmetry around the root

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Check mirror symmetry around the root. Implement the operation exposed by `boolean solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(new Node(1,new Node(2),new Node(2)))
```

Expected output:

```text
true
```

## How and why the answer works

Symmetry requires equal opposing values and recursively matching outer and inner child pairs. Comparing ordinary left-to-left positions would test equality rather than reflection.

## Walkthrough

This example uses root 1 with two leaf children both valued 2. Compare the left child with the right child: values agree. Then compare their outer children and inner children; all are null on both sides, so the tree is symmetric. Equal child values alone would not be enough if their deeper shapes differed.

## Complexity and tradeoffs

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `static boolean same(Node a,Node b) {` — Pair positions that should reflect one another.
- `if(a==null||b==null) return a==b;` — Symmetry fails when only one reflected position exists.
- `return a.value==b.value&&same(a.left,b.right)&&same(a.right,b.left);` — Compare values and both cross-paired branches.
- `return root==null||same(root.left,root.right);` — Empty trees are symmetric; otherwise compare mirrored child positions.

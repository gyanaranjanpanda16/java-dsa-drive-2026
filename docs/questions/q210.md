# Q210 — Score balanced parentheses by nesting rules

**Topic:** Stacks, queues, and deques · **Level:** Medium

## Question and contract

Valid parentheses input gives one pair () score 1, concatenation adds, and wrapping doubles. Empty has score0; arithmetic overflow throws.

## Example

Input: (()(())) .

Expected printed output:


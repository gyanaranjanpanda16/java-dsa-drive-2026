# Q262 — Find tree diameter measured in edges

**Topic:** Trees and BST · **Level:** Intermediate

## Question and contract

Find tree diameter measured in edges. Implement the operation exposed by `int solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example


Expected output:

## How and why the answer works

Every simple tree path has a highest node. At that node its length is left height plus right height; maximizing those candidates covers all paths.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

At root 4, the left and right subtree heights are both 2 nodes. Combining them gives a path with 4 edges, for example 1→2→4→6→7. Compare this with the best paths entirely inside each subtree. The answer is 4 edges; adding one for the root here would mix node-count and edge-count conventions.

- `int a=height(n.left,best),b=height(n.right,best);` — Heights summarize the longest downward paths.

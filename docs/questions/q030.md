# Q030 — Count distinct values

**Topic:** Arrays and sets · **Level:** Beginner

## Question and contract

Return the number of distinct int values. Set insertion collapses repetitions, making the final size the desired count.

Implement `int solve(int[] a)`. The examples below define concrete accepted inputs and expected answers. Unless stated otherwise, reference inputs must be non-null; unsupported input violates the method's contract. Read the validation and comments in the source for additional restrictions.

Expected Java value: `3`

Expected printed output (verified):

## How and why the answer works

Return the number of distinct int values. Set insertion collapses repetitions, making the final size the desired count.

Follow the state in this order for the sample input; each explanation corresponds to a line in the solution:

- `Set<Integer> seen = new HashSet<>();` — A set represents membership without duplicate entries.
- `for (int value : a) seen.add(value);` — Adding an existing value leaves the number of entries unchanged.
- `return seen.size();` — One set entry corresponds to each distinct input value.

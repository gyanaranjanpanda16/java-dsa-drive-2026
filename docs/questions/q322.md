# Q322 — Find the area of the largest island

**Topic:** Grid graphs · **Level:** Medium

## Question and contract

Find the area of the largest island. Implement the operation exposed by `int solve(int[][] grid)`. Rectangular binary grid; four-way adjacency; input preserved.

## Runnable example

```java
solve(new int[][]{{1,1,0},{0,1,0},{1,0,1}})
```

Expected output:

```text
3
```

## How and why the answer works

A component traversal counts every land vertex exactly once. Taking the maximum over disjoint components yields the greatest possible island area without merging diagonal neighbors.

# Q297 — Find the minimum number of meeting rooms

**Topic:** Interval heaps · **Level:** Medium

## Question and contract

Find the minimum number of meeting rooms. Implement the operation exposed by `int solve(int[][] meetings)`. Rows are [start,end) with start<end; every row has two int values.

## Runnable example

```java
solve(new int[][]{{0,30},{5,10},{15,20}})
```

Expected output:

```text
2
```

## How and why the answer works

Sorting by start time makes the heap contain precisely the intervals still active at each arrival. Their maximum count is both unavoidable and sufficient: released rooms can always be reused.

# Q297 — Find the minimum number of meeting rooms

**Topic:** Interval heaps · **Level:** Medium

## Question and contract

Find the minimum number of meeting rooms. Implement the operation exposed by `int solve(int[][] meetings)`. Rows are [start,end) with start<end; every row has two int values.

## Runnable example

```java
solve(new int[][]{{0,30},{5,10},{15,20}})
```

Expected output:

```text
2
```

## How and why the answer works

Sorting by start time makes the heap contain precisely the intervals still active at each arrival. Their maximum count is both unavoidable and sufficient: released rooms can always be reused.

## Walkthrough

The meeting [0,30] occupies one room. [5,10] overlaps it, requiring a second. When [15,20] starts, the room whose meeting ended at 10 is reusable while [0,30] continues. The maximum simultaneous room count is 2. Keeping earliest end times in a min heap identifies the first room that becomes available.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int[][] sorted=meetings.clone();` — Sort only row references, leaving caller order unchanged.
- `Arrays.sort(sorted,Comparator.comparingInt(a->a[0]));` — Process meetings by start time so past releases are known.
- `PriorityQueue<Integer> endings=new PriorityQueue<>();` — The earliest finishing active meeting is released first.
- `int rooms=0;` — No room is needed before the first meeting.
- `for(int[] meeting:sorted) {` — Each row is a half-open interval with positive duration.
- `while(!endings.isEmpty()&&endings.peek()<=meeting[0]) endings.poll();` — A room ending at this start is reusable.
- `rooms=Math.max(rooms,endings.size());` — Maximum simultaneous occupancy is a necessary lower bound.
- `return rooms;` — Allocating one room per overlapping meeting reaches that bound.

# Q388 — Phone Keypad Combinations

**Topic:** Recursion and backtracking · **Difficulty:** Medium

## Question and contract

Implement `Phone Keypad Combinations` using the operation demonstrated below. Non-null string of digits 2..9, short enough to enumerate; empty input returns an empty list.

## Demonstration

```java
letters("23")
```

Expected printed output (verified):

```text
[ad, ae, af, bd, be, bf, cd, ce, cf]
```

## How and why

Each answer selects exactly one mapped letter at each digit position. The Cartesian product recursion produces every valid selection once.

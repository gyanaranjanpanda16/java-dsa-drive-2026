# Q327 — Find minimum semesters with unlimited parallel courses

**Topic:** Graphs · **Level:** Medium

## Question and contract

Find minimum semesters with unlimited parallel courses. Implement the operation exposed by `int solve(int n,int[][] prerequisites)`. Each course takes one semester; unlimited simultaneous courses; prerequisite edges use valid course IDs; empty course set takes zero semesters.

## Runnable example

```java
solve(4,new int[][]{{0,2},{1,2},{2,3}})
```

Expected output:

```text
3
```

## How and why the answer works

Every course must wait until all predecessor courses finish. Kahn layers schedule it at the earliest possible semester; therefore the number of layers is both a lower bound imposed by prerequisite chains and an attainable schedule.

## Walkthrough

Courses 0 and 1 have no prerequisites, so take them together in semester 1. Their completion releases 2 for semester 2, which releases 3 for semester 3. The result is 3. Count whole dependency layers, not individual courses, because independent courses may run in parallel.

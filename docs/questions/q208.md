# Q208 — Decode nested repetition brackets

**Topic:** Stacks, queues, and deques · **Level:** Medium

## Question and contract

Input is valid lowercase text with k[encoded] groups,positive int k,proper brackets,and final/intermediate output lengths fitting available memory.

## Example

Input:3[a2[c]].

Expected printed output:

```text
accaccacc
```

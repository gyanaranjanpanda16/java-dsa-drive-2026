# Q252 — List tree values in preorder

**Topic:** Trees and BST · **Level:** Beginner

## Question and contract

List tree values in preorder. Implement the operation exposed by `String solve(Node root)`. A null root denotes an empty tree. Values are int; aggregate results use long where needed.

## Runnable example

```java
solve(sample())
```

Expected output:

```text
[4, 2, 1, 3, 6, 5, 7]
```

## How and why the answer works

Visit current node before its children. The recursive call handles one entire subtree, so placing the current value at the specified point establishes the traversal order by induction.

## Walkthrough

The sample tree has root `4`, children `2` and `6`, and leaf pairs `1,3` below `2` and `5,7` below `6`.

Emit 4 immediately. Enter the left subtree and emit 2 before its children 1 and 3. Then enter the right subtree and emit 6 before 5 and 7. This gives 4,2,1,3,6,5,7. Moving the append operation before the recursive calls is what makes a parent precede its descendants.

## Complexity and tradeoffs

O(n) time; O(h) recursion plus O(n) output. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `int value; Node left, right;` — Child references encode hierarchy; null means no child.
- `Node(int value) { this.value = value; }` — A fresh node starts as a leaf.
- `static void walk(Node n,List<Integer> out) {` — The helper appends exactly one subtree traversal.
- `if(n==null) return;` — An empty subtree contributes no values.
- `out.add(n.value); walk(n.left,out); walk(n.right,out);` — Visit current node before its children to preserve the required order.
- `List<Integer> out=new ArrayList<>();` — Collect each visited value once in the requested order.
- `walk(root,out);` — Recursion visits the whole reachable hierarchy.
- `return out.toString();` — A stable text form makes the traversal easy to inspect.

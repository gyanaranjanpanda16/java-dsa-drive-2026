# Q468 — Minimum Refueling Stops

**Topic:** Greedy and search on answer · **Difficulty:** Hard

## Question and contract

Implement `Minimum Refueling Stops` using the operation demonstrated below. Unlimited tank, stations[position,fuel], start at0; every selected station is used at most once.

## Demonstration

```java
minimum(100,10,new int[][]{{10,60},{20,30},{30,30},{60,40}})
```

Expected output:

```text
2
```

## How and why

Whenever another stop is unavoidable, choosing the largest fuel among stations already reachable cannot reduce future options compared with any other one-stop choice. Deferred choices model stopping there earlier.

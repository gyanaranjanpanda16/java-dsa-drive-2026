# Q291 — Report the median after each stream value

**Topic:** Two heaps · **Level:** Hard

## Question and contract

Report the median after each stream value. Implement the operation exposed by `String solve(int[] stream)`. All int values are accepted; medians are exact integers or half-integers representable in double.

## Runnable example

```java
solve(new int[]{5,1,9,2})
```

Expected output:

```text
[5.0, 3.0, 5.0, 3.5]
```

## How and why the answer works

Maintain all lower-half values <= all upper-half values and sizes differing by at most one. Rebalancing moves only the boundary value, preserving order; the heap roots then expose the median.

## Walkthrough

After 5, the median is 5. After 1, the lower and upper halves have boundary values 1 and 5, whose average is 3. After 9, the middle value is 5. After 2, sorted values are 1,2,5,9, so average the boundaries 2 and 5 to get 3.5. Balancing two heaps exposes these boundaries without sorting the full stream again.

## Complexity and tradeoffs

O(n log(n+1)) time and O(n) total storage. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

## Read the important code decisions

These statements connect the algorithm to Java. Follow how each one changes the state used by the next statement; the linked answer contains the complete method.

- `PriorityQueue<Integer> low=new PriorityQueue<>(Comparator.reverseOrder());` — The lower half exposes its greatest value.
- `PriorityQueue<Integer> high=new PriorityQueue<>();` — The upper half exposes its least value.
- `List<Double> medians=new ArrayList<>();` — Record a median for each processed prefix.
- `for(int value:stream) {` — Insert each arrival without sorting the whole prefix.
- `if(low.isEmpty()||value<=low.peek()) low.offer(value); else high.offer(value);` — Preserve ordering between the two halves.
- `if(low.size()>high.size()+1) high.offer(low.poll());` — Move the largest lower value when the lower half is too large.
- `double median=low.size()==high.size()?((long)low.peek()+high.peek())/2.0:low.peek();` — Widen before averaging to avoid int addition overflow.
- `medians.add(median);` — The two boundary roots determine the middle value or pair.

# Q349 — Return the first k lexicographic completions of a prefix

**Topic:** Tries · **Level:** Medium

## Question and contract

Return the first k lexicographic completions of a prefix. Implement the operation exposed by `String solve(String[] words,String prefix,int k)`. Non-null strings; k>=0; distinct suggestions in UTF-16 lexical order; recursive word depth must fit the JVM stack.

## Runnable example

```java
solve(new String[]{"cart","cat","car","care","car"},"ca",3)
```

Expected output:

```text
[car, care, cart]
```

## How and why the answer works

The prefix node contains exactly all completions. Emit a terminal node before its children because a string sorts before its extensions, then explore child characters in sorted order. This is the basic autocomplete engine; a production ranking system may store popularity instead of using lexical order.

## Walkthrough

Under ca, DFS takes r before t. At car it emits car, then care and cart; after three results it stops before visiting cat.

## Complexity and tradeoffs

O(S log(A+1)+P log(A+1)+visited nodes+output characters) time; O(S+H) space beyond output, H maximum word length. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

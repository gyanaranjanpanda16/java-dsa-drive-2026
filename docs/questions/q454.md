# Q454 — Lemonade Change

**Topic:** Greedy and search on answer · **Difficulty:** Easy

## Question and contract

Implement `Lemonade Change` using the operation demonstrated below. Each drink costs5; initially no change; bills are5,10,20.

## Demonstration

```java
possible(new int[]{5,5,5,10,20})
```

Expected output:

```text
true
```

## How and why

For fifteen change, using a ten plus a five preserves two extra fives compared with three fives. Fives are needed by more future payment types, so this exchange cannot hurt feasibility.

## Walkthrough

After three fives and one ten, the twenty can be changed with the retained ten and one five.

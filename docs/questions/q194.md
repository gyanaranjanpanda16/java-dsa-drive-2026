# Q194 — Find the largest rectangle in a histogram

**Topic:** Stacks, queues, and deques · **Level:** Hard

## Question and contract

Heights are nonnegative unit-width bars. Return maximum rectangle area as long; empty returns0.

## Example

Input:[2,1,5,6,2,3].

Expected printed output:

```text
10
```

## Approach and why each part exists

A direct scan or simulation establishes the baseline; the implementation below chooses the operations required by the contract.

An increasing stack keeps bars without a known smaller right boundary. When a smaller bar arrives, each popped bar has both nearest smaller boundaries known, defining its widest valid rectangle.

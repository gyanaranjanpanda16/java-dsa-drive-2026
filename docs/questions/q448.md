# Q448 — Optimal Search Tree Cost

**Topic:** Dynamic programming · **Difficulty:** Hard

## Question and contract

Implement `Optimal Search Tree Cost` using the operation demonstrated below. Frequencies for sorted distinct keys; successful searches only; root depth is one comparison.

## Demonstration

```java
minimum(new int[]{34,8,50})
```

Expected output:

```text
142
```

## How and why

Choosing a root divides sorted keys into independent left and right intervals. All searches in the interval pay one root comparison, so add the interval frequency total to optimal child costs.

## Walkthrough

Choosing the third key as root and the first key as its left child gives weighted cost142.

## Complexity and tradeoffs

O(n³) time and O(n²) space; aggregate weighted costs must fit long.

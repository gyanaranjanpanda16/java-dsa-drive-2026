# Q151 — Group words with equal character multiplicities

**Topic:** Strings · **Level:** Medium

## Question and contract

Group non-null words by exact UTF-16 character multiset, preserving first group appearance and input order inside groups.

## Example

Input: eat, tea, tan, ate.

Expected printed output:

```text
[[eat, tea, ate], [tan]]
```

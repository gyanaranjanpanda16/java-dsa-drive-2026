# Q379 — Partition values into k equal-sum subsets

**Topic:** Backtracking with symmetry pruning · **Level:** Medium

## Problem and accepted inputs

Given at most16 nonnegative int values and k between1 and the number of values, decide whether every value can be assigned to exactly one of k nonempty equal-sum groups. Preserve the input. Invalid bounds or negative values are rejected.

## Example

```java
solve(new int[]{4,3,2,3,5,2,1},4)
```

Expected Java value: `true`.

Expected printed output (verified):

```text
true
```

## How, why, and where to use it

A divisible total is necessary but not sufficient: [2,2,2] cannot form two groups summing3. Assign the largest remaining value first so impossible bucket capacities are exposed early. Buckets with equal current sums are interchangeable for existence, so try only one of each sum. If the total is positive and all buckets end at target, every bucket is nonempty; if all values are zero, n>=k lets us explicitly distribute at least one to each group. This is a small-instance load-balancing feasibility problem.

## Worked trace

For [4,3,2,3,5,2,1], total20 and k4 require each bucket to reach5. In descending order, place5 alone,4 with1,3 with2, and the other3 with2. The answer is true. For [2,2,2], total6 passes divisibility but no bucket can reach3, so backtracking proves false.

## Line-by-line reasoning

- `public static boolean solve(int[] values,int k) {` — Return feasibility rather than enumerating all partitions.
- `if(values.length>16||k<1||k>values.length) throw new IllegalArgumentException("1<=k<=n<=16 required");` — Each group needs at least one available element.
- `long total=0; for(int value:values) { if(value<0) throw new IllegalArgumentException("nonnegative values required"); total+=value; }` — Widen the sum before adding.
- `if(total%k!=0) return false;` — Unequal fractional targets cannot be reached with integers.
- `if(total==0) return true;` — Nonnegative inputs are all zero and can fill k nonempty groups.
- `int[] sorted=values.clone(); Arrays.sort(sorted);` — Leave the caller's order intact.
- `return place(sorted,sorted.length-1,new long[k],total/k);` — Visit values from largest to smallest.
- `private static boolean place(int[] values,int at,long[] sums,long target) {` — Bucket sums record exactly the assigned values.
- `if(at<0) return true;` — The full total is assigned and no bucket exceeded target, so every bucket equals target.
- `for(int bucket=0;bucket<sums.length;bucket++) {` — Try placing this value into each meaningfully different bucket.
- `boolean repeated=false; for(int earlier=0;earlier<bucket;earlier++) if(sums[earlier]==sums[bucket]) repeated=true;` — Equal sums produce symmetric subproblems.
- `if(repeated||sums[bucket]+values[at]>target) continue;` — Skip symmetry and impossible capacity.
- `sums[bucket]+=values[at];` — Make one tentative choice.
- `if(place(values,at-1,sums,target)) return true;` — A successful completion proves feasibility.
- `sums[bucket]-=values[at];` — Undo the failed choice before another bucket is tested.
- `return false;` — Every distinct feasible bucket choice failed.

## Complexity and tradeoffs

O(n log n + k^n) worst-case time and O(n+k) working space. Symmetry pruning helps but does not make this polynomial; the16-element contract keeps it an educational small-instance search.

## Cases to practise

- `solve(new int[]{4,3,2,3,5,2,1},4)` → `true`: Multiple nontrivial groups.
- `solve(new int[]{2,2,2},2)` → `false`: Divisibility alone is insufficient.
- `solve(new int[]{0,0,0},2)` → `true`: Zero-sum groups must still be nonempty.

# Q463 — Maximum Units On A Truck

**Topic:** Greedy and search on answer · **Difficulty:** Easy

## Question and contract

Implement `Maximum Units On A Truck` using the operation demonstrated below. Each type is[available boxes, units per box]; box-count capacity is nonnegative.

## Demonstration

```java
maximum(new int[][]{{1,3},{2,2},{3,1}},4)
```

Expected output:

```text
8
```

## How and why

All boxes consume equal capacity, so swapping any selected lower-unit box for a higher-unit available box improves or preserves value. Choosing in descending unit order exhausts these improvements.

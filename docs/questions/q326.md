# Q326 — Find the shortest one-letter word transformation

**Topic:** Implicit graphs · **Level:** Hard

## Question and contract

Find the shortest one-letter word transformation. Implement the operation exposed by `int solve(String begin,String end,String[] words)`. Lowercase English words of the same length; every transformed word must belong to the dictionary; begin itself need not belong.

## Runnable example

```java
solve("hit","cog",new String[]{"hot","dot","dog","lot","log","cog"})
```

Expected output:

```text
5
```

## How and why the answer works

Words form an implicit graph with edges between equal-length words differing in one letter. BFS explores this graph by transformation count; dictionary removal ensures each word enters the queue once.

## Walkthrough

One shortest ladder is hit→hot→dot→dog→cog. Each transition changes one letter and uses a dictionary word, so there are four transformations but five words. The reported result is 5 because this contract counts words. BFS explores transformations by distance, unlike DFS which might find a longer route first.

## Complexity and tradeoffs

O(N L² A) time with copied strings of length L and alphabet size A=26; O(NL) dictionary/frontier storage. This cost describes the supplied representation and stated input contract. A more general version may need extra validation or a different representation; do not silently extend the assumptions.

- `if(begin.equals(end)) return 1;` — A zero-change route contains the starting word itself.
- `Set<String> remaining=new HashSet<>(Arrays.asList(words));` — The dictionary also acts as the unvisited vertex set.
- `if(!remaining.contains(end)) return 0;` — The destination must be an allowed transformed word.
- `Deque<String> q=new ArrayDeque<>(); q.add(begin); remaining.remove(begin);` — Start one BFS frontier without revisiting the starting word.

- `length++;` — Advance only after finishing the entire current frontier.
- `return 0;` — Exhausting reachable dictionary words proves no transformation exists.

# Q326 — Find the shortest one-letter word transformation

**Topic:** Implicit graphs · **Level:** Hard

## Question and contract

Find the shortest one-letter word transformation. Implement the operation exposed by `int solve(String begin,String end,String[] words)`. Lowercase English words of the same length; every transformed word must belong to the dictionary; begin itself need not belong.

## Runnable example

```java
solve("hit","cog",new String[]{"hot","dot","dog","lot","log","cog"})
```

Expected output:

```text
5
```

## How and why the answer works

Words form an implicit graph with edges between equal-length words differing in one letter. BFS explores this graph by transformation count; dictionary removal ensures each word enters the queue once.

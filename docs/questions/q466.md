# Q466 — Minimum Simultaneous Platforms

**Topic:** Greedy and search on answer · **Difficulty:** Medium

## Question and contract

Implement `Minimum Simultaneous Platforms` using the operation demonstrated below. Comparable integer times, positive-length half-open visits; equal-time departure precedes arrival.

## Demonstration

```java
minimum(new int[][]{{900,910},{940,1200},{950,1120},{1100,1130},{1500,1900},{1800,2000}})
```

Expected output:

```text
3
```

## How and why

Every overlapping visit requires a different platform. Reusing a platform immediately after departure achieves exactly the maximum active interval count, so that count is optimal.
